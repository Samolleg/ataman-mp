# EI Mapper: Endurance Edition 0.1.0-alpha.41

Исправления после тестовой сборки alpha.40:

- Исправлен отказ сохранения после последовательности «вставить объекты →
  сохранить → отменить → сохранить → повторить». Redo теперь восстанавливает
  привязку копии к проверенному исходному поддереву MOB.
- При выборе объектов с разными наборами частей модели поле **Model parts**
  больше не исчезает. Различающиеся значения показываются как неопределённые,
  а совместимый набор частей можно вставить сразу в несколько объектов.
- В окне создания объекта работает вставка нескольких совместимых свойств за
  одну операцию.
- Создание и размещение точки патруля или направления взгляда теперь является
  одним действием Undo/Redo.
- При переходе через длинную цепочку истории показывается блокирующий индикатор
  выполнения.
- Команда создания объекта отключена, если активный MOB не загружен.
- Исправлено отображение отключённых пунктов и полей: они больше не выглядят
  как активный жирный белый текст.
- Из окна MOB Diff удалена неработающая кнопка справки.

Резервные копии уже создаются автоматически. При открытии сохраняется снимок
исходного файла, а перед перезаписью существующего файла — отдельный снимок
`pre-save`. Они находятся в `%LOCALAPPDATA%\EI Mapper Endurance\backups` и
доступны через **Tools → Open Backup Folder**.
