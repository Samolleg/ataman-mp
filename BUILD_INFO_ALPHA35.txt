Non-interactive version commit: b10261f
Clean-package implementation commit: a3a416b
Package source snapshot: tag v0.1.0-alpha.35
Purpose: clean first-run tester package and non-interactive build verification

Alpha.35 supersedes the withdrawn alpha.34 package. Alpha.34 accidentally
included a developer-local endurance-options.json, suppressing first-run setup
and exposing local game/recent-file paths.

This package contains no user settings, logs, or crash dumps. A clean extraction
must open Game and Mod Setup on first normal startup. Qt's GUI version dialog is
also replaced with a non-interactive command-line handler so automated build
checks do not leave pop-up windows behind.

Follow ALPHA35_VALIDATION.md and ALPHA34_VALIDATION.md.
