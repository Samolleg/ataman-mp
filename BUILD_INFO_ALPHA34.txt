Purpose: independent MOB script workflow, first patrol creation, duplicate/history shortcuts

MOB scripts are now edited in a separate internal window. The external UTF-8
workspace and file watcher belong to the loaded MOB document, remain active even
when no script or parameters window is open, and import accepted changes as one
main undo-history command.

Pressing P on a unit without patrol points creates its first point. A non-Path
unit is switched to Path as part of the same undoable command; undo restores its
previous behavior. Ctrl+D duplicates the current selection through the existing
deferred paste transaction, and Ctrl+L opens History.

Endurance application shortcuts added during recent UI work are persisted under
Settings > Key Bindings and are applied immediately.

The production MinGW build and extended non-interactive widget checks passed.
Follow ALPHA34_VALIDATION.md and test only on copied MOBs or Save As outputs.
