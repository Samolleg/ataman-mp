# Текстуры предметов с суффиксом map — 0.5.0-alpha, r5

Предметы из базы используют отдельные преобразованные текстуры с окончанием `map`.
Для cheat dagger из бронзы обе текстуры объекта получают имя:

`unhumadg_03.br.1.x2map`

В ресурсах активного профиля должен находиться файл `unhumadg_03.br.1.x2map.mmp`.
Предпросмотр использует именно этот ресурс. Если он отсутствует или не читается,
окно показывает нужное имя и блокирует размещение. Исходная текстура экипировки
не подставляется. Суффикс не добавляется второй раз.

1. Запустите редактор и выберите профиль с вашими преобразованными текстурами.
2. Добавьте из базы cheat dagger, материал bronze. Проверьте предпросмотр и обе текстуры.
3. Нажмите «Разместить на карте»: окно закроется, предмет появится у мыши.
4. Сохраните и откройте карту снова; проверьте отмену/повтор и преобразование в рычаг.
5. Загрузите карту в игре и проверьте рисунок текстуры и взаимодействие.

У уже размещённых кинжалов задайте указанное имя вручную в основной и дополнительной
текстуре. Установленные карты не переписываются автоматически. Имена новых мобов
и рычагов из категории «Рычаги» не изменяются; рычаг из предмета сохраняет его map-текстуру.

Файлы текстур готовит пользователь. Сборка редактора не содержит ресурсов игры и
не преобразует их. Формат DXT1 сам по себе не меняет раскладку изображения на модели:
map-текстура отображается с координатами модели, без коррекции x2 для экипировки.

Проверены 13 тестов, создание/история/сохранение и реальный DXT1-файл кинжала в JMV.
Base проверен с искусственной тестовой DXT1-текстурой. Внешний вид в игре остаётся
ручной проверкой. Известный сбой общей проверки интерфейса сохраняется.

r4 и её настройки сохранены; эта сборка находится в отдельной папке r5.
