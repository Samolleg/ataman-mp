# Добавление из database.res — промежуточная проверка

Версия редактора: 0.5.0-alpha. Это промежуточная сборка, а не завершение всех
трёх категорий задачи EI-ADD-FROM-DB-001.

В окне создания доступны каталог активной базы, поиск по названию/модели,
предпросмотр и размещение существа или рычага щелчком по карте. Существующий
объект-образец не нужен. Дополнительные свойства раскрываются отдельно.
Прежнее создание технических объектов по образцу сохранено в отдельной категории.

Исправлено повторное сохранение после отмены и возврата созданного объекта.
Новые записи проходят проверку сохранения перед добавлением в историю действий.
Сценарий карты не изменяется.

## Проверка

1. Настройте профиль игры или мода и откройте карту либо отдельный файл объектов.
2. Откройте создание объекта. В разделе «Существа» найдите запись базы и
   проверьте предпросмотр. Ничего на карте выделять заранее не требуется.
3. Нажмите «Разместить на карте» и щёлкните по нужному месту. Повторите действие
   с отменой через Esc: новый объект при отмене появляться не должен.
4. Проверьте отмену/повтор, сохраните под новым именем, снова отмените создание,
   сохраните, повторите создание и сохраните ещё раз. Откройте результат заново.
5. Повторите с рычагом. Если основная текстура не определилась, выберите её в
   дополнительных свойствах. Проверьте расположение и поведение в тестовой игре.

## Незавершённые части

- Категория предметов пока показывает записи базы, но размещение подбираемого
  предмета недоступно. Новый сценарий или декоративная подмена не создаются.
- В базе рычагов нет установленной связи с текстурой. При неоднозначном выборе
  текстуру нужно указать вручную. Значение Scale из базы не подменяет пропорции
  модели на карте.
- Вид и игровое поведение размещённых объектов, особенно моделей JMV,
  требуют ручной проверки. Сборка не проверялась интерактивным запуском игры.
- Общая автоматическая проверка виджетов редактора по-прежнему завершается
  ошибкой доступа к памяти. Отдельные проверки каталога, создания и сохранения
  проходят; это не заменяет проверку окна пользователем.
