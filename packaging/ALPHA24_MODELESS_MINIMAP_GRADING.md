# Alpha 24 tester changelist

- The viewport minimap now appears whenever an MPR is loaded, allowing Generated
  mode and manual refresh to be used while Auto regeneration is off.
- Export Minimap remains open while the viewport is edited. Press Regenerate to
  capture current object positions and visibility.
- Grading controls accept typed values as well as slider input.
- Added Hue from -180 to +180 degrees.
- Shading intensity now supports 0-150%.
- Apply & Lock updates the viewport immediately; Unlock re-enables the open
  export tool.
