# Общая кисть рельефа — 0.5.0-alpha, world-terrain-sculpt r3

Добавлено согласование высот соприкасающихся границ со смещёнными вершинами,
включая стык zone1/zone2/zone3obr. Целые отрезки границы внутри кисти получают
общий прямой профиль с сохранением наклона. Положение карт не меняется.
Исправление обновления видеобуферов из R2 сохранено.

## Проверка

1. Откройте прежний стык трёх карт. В «Общая кисть: выбрать карты…» включите
   соседей zone2 и zone3obr.
2. Выберите сглаживание, радиус 5, силу 1. Поместите стык внутрь круга и проведите
   мазок, как на записи. Проверьте границу с обеих сторон.
3. Отмените и повторите мазок, затем переключите активную карту.
4. Если результат подходит, сохраните весь набор через «Сохранить все карты»,
   откройте карты повторно и проверьте тот же участок.

Согласование может локально выпрямить край. Отрезки, пересекающие край кисти,
переходят к неизменённому рельефу: там может остаться несовпадение. Для проверки
помещайте проблемный участок внутрь кисти. Защищённые карты не изменяются;
зазоры между картами и перекрывающиеся площади эта операция не исправляет.

Проверки: ядро — 12 успешно, включая расчёт на реальных трёх картах без записи
игровых файлов; панель — 16 успешно/2 пропуска без графического контекста;
отдельный тест видеобуферов Windows — 3 успешно. После восьми сглаживаний разница
на проверенных границах составила около 0,00025 единицы высоты, в пределах
точности MPR. Визуальная проверка вашей сцены ещё требуется.

Прежний сбой полной проверки интерфейса 0xC0000005 остаётся открытым.
R2 сохранена отдельно; пользовательские настройки в новую сборку не копируются.
