# Сценарий карты — 0.5.0-alpha, R2

Слой открывается через **Инструменты → Сценарий карты**. Показывает обращения,
условия, переходы к коду и проверенные маркеры появления/перемещения; учитывает
неприменённый буфер редактора, не меняя MOB и историю.

Исправлены два пропуска подключаемых MOB:

- `AddMob("quest")` теперь находит `quest.mob`, включая цепочки подключений.
- При работе с дополнительным MOB учитывается проверенный основной MOB,
  даже если он не открыт в редакторе. Закрытие подключённого документа сохраняет
  его исследованный сценарий в семействе. Чужие карты остаются вне семейства.

## Проверка

1. Откройте ту же карту и панель сценария. Для полного списка снимите
   **Только выбранный участник**, если выбран объект. Проверьте столбец источника
   и обращения из подключённых MOB; выберите нужное обращение и нажмите **К коду**.
2. Проверьте команды подключения без `.mob` и цепочку подключений. При закрытии
   дополнительного MOB его исследованный исходник остаётся доступен для просмотра.
3. Проверьте переключение на другую карту: ссылки прежнего семейства не должны
   попадать в её список. Проверьте изменение буфера с AddMob и его отмену.

## Границы проверки

Исправления воспроизведены отдельными тестами. Семейство JMV zone3obr проверено
только чтением: 9 источников, 2191 запись сценария, 26 виртуальных маркеров.
Какой именно участник пропадал у пользователя, пока не установлен: требуется
проверка того же случая в интерфейсе. R1 сохранена для сравнения вместе с её
пользовательскими настройками и журналом.

Сценарий анализируется статически: выполнение и достижимость не доказаны,
неразрешённые выражения и неоднозначные ID не получают угаданных маркеров.
Незагруженные размещённые объекты участвуют в сопоставлении ID; их модели
автоматически не загружаются. Для XY-маркера нужна загруженная поверхность.
Зависимость вне исследованного набора источников остаётся неполной.

Release, 15 проверок модели, 38 проверок Desktop OpenGL и 42 проверки ANGLE
с корпусом прошли. Общий `--ui-widget-check` остаётся непрошедшим по протоколу
R1; повторно в этой правке не запускался. Упакованный редактор запускает пользователь.

Локальная сборка; push, PR и публикация не выполнялись.
