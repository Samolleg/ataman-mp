# Сценарий карты — 0.5.0-alpha, R3

Русский теперь выбран по умолчанию при первом запуске. Явно сохранённый выбор
английского сохраняется; язык можно изменить в настройках и перезапустить редактор.

**Правый клик по строке сценария** выделяет найденный объект и переносит к нему
камеру. Если его подключаемый MOB ещё не открыт, редактор автоматически открывает
этот MOB. Повторный клик использует уже открытый документ. Основной активный MOB
сохраняется; переход не меняет файлы карт и не добавляет команд в историю правок.
При открытии действует штатное создание резервной копии.

Если строка содержит несколько найденных участников, ПКМ переходит к первому.
Другого можно выбрать в списке внизу и нажать **Показать участника / маркер**.
Для виртуальной цели камера переходит к маркеру. Неоднозначные и динамические
ссылки не получают угаданных объектов. Для скрытого MOB нужно включить видимость.
Если файл изменился после анализа, сначала обновите проверку семейства MOB.

## Проверка

1. Запустите редактор из этой папки: интерфейс должен быть русским.
2. Откройте карту и **Инструменты → Сценарий карты**. Нажмите ПКМ по строке с
   найденным объектом, в том числе из подключаемого MOB, как на вашем скриншоте.
   Объект должен выделиться, камера — перейти к нему, нужный MOB — открыться.
3. Нажмите ПКМ повторно: второй экземпляр того же MOB появляться не должен.
   Проверьте другую строку и строку с неразрешённым выражением.
