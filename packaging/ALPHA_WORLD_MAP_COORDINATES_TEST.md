# 0.5.0-alpha — постоянные координаты карт мира

## Что изменилось

- У каждой карты теперь есть постоянное абсолютное начало координат в пределах
  пары «профиль ресурсов + аллод».
- При первом использовании схема детерминированно строится из `map.txt` и
  сохраняется в `%LOCALAPPDATA%\EI Mapper Endurance\world-map-layouts.json`.
- Повторное чтение `map.txt` сохраняет уже известные координаты и добавляет
  только новые зоны. Полная связная компонента хранится без ограничения по
  глубине; ограничение до пяти карт осталось только у отображаемого фона.
- Переход по двойному щелчку теперь переводит позицию камеры и точку вращения
  через абсолютные координаты мира. Переход A → B → A должен возвращать тот же
  видимый участок без накопления смещения.
- Повреждённый, неподдерживаемый или недоступный для записи JSON не
  перезаписывается. Редактор временно использует вычисленную в памяти схему и
  показывает предупреждение в интерфейсе и журнале.

## Что намеренно не менялось

- Перетаскивание карт мышью и другие элементы ручного редактирования схемы не
  добавлены. Для следующего этапа подготовлены только независимые от UI API:
  задать координату, сбросить одну зону и сбросить раскладку одного аллода.
- Соседние MPR остаются фоном только для чтения и не попадают в сохранение,
  экспорт, мини-карту или запуск теста карты.
- Файлы установленной игры и модов не изменяются и не копируются. Постоянный
  JSON не содержит путей к игре, архивам, MPR или MOB.

## Основная ручная проверка A → B → A

1. Запустите `EIMapperEndurance.exe` из этой папки, выберите тестовый профиль и
   откройте карту A, у которой есть видимая соседняя карта B того же аллода.
2. Включите «Соседние карты» и наведите камеру на легко узнаваемую точку карты
   B. Запомните положение, направление и масштаб.
3. Дважды щёлкните по B. Убедитесь, что B стала активной, A видна фоном, а
   камера осталась над той же точкой мира и не перескочила ко входу.
4. Не меняя камеру, дважды щёлкните по A. Сравните итоговый вид с исходным:
   положение, точка вращения, направление и масштаб не должны получить
   дополнительного смещения.
5. Закройте редактор, запустите его снова и повторите переход. Сохранённая
   раскладка должна дать тот же результат. Сам JSON можно проверить только для
   чтения: в нём не должно быть абсолютных путей или имён файлов `.mpr`/`.mob`.
6. Если доступны два профиля или два аллода, откройте по карте из каждого и
   убедитесь, что фон одной группы не появляется в другой.

## Дополнительная проверка защиты JSON

При желании, только при закрытом редакторе, сохраните резервную копию
`world-map-layouts.json`, замените рабочий файл заведомо неверным JSON и
запустите редактор. Должно появиться предупреждение, соседний фон должен
работать на временно вычисленной схеме, а неверный файл должен остаться без
изменений. После проверки закройте редактор и восстановите резервную копию.

## Граница автоматической проверки

Автоматические тесты подтверждают детерминированный якорь, разделение профилей
и аллодов, сохранение и повторное чтение, добавление новой зоны без сдвига
старых, защиту повреждённой/неподдерживаемой схемы, отсутствие путей в JSON,
API ручной координаты и сброса, ограничение видимого фона и точный
local → world → local переход. Визуальная непрерывность на реальных картах и
попадание двойного щелчка требуют ручного подтверждения по шагам выше.
