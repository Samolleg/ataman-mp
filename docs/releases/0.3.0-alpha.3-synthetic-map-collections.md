# EI Mapper: Endurance Edition 0.3.0-alpha.3

This closed-test build corrects unmapped collection testing and collection
authoring UX.

- Loose single-MPR/single-MOB JMV tests now use a guarded process-local
  synthetic zone identity with the loaded MPR dimensions and Play from Here as
  its only entrance. They no longer expose the borrowed bootstrap map's
  minimap, travel zones, or coordinate frame.
- Initial launch and hot reload share protocol version 3 metadata for synthetic
  identity, dimensions, and entrance coordinates. A stale packaged bridge is
  rejected before launch.
- Collection trees display the collection's editable `name` value.
- Cancelling the native filename dialog returns to the new-collection editor
  without losing the draft.
- Duplicated collections now offer to open after a successful save, matching
  newly created collections.
- Particle runtime diagnostics are reduced to an empty control, the confirmed
  crashing row 0 parent, and ten deterministic single-particle controls.
- A runtime process crash takes precedence over a later manual stop in the
  authoritative result.

Manual acceptance still requires confirming that an unmapped collection opens
without a minimap, spawns at its Play from Here anchor, and hot reload preserves
that synthetic identity.
