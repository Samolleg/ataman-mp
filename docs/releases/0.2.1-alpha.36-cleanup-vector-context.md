# 0.2.1-alpha.36 — Runtime cleanup and Vector3 context menu

- Hash-owned test-run artifacts now receive bounded cleanup retries after the
  owned runtime exits. This handles the observed Windows delay releasing the
  run-local bridge DLL without weakening the hash guard or hiding persistent
  cleanup failures.
- Right-clicking an X, Y, or Z component no longer changes the current plate or
  parent Vector3 selection merely to open that component's Copy/Paste menu.

The supplied alpha.35 run successfully loaded `gz2g`, completed three hot
reloads into `gz9g`, and validated all staged hashes. Its single reported error
was the transient bridge-DLL cleanup failure addressed here.
