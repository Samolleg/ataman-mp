# EI Mapper Endurance 0.3.0-alpha.26 — full database editor test

## What changed

- Replaced the three-table authoring projection with all 26 public Evil Islands
  database tables and every schema-described field.
- Added native typed codecs for scalar values, lists, bit fields, fixed strings,
  nested typed lists, acknowledgement records, and descriptor-unknown hex data.
- Added physical source-record provenance so duplicate display IDs, row order,
  clones, deletions, and edits target the exact original record.
- XLSX export/import now covers all 26 tables using EIDB-compatible sheet names
  and `FLD<id>-<index>` identifiers. The workbook carries the exact source RES
  and a profile/source/schema manifest; mismatched or stale workbooks fail closed.
- Native publication starts from the immutable source archive and rewrites only
  the selected member/record/field. Unrelated members and field encodings remain
  byte-identical.

## Focused test

1. Open the Database Editor and confirm the table list includes Materials,
   Weapons, Armors, all Unit tables, Spells, Perks, Prints, Quests, and Acks.
2. Change an ordinary scalar and a structured/list value, then undo and redo.
3. Export XLSX, edit several rows in Excel, and reimport it. Review validation,
   then Apply Database or Save Database As.
4. Reopen/export the produced RES and compare the intended edited values.

## Known limitation

Fields whose public descriptor is `Hex` are editable hexadecimal payloads. Their
bytes are losslessly preserved and isolated, but their game meaning is not
claimed. Compound values are currently edited as compact structured JSON cells.
