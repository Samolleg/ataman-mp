# EI Mapper: Endurance Edition 0.2.1-alpha.26

Closed-test candidate for owned runtime delivery and installation isolation.

- JMV and Base launch through the same editor-owned 32-bit runtime host.
- The host creates `game.exe` suspended, injects the run-local bridge, calls
  `EnduranceInitialize` outside `DllMain`, and resumes only after guarded
  initialization succeeds.
- JMV no longer relies on Starter's DEV `plugin.dll` slot to deliver Endurance.
- Base path queries are virtualized inside the owned process, so the selected
  profile root supplies work/resources/CD paths without changing the user's
  shared Evil Islands registry settings.
- The known VK-packaged Base executable hash is accepted as a second exact
  experimental manifest after confirming its sole differing code byte lies
  outside all guarded bridge sites.
- Map, collection, and direct document loads reject nested activation while
  finalisation is in progress. Progress event pumping excludes user input and
  open/save/test commands remain disabled until the load finishes.

Focused validation:

1. Select each of two Base installations with different hero/data sets and
   prove the launched game uses the selected root.
2. Run Base probe levels 3 and 4 against both listed hashes.
3. Launch JMV, verify a bridge result and runtime log are produced, then test
   one hot reload.
4. During a large map load, click another Maps/Collections row and use Open
   shortcuts; no second workspace may begin.
