# EI Mapper: Endurance Edition 0.3.0-alpha.11

> Withdrawn. Alpha.11 passed the fixed world object's first word as the world
> pointer and crashed immediately after Main Menu readiness. It must not be
> used for Test Current Map.

This focused build fixes the alpha.10 Test Current Map regression where a
synthetic/no-identity collection stopped at the main menu.

- The supported game executable's fingerprinted texture-manager accessor is
  now called directly after the main-menu runtime becomes ready.
- Both that accessor and resource-registration entry point remain protected by
  exact byte guards.
- The temporary placeholder archive remains run-owned, hash-journaled, and
  shared by the Base and JMV launch paths. Installed RES archives are not
  replaced or edited.
- A registration failure remains fail-closed and is reported explicitly rather
  than allowing the game to load an unresolved synthetic map texture.
