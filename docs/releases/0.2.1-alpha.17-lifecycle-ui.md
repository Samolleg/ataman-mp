# EI Mapper: Endurance Edition 0.2.1-alpha.17

This closed-test build tightens test-run and main-window UI lifecycle behavior.

## Changes

- Defer each post-test result notification until the launcher lifecycle signals
  have settled, and stop the previous dismissal timer before showing a new run.
- Save dock visibility before shutdown closes secondary windows, preserving the
  enabled Maps and Collections, Object Outliner, Object Properties, History, and
  MOB Family Validation panels across restarts.
- Render disabled menu entries in an unmistakable dark grey while retaining the
  same alignment and spacing as enabled entries.
- Disable **Close All** when neither an MPR nor any MOB is loaded.
- Keep an application-modal progress dialog open from hot-reload staging until
  the runtime bridge reports commit, failure, timeout, process exit, or launch
  error. The game is focused only after this dialog closes.

## Focused validation

- Full x64 MinGW release compile.
- Headless widget/lifecycle smoke check.
- Manual runtime checks: two consecutive completed test runs, panel visibility
  across restart, empty-workspace File menu, and a successful/failed hot reload.
