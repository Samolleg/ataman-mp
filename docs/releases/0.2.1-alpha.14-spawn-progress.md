# EI Mapper: Endurance Edition 0.2.1-alpha.14

This closed-test build fixes stale Play-from-Here state across different-map hot
reloads and standardizes blocking progress UI.

Implementation: [`3f658af`](https://github.com/Ilufus/ei-mapper-endurance/commit/3f658af).

## Changes

- Bind a custom spawn anchor to the exact loaded MPR and map-table identity.
- Clear all custom-spawn picking, movement, selection, and position state when
  the map-test context changes.
- Ignore and log any stale anchor that survives without matching the current
  map context.
- Package the current runtime bridge, which clears the previous generation's
  optional bootstrap MOB when a different map uses a normal entrance.
- Reuse one application-modal progress dialog style for map loading, collection
  loading, test staging, hot reload, and long undo/redo operations.
- Remove Close and Help title-bar controls from those blocking dialogs.

## Focused test

1. Load map A, place Play from Here, and launch it.
2. Load map B and confirm no custom marker is present.
3. Keep map B's normal entrance selected and hot reload.
4. Confirm the player starts at map B's selected entrance rather than map A's
   former custom coordinates.

Nested and conditional supplemental `AddMob` exact-once behavior remains marked
for confirmation when a deterministic test case is available.
