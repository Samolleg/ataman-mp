# 0.2.1-alpha.4 cross-MOB object validation

This focused build fixes lossless save/hot-reload rejection after copying an
object from one MOB into another. It does not change the installed game or map
files during test launch.

## Reproduction

1. Open the Zone 1 MPR, `zone1.mob`, and `Autozone1cyclopus.mob`.
2. Make `Autozone1cyclopus.mob` the active destination MOB.
3. Copy one or more trees from `zone1.mob` and paste them into the AutoZone.
4. Finish their placement.
5. Use Save As to a disposable MOB and confirm it succeeds.
6. Start the current-map test, then repeat Ctrl+F5 after another tree edit.
7. Confirm the trees appear once and that the workflow log contains no
   `mob.object_sequence.ui_provenance` or `Could not rebase copied-object raw
   template` warning.

## Safety checks

- Confirm the installed `zone1.mob` and `Autozone1cyclopus.mob` hashes do not
  change.
- Reopen the disposable saved AutoZone and verify the copied trees and their
  intended transforms.
- Test deletion plus undo/redo of a cross-MOB copy before saving.

## Known separate limitation

Play From Here still uses a post-registration fallback move. On some systems
the player can be briefly visible at the selected native entrance before being
moved to the custom marker. A true pre-render custom placement path remains a
runtime research task.
