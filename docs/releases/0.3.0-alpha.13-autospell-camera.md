# 0.3.0-alpha.13 — autorun capability and camera timing

This test slice replaces inferred Play from Here availability with an explicit
JMV autorun-MOB capability check. Base EI and map lifecycles that do not execute
the autorun MOB do not expose custom spawn, Godmode, or Time of Day delivery.
No live entrance records are changed.

Continuous keyboard camera movement now integrates its configured speed over
elapsed time using the previous 60 FPS behavior as the nominal speed. Long UI
stalls are bounded, camera resets restart timing, and selection render passes no
longer trigger additional movement updates.

Validation:

- JMV launcher tests: 37 passed, 3 environment-dependent skips;
- camera tests: 6 passed;
- full Qt 5.12.12/MinGW release build passed;
- `--ui-widget-check` passed.
