# EI Mapper: Endurance Edition 0.2.1-alpha.34

## Vector component clipboard

- Treat X, Y, and Z plates as mutually exclusive component selections instead
  of leaving the complete Vector3 row selected.
- Support validated Ctrl+C/Ctrl+V directly on a selected component plate.
- Add Copy value and Paste value to each component plate's context menu.
- Update only the selected component and retain the existing compound vector.

## Outliner filtering

- Suspend tree repainting and expansion signals while applying a filter.
- When a matching category already makes all descendants visible, skip
  rebuilding model, texture, database, owner-MOB, and validation search text
  for every descendant.
- Record filter passes taking at least 100 ms in the workflow log for further
  large-map profiling.

## JMV Starter selection

- Require the profile-selected JMV mod root to contain a readable `config.reg`.
- Record Starter's persisted `ModSel` and registry `AddonPath` beside the
  profile-selected target in the run manifest and runtime log.
- Keep the selected editor profile authoritative through the existing
  owned-process `AddonPath` override. Shared Starter configuration remains
  untouched.

## Focused validation

- Clean Qt/MinGW release compile.
- `--ui-widget-check`: individual component selection, keyboard copy/paste,
  context-menu paste, numeric conversion, partial text editing, and scroll
  preservation all pass.
- JMV profile discovery against the configured installation succeeds with the
  approved `game.exe` fingerprint and selected mod root.
