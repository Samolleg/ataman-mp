# EI Mapper Endurance 0.3.0-alpha.20

## Camera navigation during editing

- Keep middle-mouse camera orbit active during Move, Rotate, Scale, tile
  painting, and Play-from-Here movement.
- Give the camera exclusive ownership of an active MMB drag so it cannot also
  transform an object or move the provisional spawn marker.
- Resynchronize the pending transform cursor after camera navigation to avoid
  a jump when editing resumes.

## Settings and UI scaling

- Apply changes without closing Settings.
- Add a separate Save & Close action; Cancel continues to discard unapplied UI
  values.
- Propagate UI-scale changes through already open top-level editor windows and
  their inherited child controls, while preserving intentionally customized
  child fonts.
- Continue rebuilding cached viewport entrance/map label textures at the new
  scale.

## Validation

- Extend the headless widget check to verify live-window font propagation,
  Apply staying open, and Save & Close closing the window.
- Require a clean Qt 5.12.12/MinGW release build before tester handoff.
