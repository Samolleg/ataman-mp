# EI Mapper Endurance 0.3.0-alpha.23 - minimap control and runtime header

## Changes

- DXT1 minimaps now include the legacy RGB565 descriptor required by the game
  texture loader. The prior zero-filled descriptor remained inspectable in the
  editor but produced an invisible in-game minimap.
- Generated capture excludes hidden static objects. The viewport minimap has an
  explicit refresh button and an opt-in Auto toggle; Auto is off by default and
  queues regeneration after MOB changes including hide and unhide.
- Export Minimap compares the graded generated texture with the current embedded
  minimap when one resolves through the active resource profile.
- Export provides shading, saturation, contrast, and brightness controls.
  Apply & Lock freezes the selected result until Unlock is pressed in the
  viewport minimap.
- Changing the loaded map clears a locked generated image so it cannot leak into
  another map context.

## Automated validation

- Minimap export tests: 17 passed, 0 failed.
- Coverage includes exact DXT1 runtime header bytes, capture framing and
  orientation, terrain/overlay/static ordering, dynamic exclusion,
  deterministic grading and encoding, archive create/append/replace/refusal,
  failed-save preservation, catalog gating, and temporary test staging.
- Clean Qt 5.12.12 / MinGW 7.3 release build uses the documented ASCII `subst`
  wrapper. No visible editor is launched by the build or headless checks.

## Required private runtime checks

1. Export a generated DXT1 minimap to a copied test RES and run Test Current Map;
   confirm that the texture is visible, opaque, correctly oriented, and sharp.
2. Hide a scripted gate, press refresh, and confirm it disappears. With Auto
   disabled, hide/unhide must not regenerate; with Auto enabled, it must.
3. Compare embedded and generated views, adjust all four grading controls, apply
   and lock, edit or hide an object, and confirm the image remains unchanged
   until Unlock.
4. Hot-reload between embedded and generated modes and confirm the running test
   adopts the newly staged texture.
