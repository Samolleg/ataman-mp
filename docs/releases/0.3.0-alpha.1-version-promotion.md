# 0.3.0-alpha.1 — Integrated Endurance baseline

This version promotes the accumulated `0.2.1-alpha.44` feature set to a new
minor-development line. It does not change the established lossless MOB format
contract or compatibility policy.

The baseline includes the hardened MOB editor, runtime-family validation,
multi-MOB workspace UX, collections, recovery autosaves, JMV Test Current Map
and hot reload, profile-correct humanoid visuals, the integrated render and
environment pipeline, independent Time of Day and Lighting Mode controls, and
the taskbar-visible startup splash.

`0.3.0-alpha.1` remains a closed-test build. Stable `0.3.0` requires the final
editor/runtime matrix and clean distribution validation listed in `ROADMAP.md`.

Landscape editing moves to `0.4.0`; AI navigation graph visualization and
regeneration move to `0.5.0`.
