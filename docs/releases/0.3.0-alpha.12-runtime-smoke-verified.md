# EI Mapper: Endurance Edition 0.3.0-alpha.12

This build replaces withdrawn alpha.11.

## Fixed

- Corrected temporary resource registration to pass the fixed global world
  object itself to the fingerprinted accessor. Alpha.11 incorrectly
  dereferenced the object and passed its first word, causing an access violation
  immediately after `MainMenuReady`.
- Retained the shared Base/JMV temporary RES staging route without replacing
  installed texture archives.

## Regression coverage

- Added an opt-in owned-process runtime test which launches the configured JMV
  executable, waits for the bridge to report `GameplayReady`, and cleans up the
  owned process and staged files.
- Added stable generated MPR, empty MOB, and AI graph fixtures for the synthetic
  no-map-identity case.
- The release gate runs the test once against normal Zone 1 and once against the
  synthetic empty-control fixture. File-only staging tests are not sufficient
  for this bootstrap path.
