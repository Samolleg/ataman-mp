# 0.2.1-alpha.2 runtime validation

This build corrects the custom-spawn script syntax and adds collection-backed,
script-driven JMV supplemental MOB staging. Source maps and installed AutoZone
files must remain unchanged.

## Custom spawn and Godmode

1. Place Play from Here over clear terrain near selectable objects. The same
   click must not begin a selection rectangle or select an object.
2. Start Test Current Map. The run manifest must say `spawnMode: custom`, and
   the player must appear at the hero marker rather than the dropdown entrance.
3. Repeat with Godmode enabled and verify damage immunity.
4. The generated autorun script should contain `SetCPFast(GetLeader(), ...)`
   and `GodMode(0,3)` without semicolons. The installed
   `AutoRunSpellAddon123.mob` hash must not change.

## Collection and AutoZone loading

1. Open a collection containing one matching main MOB and one or more AutoZone
   MOBs referenced by its scripts.
2. Test Current Map must be enabled. Confirm the expected supplemental content
   appears once; do not assume every listed AutoZone is unconditional.
3. Check `bridge-result.log` for `SUPPLEMENTAL_MOB redirect` entries and verify
   `manifest.json` lists all ordered staged MOB paths and hashes.
4. Make one disposable edit in a referenced supplemental MOB and press Ctrl+F5.
   Confirm the edit appears after reload without a duplicate old instance.
5. Stop Test and compare hashes of the installed main/AutoZone files against
   their pre-test values.

Quick access to the retained run evidence:

`%LOCALAPPDATA%\EI Mapper Endurance\EI Mapper Endurance Edition\test-runs`
