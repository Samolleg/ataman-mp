# 0.2.1-alpha.20 Workspace responsiveness

## Changes

- Ctrl+A now refreshes Loaded Map selected-object counters immediately.
- Sticky outliner ancestry uses amber styling when its selected object belongs
  to a locked MOB.
- MPR and MOB visibility checkboxes share one aligned visibility column.
- Visibility can be painted across rows: the first checkbox determines the
  target state, crossed rows preview that same state, and the whole batch is
  applied once on release. Matching rows are not inverted.
- Clean MOBs are no longer rebuilt into redundant in-memory validation
  candidates. They are validated from their unchanged source files.
- Ordinary edit/undo validation is coalesced after 2.5 seconds of inactivity.
  Validation is deferred while a paste, move, rotate, or scale preview remains
  active. Save and Test Current Map preflights remain authoritative.

## Focused test

1. Ctrl+A in a MOB and confirm its Loaded Map row reports the selection count.
2. Keep a locked-MOB object selected, scroll its MOB parent out of the outliner,
   and confirm the sticky hierarchy is amber.
3. Drag through several MPR/MOB visibility checkboxes in both directions.
   Every crossed row should receive the first row's target state in one update.
4. Copy a large tree from the main MOB into a supplemental MOB, spend several
   seconds positioning it, and confirm validation does not hitch the active
   transform. After settling, only one coalesced validation run should appear.
