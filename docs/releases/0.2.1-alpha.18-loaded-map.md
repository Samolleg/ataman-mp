# 0.2.1-alpha.18 Loaded Map test

This focused tester build adds the first persistent multi-document workspace UI
without enabling simultaneous multi-MOB editing.

## Implemented

- A dockable **Loaded Map** tree shows the optional MPR root and every loaded
  MOB. Exactly one MOB is active; the others are locked against mutation.
- MPR and MOB visibility can be toggled independently without unloading data or
  changing object coordinates. Hidden MOB objects cannot be picked or selected.
- A MOB can be activated by clicking its row. Ctrl+T activates the owner of the
  selected locked-MOB object and is configurable under **Settings > Key Bindings**.
- **Unload MOB** performs the normal local-window and dirty-document checks,
  clears document-bound undo history, and removes that MOB from the workspace.
- The Object Outliner shows all loaded MOBs as top-level groups. Visible locked
  objects can be selected, inspected, copied, and used as templates; mutation
  remains directed to the active MOB.
- Paste and Ctrl+D create objects in the active MOB even when their source is a
  locked MOB.
- Individual Vector3 components can be copied as numeric scalars. Numeric paste
  validates the destination type/range; integer destinations round to the
  nearest integer.

## Focused tester pass

1. Load one MPR and at least two MOBs. Confirm the MPR is the root and switching
   MOB rows changes the active/locked labels.
2. Select a visible locked-MOB object. Confirm its properties are readable but
   cannot be changed or transformed. Copy/paste or Ctrl+D and confirm the new
   object belongs to the active MOB.
3. Double-click a locked object and use Ctrl+T in a separate pass. Confirm its
   owner becomes active and the object stays selected.
4. Hide and show each MOB, including the active MOB. Confirm hiding clears its
   selection and prevents viewport/outliner selection while hidden.
5. Hide/show the MPR and confirm terrain disappears/reappears without changing
   object heights or workspace/test membership.
6. Unload a clean MOB and a dirty MOB (testing Save, Discard, and Cancel). Also
   repeat with Mob Parameters or a script editor open for the target MOB.
7. Copy Position Z into a float field and an integer field. Confirm compatible
   values apply, integers round, and incompatible/out-of-range paste is refused.
