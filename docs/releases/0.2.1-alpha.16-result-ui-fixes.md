# EI Mapper: Endurance Edition 0.2.1-alpha.16

This closed-test build corrects alpha.15 result validation and finishes the
first post-test notification/settings/action-state UX pass.

## Changes

- Validate the latest hot-reload generation against its own recorded MPR/MOB
  paths and hashes instead of the initial launch aliases.
- Keep the internal recovery log under the test run while mirroring the same
  runtime messages to `logs/test-runtime-<run-id>.log` beside workflow logs.
- Replace per-module transition-probe path dumps with one aggregate summary.
  The bridge still inspects only modules loaded in its owned `game.exe` process
  to patch the required import tables.
- Show a green check, yellow warning, or red error in the non-modal post-test
  notification. Errors take display priority over warnings.
- Give Open Last Session its own Settings row instead of overlapping the
  inactive external-MPR polling control.
- Disable MOB and MPR Save/Save As actions immediately when their corresponding
  document is no longer loaded.
- Let the native disabled-menu palette provide readable grey text without a
  stylesheet-induced horizontal offset.

## Focused validation

- Initial launch and latest-generation hot-reload result tests.
- Full editor and x86 bridge release builds.
- Packaged headless and widget/lifecycle smoke checks.
