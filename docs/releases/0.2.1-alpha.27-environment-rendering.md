# EI Mapper: Endurance Edition 0.2.1-alpha.27

Focused graphics test candidate.

## Integrated visual work

- Restores the tester-approved profile/database humanoid visuals, linked armor
  submeshes, exact JMV PNT3 decoding, idle animation, and viewport-centered MMB
  orbit behavior.
- Retains the Final Character Texture / UV inspector under **View**, including
  upright atlas content and labels.
- Makes profile/equipment incompatibilities visible and navigable in MOB
  Family Validation instead of leaving them only in `workflow.log`.
- Retains the NVIDIA-safe entrance/spawn overlay state reset and the optimized
  final viewport teardown.

## New environment slice

- Draws the six-sided sky from `sky00` through `sky05` in the active game/mod
  resource profile. If any face is unavailable, the sky pass disables itself
  and logs the missing-profile condition.
- Uses active-MOB time, ambient, and sunlight values for terrain and objects.
- Adds a non-destructive time-of-day preview slider plus toggles for environment
  lighting, sky, fog, MOB point lights, and shadows under **Settings > Render**.
- Lights the scene with up to four nearest visible MOB light objects.
- Reuses the existing culled/batched render queue for directional shadow
  casters. Static casters are fingerprinted and cached; animated units refresh
  through a throttled dynamic layer. World objects with `Is shadow` disabled do
  not enter either shadow layer.

## Focused tester checks

1. Compare a day, night, dungeon, and briefing map with Environment Lighting
   toggled off/on.
2. Verify the sky uses game/mod resources and disappears cleanly when Game
   Resource Skybox is disabled.
3. Enable Preview Time Override and move the slider through sunrise, noon,
   sunset, and midnight. Confirm this does not dirty a MOB.
4. Inspect maps containing MOB Light objects and verify position/range/color
   affect nearby surfaces.
5. Toggle an ordinary object's `Is shadow` property and confirm only its shadow
   participation changes.
6. Observe animated units and dense static scenery with Render Performance
   Counters enabled; report FPS, visual artifacts, and `workflow.log`.

Known scope boundary: runtime weather semantics, particles, spot-light cones,
and point-light shadow maps are not claimed by this slice.
