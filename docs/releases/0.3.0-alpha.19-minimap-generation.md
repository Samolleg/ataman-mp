# EI Mapper Endurance 0.3.0-alpha.19 — minimap generation

## Changelist

- Adds **Tools > Generate Minimap...** for a loaded MPR or active collection.
- Captures the complete MPR at 128 review pixels per sector with fixed
  orthographic framing: world +X is right and world +Y is up.
- Includes terrain, authored overlay surfaces, fixed-noon scene lighting, and
  active-collection static geometry. Dynamic units, particles, editor helper
  icons, selection highlighting, tile previews, and grid overlays are excluded.
- Marks standalone MPR captures incomplete because collection static geometry
  is absent. It does not infer a texture name for an unregistered MPR.
- Shows the full-resolution source dimensions, capture completeness, framing,
  orientation, warnings, and a 256x256 game preview before any write.
- Saves the full-resolution review separately, or encodes the reviewed game
  image as deterministic uncompressed 8888 MMP.
- Uses one RES export path for new archives, additions, and explicitly
  confirmed replacements. Existing destinations retain the backend's backup,
  staged reopen, untouched-member, race-check, atomic publish, and fresh reopen
  validation contracts.
- After a successful texture export, can open the selected active-catalog zone
  with only its existing minimap field staged. The objectives texture remains
  unchanged; catalog publication still requires the ordinary verified Save As.
- Can stage the reviewed texture for the next JMV **Test Current Map** through a
  run-owned temporary RES and private staged map table. Installed resources and
  the editor document remain unchanged, and the queued preview is scoped to the
  current loaded-map identity.

## Manual acceptance cases

1. Open a copied collection containing one MPR, its primary MOB, supplemental
   static MOBs, and at least one unit. Generate twice without edits. Confirm the
   review framing/orientation, matching images, visible static structures and
   overlays, and absent units/editor helpers.
2. Open the same MPR alone. Confirm the dialog prominently says the capture is
   incomplete and does not claim that static collection geometry is present.
3. Use a synthetic destination path. Confirm a new RES is created and freshly
   reviewable. Repeat with an existing copied RES and a unique texture name;
   confirm addition plus backup. Repeat with the same name; cancel replacement,
   rename, then explicitly confirm replacement on a disposable copy.
4. Queue **Stage for Next Test**, then run a copied-map JMV Test Current Map.
   Confirm the generated minimap is shown and cleanup removes only the owned
   temporary RES/map-table files. Repeat after switching workspaces and confirm
   the stale queued preview is not reused.
5. Export a texture and request catalog registration. In Map Catalog Editor,
   verify only the minimap field is staged and the objectives texture is
   unchanged. Cancel Save As and confirm the active catalog remains unchanged;
   then save a copied active `texts.res` and confirm the existing refresh/rebind
   behavior without loss of dirty MPR/MOB work.
6. Exercise a destination on a nearly full disk or read-only directory. Confirm
   failure leaves the destination/catalog unchanged and preserves any staged
   candidate or backup diagnostics needed for recovery.

## Private runtime validation still required

Stock/JMV ZoneView correlation, a real JMV run-owned minimap preview, duplicate
resource precedence for a newly created RES, and large proprietary
`textures.res` timing remain private runtime gates. Perform them only against
hash-recorded copies; do not install this tester build into a live game tree.
