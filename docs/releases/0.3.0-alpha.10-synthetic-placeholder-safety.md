# EI Mapper: Endurance Edition 0.3.0-alpha.10

- Replace the unsafe alpha.9 `menus.res` rebuild with a standalone, uniquely
  named temporary RES containing only Endurance's checkerboard minimap.
- Register that archive through the same fingerprinted owned-process bridge in
  Base EI and JMV. No JMV configuration compiler or profile-specific resource
  loader is required.
- Keep the temporary archive beside the selected installation's resources only
  for the lifetime of the test. Its path and SHA-256 are journaled before
  creation, then normal and interrupted-run cleanup remove only an exact match.
- Never replace a member of `menus.res`, `textures.res`, or another installed
  archive. The same registration mechanism is ready for generated minimap
  captures in a later build.
