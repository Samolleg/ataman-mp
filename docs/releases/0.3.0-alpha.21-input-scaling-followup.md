# EI Mapper Endurance 0.3.0-alpha.21

## UI scaling and layout

- Scale existing child widgets, including the main menu bar and dock content,
  while preserving each widget's relative font styling.
- Wrap long entrance labels at word boundaries or within long tokens and size
  the rendered label texture to every resulting line.
- Keep Apply on the left of the Settings footer and the closing actions on the
  right.
- Render the literal `Save & Close` caption without treating the ampersand as
  a mnemonic marker.

## Viewport input

- Restore Esc cancellation for active Move, Rotate, and Scale previews before
  persistent docks or selections consume the key.
- Preserve Esc cancellation/restoration for Play-from-Here placement and
  movement previews.
- Keep ordinary wheel camera height/zoom active during object transforms.
- Clear object selection when entering Play-from-Here placement.

## Validation

- Extend the headless UI check for existing-child font propagation and the
  Settings footer/button behavior.
- Require a clean Qt 5.12.12/MinGW release build before tester handoff.
