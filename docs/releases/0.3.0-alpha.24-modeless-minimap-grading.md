# EI Mapper Endurance 0.3.0-alpha.24 - modeless minimap grading

## Changes

- The viewport minimap is shown as soon as an MPR is loaded. It no longer
  depends on an automatic generated capture, so the manual refresh control and
  Generated mode remain reachable while Auto is off.
- Export Minimap is a single persistent modeless tool window. Authors can move,
  hide, or unhide scene objects and regenerate without closing and reopening it.
- Manual or automatic viewport regeneration also refreshes an open, unlocked
  export preview while retaining its current grade.
- Every grading slider now has an editable numeric field. Shading supports
  0-150%, and Hue supports -180 to +180 degrees.
- Apply & Lock updates the viewport immediately. Viewport Unlock re-enables the
  controls in an open Export Minimap window.

## Validation

- Focused minimap tests: 17 passed, 0 failed, including deterministic hue and
  150% shading coverage.
- Headless widget checks cover modeless state, typed value synchronization,
  shading range, hue range, and the existing viewport refresh/lock controls.
- Clean Qt 5.12.12 / MinGW 7.3 build and both x86 Test Current Map runtime
  components are required for the tester package.
