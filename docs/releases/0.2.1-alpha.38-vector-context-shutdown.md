# 0.2.1-alpha.38 — Vector context and shutdown safety

- The complete right-click press/release gesture is consumed by the X/Y/Z component plate, preventing the parent Vector3 row from blinking selected.
- The clicked component is highlighted only while its context menu is open; the previous component selection is restored afterward.
- Final shutdown no longer destroys the diagnostic GPU timer through an invalidated Qt surface. The driver releases that one process-lifetime query with the OpenGL context.
- UI checks now verify press/release routing, in-popup component-only highlighting, and post-popup selection restoration.
