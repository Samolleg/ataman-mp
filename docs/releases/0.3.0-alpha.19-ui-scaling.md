# EI Mapper Endurance 0.3.0-alpha.19

## UI scaling

- Add **Settings > General > UI scale** with a 75-200% range, 5% steps, and
  100% default.
- Apply the saved scale before the splash, setup flow, and main editor UI are
  constructed.
- Update application fonts, menus, dialogs, docks, tables, and layout-derived
  control sizes immediately when Apply is pressed.
- Rebuild cached viewport entrance/map label textures at the selected scale.
- Keep world geometry, camera movement, picking coordinates, render targets,
  and map data unchanged.

## Validation

- The headless UI check covers slider range/step, percentage display,
  persistence, and live apply signaling.
- A clean Qt 5.12.12/MinGW release build and packaged UI smoke check are
  required before tester handoff.
