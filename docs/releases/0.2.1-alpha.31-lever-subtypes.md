# EI Mapper: Endurance Edition 0.2.1-alpha.31

## Lever conversion compatibility fix

- Correct the alpha.30 assumption that every basic `OBJECT` has `OBJTYPE 54`.
- Accept the complete normal Base/JMV basic-world-object subtype set:
  - 53: flora;
  - 54: ordinary scenery/world objects;
  - 55: stone/scenery.
- Preserve the structural safety boundary: the source must remain one complete
  `OBJECT` envelope with exactly one well-formed `OBJTYPE` record. Unknown,
  duplicate, missing, or malformed subtype records are rejected before any
  mutation.
- Replace the source subtype with lever subtype 60 while preserving all common
  and opaque source children byte-for-byte.
- Rejection diagnostics now identify the exact unsupported value or malformed
  record instead of reporting only an ambiguous `OBJTYPE`.

## Evidence

- Zone 2 contains 761 type-53, 34 type-54, and 2 type-55 basic objects; this
  directly reproduces the alpha.30 rejection.
- The full installed Base corpus contains 34,166 type-53, 8,873 type-54, and
  615 type-55 `OBJECT` records.
- The full installed JMV corpus contains 27,949 type-53, 13,002 type-54, and
  636 type-55 `OBJECT` records.
- One anomalous type-51 `OBJECT` exists in each corpus copy of the main-menu
  MOB and remains excluded pending runtime evidence.
- Focused lossless-document tests: 33 passed, 0 failed, 1 private fixture
  skipped.

The earlier alpha.30 runtime ownership and Hot Reload corrections are unchanged.
