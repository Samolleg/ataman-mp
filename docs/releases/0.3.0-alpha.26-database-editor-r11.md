# Database editor r11 tester notes

## Changed

- List fields such as `Wears` are presented as plain entries, one per line, in
  the full value editor. Internal JSON brackets and quotation marks are hidden.
- Grid previews remain compact and bounded; the full editor wraps long lines
  and reports the number of list items.
- XLSX export now uses EIDB-compatible shared strings, `FLD` columns, sheet
  names, flattened typed columns, and comma-delimited string lists.
- XLSX import accepts both Endurance workbooks and EIDB-produced workbooks with
  shifted/reordered sheets and columns, missing optional columns, and EIDB's
  numeric formatting.
- Endurance no-op XLSX export/import still reconstructs the original Base
  `database.res` byte-for-byte through the embedded-source minimal-patch path.

## Manual checks

1. Open `Human Poselok AD F4`, edit `Wears`, and confirm each item occupies one
   line with no brackets or quotation marks.
2. Export XLSX and open it in Excel and the patched EIDBEditor. Confirm `Wears`
   is a comma-delimited value and EIDBEditor does not freeze.
3. Reimport the unchanged XLSX in Endurance and confirm it introduces no
   database changes.

## Known limitation

Stock/patched EIDBEditor's standalone XLSX-to-RES path does not preserve every
opaque member from the source RES and is not byte-identical. Endurance's own
embedded-source import/export path is the verified lossless path.
