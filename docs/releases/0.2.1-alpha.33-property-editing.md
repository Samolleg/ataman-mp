# EI Mapper: Endurance Edition 0.2.1-alpha.33

## Property editing

- Preserve the Object Properties scroll position while transforms and direct
  field edits refresh the selected object.
- Restore native text-edit behavior: Ctrl+C copies only highlighted text and
  Ctrl+V replaces the current selection inside comments, templates, and other
  editable text fields.
- Make X, Y, and Z component plates independently selectable so typed property
  copy/paste can target one vector component without selecting the whole vector.
- Keep table-level typed validation and numeric conversion when copying through
  a property plate instead of editing text inside its field.
- Keep editable model and texture filters transactional: typing does not alter
  the object until Enter or an explicit dropdown choice commits it.

## Focused validation

- Clean Qt/MinGW release compile from a fresh shadow directory.
- `--ui-widget-check`: covers scroll preservation, native substring copy/paste,
  individual vector-component copy, typed numeric conversion, and transactional
  combo editing.
- Distribution finalizer: removes settings, logs, saves, and dumps, regenerates
  SHA-256 checksums, and validates the direct tester folder.
