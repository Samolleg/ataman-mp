# EI Mapper Endurance 0.3.0-alpha.16

Focused model-parts transaction and map-composition correctness build.

## Changes

- Display only checkboxes in the Parts Enabled column. The words `checked`,
  `unchecked`, `true`, `false`, `on`, and `off` remain search aliases only.
- Make all Parts columns interactively resizable and remember their widths.
- Record exact serialized Parts arrays for undo and redo.
- Paste the complete exact Parts array across objects and MOBs, including
  hidden, unknown, ordered, and duplicated tokens.
- Identify primary map MOBs through their serialized `SC_OBJECT_DB_FILE`
  declaration. Renamed copies remain valid; supplemental `PR_OBJECT_DB_FILE`
  Autozone MOBs cannot initialize Test Current Map by themselves.
- Emit one non-blocking validation warning when multiple primary MOBs are
  loaded, listing their complete paths.

## Validation

- Full Qt 5.12.12/MinGW release build passed.
- `--ui-widget-check` passed checkbox-only state display, resizable columns,
  filter aliases, exact Parts property paste, and existing lossless checks.
- `mob_family_validation_tests` passed the multiple-primary warning and the
  existing workspace-overlay/family regressions.
