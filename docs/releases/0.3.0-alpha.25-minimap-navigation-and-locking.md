# EI Mapper Endurance 0.3.0-alpha.25 - minimap navigation and locking

## Changes

- Removed the separate Auto toggle. Unlocked generated minimaps regenerate after
  map changes; locked minimaps remain frozen.
- The viewport lock icon and Export Minimap Apply & Lock / Unlock action now
  share one state. Applying also selects Generated mode immediately.
- Export preview zoom and center are preserved across grading changes and scene
  regeneration. Reset settings restores the authored-profile defaults.
- Non-square generated and embedded comparisons are both cropped to the active
  map rectangle before display, so square-texture padding no longer appears as
  a black stripe or changes Fit geometry.
- Export Minimap saves its window geometry. It remains open across map switches
  and shows a disabled no-map/waiting state until a valid capture is available.
- The viewport minimap draws the current perspective camera footprint and accepts
  clicks to move the camera pivot in XY while preserving its vertical/orbit state.
- AI graph and minimap overlays share the same opaque child-widget repaint
  contract required over the OpenGL viewport.

## Validation

- Focused minimap tests cover deterministic capture, grading, encoding, archive
  safety, catalog gating, and staging.
- Headless UI checks cover unified lock state, opaque overlay configuration,
  reset behavior, modeless editing, typed controls, active-rectangle crop, and
  preview transform preservation.
- A clean Qt 5.12.12 / MinGW 7.3 build and both x86 Test Current Map runtime
  components are required for the tester package.
