# 0.2.1-alpha.43 — Runtime activation reliability

- Caches the owned game's main module during the loader-safe preparation call,
  before the JMV process is resumed.
- Removes `GetModuleHandleW` from post-JMV bridge activation while the game's
  main thread is suspended. This prevents a first-launch deadlock when that
  thread still owns the Windows loader lock after executable patch bytes have
  become quiescent.
- Records every runtime-host bridge export, wait result, elapsed time, and
  return value in `runtime-host.log` so future activation failures identify the
  exact phase instead of appearing only as game exit code 68.

Focused reproduction: alpha.42 run `20260723-074630-0d459fb9` completed bridge
preparation but its `EnduranceActivateRuntime` remote thread timed out after 15
seconds. A second identical run succeeded, establishing a startup race rather
than a map, entrance, manifest, or staged-payload failure.
