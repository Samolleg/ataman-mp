# EI Mapper Endurance 0.3.0-alpha.26 - minimap polish

## Changes

- The viewport camera frame is now a map-clipped convex ground footprint. It is
  drawn as a white outline with a fully transparent interior, including when the
  camera approaches or crosses the ground-plane horizon.
- The viewport Regenerate action selects the refreshed Generated preview.
- The minimap lock uses a centered editor-drawn icon instead of a platform emoji.
- Reset settings now sits with Fit and 100%; Apply & Lock / Unlock has a wider,
  stable action area.
- Export Minimap is an independent modeless top-level window with the editor
  icon and normal minimize, maximize, taskbar focus, and close behavior. Closing
  it does not close the editor.
- Catalog entries whose authored zone type is `brief` suppress minimap capture,
  display, staging, and export. No filename heuristic is used.
- The former middle minimap size is now the smallest/default size. The former
  largest remains available and a new 910 x 980 level is added at 1.75 times
  its dimensions.
- Collapsed mode is a compact title bar with no map image. Holding the left
  mouse button and dragging across the minimap continuously moves camera XY.

## Validation

- Clean Qt 5.12.12 / MinGW 7.3 release build: passed.
- `--version`: `0.3.0-alpha.26`.
- `--ui-widget-check`: passed, including regenerated-source selection,
  standalone window flags/icon, widened lock action, opaque overlay repaint,
  typed grading controls, crop, and preview-transform preservation.
- Headless widget checks also cover exact three-level sizing, title-only
  collapse, and multiple camera-move events during one drag gesture.
- Focused minimap export suite: 17 passed, 0 failed.
- Map catalog suite: 8 passed, 0 failed, including case-insensitive briefing
  metadata classification.
- Runtime behavior still requires the manual checks in the tester checklist.
