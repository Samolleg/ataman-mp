# 0.5 beta foundation: database and resource authoring

Status: integrated on `main` through `0eebd4b1`; the r8 tester build was
confirmed by the user.

## Delivered foundation

- The Database Editor covers all 26 physical Evil Islands database tables and
  preserves exact source-record identity, row order, unknown fields, and
  unrelated archive members.
- Typed editing, structured value editing, clone/delete, undo/redo, change
  review, validation, XLSX interchange, native Save As/Apply publication, and
  the item/spell constructor share one transaction model.
- The Resource Browser handles active-profile and external RES archives with
  provider provenance, winning/overridden status, responsive search/filtering,
  format-aware previews, export, and reviewed Save As mutations.
- Protected `database.res` opens in the Database Editor. Established database
  resource fields open the exact winning active-profile resource without
  blocking preview/decode work.
- Cross-tool navigation preserves dock ownership, activates the correct tab,
  and raises the appropriate host window without hiding the source editor.
- Database column visibility, order, width, and freeze state persist. The
  literal `#` column is frozen by default, the active row receives a soft
  highlight, and frozen columns remain stable while the current cell changes.
- Wide-table painting and interaction no longer perform full-grid work on each
  click, context menu, or scroll step. Focused real-JMV Race Models checks and
  the complete Database Editor contract suite cover the corrected paths.

## Validation evidence

- Complete Database Editor suite: 60 passed, 13 environment-dependent skips,
  0 failures.
- Focused enlarged Race Models UI contract: 1 ms actual click handling, 82 ms
  selection path, 39 ms context-menu path, 36 ms worst cold-row path, and
  135 ms for four complete horizontal traversals in the offscreen Qt harness.
- Headless UI contract, checked Qt 5.12.12 MinGW release link, and strict tester
  package validation passed for r8.
- Interactive r8 checks were confirmed by the user.

Automated timings are regression evidence from the test harness, not universal
latency guarantees.

## Beta promotion boundary

This work is the completed database/resource-authoring foundation for 0.5. The
generated-blend terrain painter and explicit **Finalize Atlas** workflow remain
the beta promotion gate tracked in the 0.4 landscape workstream. Representative
Base/JMV mutation, reopen, preservation, and cross-tool navigation acceptance
remain required before the beta release is cut.
