# 0.2.1-alpha.11: unified state rebootstrap

Alpha.10 runtime testing validated generation-scoped saves, Main Menu reload,
transition-time deferral, and both editor/game crash-recovery cases. It also
produced two actionable failures:

- direct loader substitution into a different map loaded its terrain/objects
  while retaining the previous map's minimap, quest log, and entrances;
- the experimental generic UI visibility detour crashed `game.exe` when
  inventory or store was opened, before it emitted a state event.

Alpha.11 removes that detour. Every hot reload now reaches the engine's normal
Main Menu state and then invokes the already-proven complete New Game bootstrap
with the editor-selected zone and entrance. This reinitializes zone metadata,
player/UI state, map-table identity, and the staged MPR/MOB as one operation.

The bridge still defers during a recent transition. If the game message loop is
responsive and the transition state has remained unchanged for at least 1.5
seconds, it classifies the observed loader-less map-screen state as
`WorldMapReady` and takes the same Main Menu rebootstrap path. A real synchronous
map load owns the game thread and publishes `GameplayReady` before the queued
message can run, so it is not classified by elapsed wall time alone.

## Focused retest

1. Launch one zone, open another zone in Endurance, and hot reload. Confirm the
   minimap, quest log, entrance/player placement, music, and save identity all
   belong to the new zone.
2. Open inventory without pressing Ctrl+F5, close it, then repeat with store.
   Neither action may crash.
3. Press Ctrl+F5 while inventory is open and while store is open. Confirm the
   game returns through Main Menu and enters the staged map with initialized UI.
4. Press Ctrl+F5 from the world map/map screen. Confirm a
   `WorldMapReady` classification followed by Main Menu/New Game rebootstrap.
5. Press Ctrl+F5 during an actual map load. Confirm it runs only after the
   current loader publishes a stable state.
6. Confirm each successful reload shows an empty generation Load list and that
   normal exit still cleans temporary map/plugin/save artifacts.

Retain the run folder's `manifest.json`, `runtime.log`, and `bridge-result.log`
for any failed case. Live campaign saves and source maps must remain unchanged.
