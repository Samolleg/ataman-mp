# EI Mapper Endurance 0.3.0-alpha.18

Correction build for secondary-only map testing and Parts filtering.

## Changes

- Test Current Map and Hot Reload no longer fail because a loaded
  supplemental/Autozone-only set cannot apply a Play from Here override.
- A matching but unavailable custom spawn is ignored for that run and the
  selected normal entrance is used instead.
- Only Play from Here, Godmode, and runtime time override remain unavailable;
  their tooltip now describes that capability boundary without implying that
  the MOB itself must provide SpellAddon's lifecycle.
- `enabled` and `disabled` are exact aliases for checked and unchecked rows in
  the Bodypart visibility filter.

## Validation

- The UI widget check covers all eight checkbox state aliases.
- Full Qt 5.12.12/MinGW release build and packaged startup checks are required
  before tester handoff.
