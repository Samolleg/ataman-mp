# EI Mapper Endurance 0.3.0-alpha.15

Focused Parts-editor usability and canonical humanoid-option build.

## Changes

- Filter by part name, source, and enabled state. State aliases include
  `true`, `false`, `checked`, `unchecked`, `on`, and `off`.
- Click Part, Enabled, or Source headers to sort.
- Distinguish `Serialized`, `Model option`, and `Unknown serialized` rows.
- Expose canonical wearable-humanoid anatomy such as `hr` even when a malformed
  object omitted it and its currently resolved assembly does not advertise it.
- Remember the Bodypart visibility window size.
- Preserve the complete body-part property when copying through the general
  property clipboard.

## Validation

- Full Qt 5.12.12/MinGW release build and runtime-component rebuild passed.
- `--ui-widget-check` passed state/source filtering, sorting, unknown-source,
  canonical `hr`, exact-array, duplicate, and no-op preservation checks.
- `zone3obrtest1.mob` is byte-identical to original `zone3obr.mob` after a
  no-change Parts Apply; both hashes are
  `F3F15E3A5DADD1ED52966DB94EFAB32D5E1780C2501FABC4C6B47E52CC3C7DC5`.
- `zone3obrtest1.mob` also passes byte-identical `--roundtrip-check`.
