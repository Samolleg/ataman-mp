# EI Mapper Endurance 0.3.0-alpha.17

Correction build for secondary-only map testing and Parts filtering.

## Changes

- Keep Test Current Map available for mapped compositions whose staged MOB is
  a supplemental `PR_OBJECT_DB_FILE`/Autozone MOB.
- Disable only the features that require SpellAddon's autorun-MOB lifecycle:
  Play from Here, Godmode, and the runtime time override.
- Continue preferring a map.txt filename match or one unique structural primary
  when selecting the staged MOB. Otherwise use the explicitly active MOB, so
  copied and secondary-only compositions remain testable.
- Read checkbox filtering state from the sortable table model rather than its
  embedded widget. `checked`, `true`, `on`, `unchecked`, `false`, and `off`
  now remain reliable after sorting.

## Validation

- `--ui-widget-check` covers every checkbox state alias.
- Full Qt 5.12.12/MinGW release build passed.
