# 0.3.0-alpha.1 — Current tester build

This package updates the integrated landscape and particle-catalog test line
through main commit `413957b`.

## Latest workflow changes

- Creating a collection now asks whether to load it immediately after it is
  saved. Declining leaves the current workspace unchanged.
- The redundant **Activate Selected Object's MOB** View-menu command and
  Ctrl+T shortcut were removed. Use the persistent **Loaded Map** panel to
  switch the active MOB.
- **Open Last Session** now preserves whether the workspace came from a catalog
  map or collection instead of reopening it as an anonymous loose-file set.
- Catalog zone ID, collection path/name, and collection map mapping survive a
  clean restart. Older session files remain compatible and load as loose
  workspaces.
- The main title now shows the active catalog map or collection identity beside
  the editing profile and active MPR/MOB.
- The bottom viewport help no longer advertises Ctrl+T.

## Included test content

- Integrated landscape sculpting, heightmap import, terrain painting, MPR
  Save As safety, and map-table catalog editing.
- Portable 7x5 particle catalog collection.
- Empty/half/quarter/row particle runtime bisection collections based on the
  same canonical 7x5 terrain.

## Safety boundary

Changed MPRs still cannot overwrite their currently open source. Save to a
separate test filename, reopen that copy, and use **Test Current Map**.

The package contains no Endurance settings, workflow/runtime logs, saves,
crash dumps, live game files, or private installation paths.
