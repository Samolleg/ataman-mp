# 0.2.1-alpha.3 runtime validation

This build addresses the alpha.2 ground-height regression, explicit collection
MOB loading, and hot reload's attempt to replace a map file held open by JMV.
No source or installed map is modified.

## Ground and custom spawn

1. Launch `gz1g` through entrance 2 and confirm the player starts on the ground
   and can move immediately.
2. Repeat through another ordinary entrance. Endurance must not apply a second
   scripted teleport for an entrance start.
3. Place **Play from Here** on open terrain and launch. Confirm the player is on
   the ground. The bootstrap tries the custom position immediately and repeats
   it after JMV's two-second leader-registration delay as a compatibility
   fallback; report whether any visible entrance-first frame remains.

## Collection MOBs

1. Open a collection containing the primary `zone1.mob` followed by the edited
   `Autozone1cyclopus.mob`.
2. Launch regardless of campaign quest state and confirm the unique Cyclopus
   test content appears exactly once.
3. Check `bridge-result.log` for `SUPPLEMENTAL_MOB redirect` and the manifest's
   `explicitSupplementalMobs` list.

## Hot reload

1. While the Endurance-owned JMV process is running, make one disposable edit
   to the primary MOB and press Ctrl+F5.
2. Confirm there is no access-denied dialog and the game reloads the map.
3. Repeat with one MPR change and one supplemental-MOB change if available.
4. Exit normally and confirm all `ed*.mpr`/`ed*.mob` files owned by the run are
   removed from the JMV Maps directory. Reload generations remain in the run
   log directory as diagnostic evidence.
