# EI Mapper Endurance 0.3.0-alpha.20 — minimap viewport and export fixes

## Changelist

- Adds a game-style minimap widget in the viewport's upper-right corner. It can
  be minimized or expanded and switches explicitly between a generated preview
  and an embedded profile texture when that texture can actually be resolved.
- Defaults to Embedded when available. Generated mode is selected automatically
  when no embedded texture exists and is regenerated after loaded-map, MOB, or
  committed terrain changes with a short debounce.
- Automatically stages Generated mode for the next initial JMV Test Current Map.
  The run-owned RES and private map table use a run-unique texture name so an
  identically named member in installed textures.res cannot shadow the preview.
- Renames Generate Minimap to Export Minimap. The viewport widget provides the
  shortcut and the export dialog remains the reviewed mutation boundary.
- Removes the context-help question mark from the export window. Its 256x256
  preview now fits the available area and supports wheel zoom, drag pan, Fit,
  and 100% controls.
- Selecting a destination archive no longer displays a native overwrite prompt.
  Texture replacement confirmation occurs only after Export is pressed and the
  selected RES has been inspected.
- Fixes append validation for RES archives whose hash-table order changes after
  adding a differently named texture. Untouched members are matched by unique,
  case-folded name and still require byte-identical payloads and timestamps.
- Shows application-modal progress while inspecting, rebuilding, validating,
  backing up, and publishing minimap or map-catalog RES operations.
- Clarifies that a minimap saved only in an editor-local RES cannot be viewed as
  Embedded until that archive belongs to the active resource profile.

## Automated validation

- Focused synthetic minimap/export tests cover RES hash-table reordering and
  deterministic run-unique temporary texture names in addition to the alpha.19
  capture, encoding, archive, catalog, failure-preservation, and staging cases.
- The non-interactive widget suite checks Embedded default selection and the
  Generated/Embedded source switch.
- Qt 5.12.12 / MinGW 7.3 clean release build uses the documented ASCII `subst`
  path and rebuilds both 32-bit runtime components.

## Manual acceptance cases

1. Open a copied registered collection. Confirm the upper-right minimap defaults
   to Embedded when its MMP resolves; switch to Generated, then minimize and
   expand it. Edit terrain and move a static object and confirm regeneration.
2. Open an MPR whose embedded minimap cannot be resolved. Confirm Generated is
   selected, the incomplete warning appears for MPR-only composition, and Test
   Current Map stages the generated image without an explicit queue button.
3. In Export Minimap, resize the window, use Fit, 100%, wheel zoom, and drag pan.
   Confirm there is no title-bar question mark and the image fills the available
   preview area while keeping its aspect ratio.
4. Browse to an existing copied RES. Confirm browsing alone does not ask to
   replace it. Press Export with a unique member name and confirm append succeeds;
   repeat with an existing name and confirm replacement is asked only then.
5. Append a second differently named minimap to a disposable RES that already
   contains the first. Confirm staged reopen succeeds and both members reopen
   with their original bytes.
6. Export to a large copied textures.res and save a copied texts.res. Confirm a
   blocking progress window remains visible throughout each RES operation.
7. Select Generated and start an initial JMV Test Current Map. Confirm the run
   log reports an `eimmap_` texture name, the generated image appears in game,
   and cleanup removes only the run-owned RES and private map-table artifacts.
8. Select Embedded and repeat. Confirm no generated override is staged and the
   active profile's embedded minimap is used.

## Private runtime validation still required

The game-visible generated preview and resource-precedence correction require a
controlled JMV run against hash-recorded copies. Large proprietary textures.res
timing also remains a private gate. Do not install or edit a live archive while
performing either check.
