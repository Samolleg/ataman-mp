# EI Mapper: Endurance Edition 0.2.1-alpha.15

This closed-test build makes each JMV test-run outcome machine-readable and
keeps post-test warnings visible without interrupting editor work.

## Changes

- Write `result.json` after the owned game process exits and guarded cleanup
  finishes.
- Correlate runtime-observed MPR/MOB loader paths with the hash-verified staged
  payload and report zone, entrance, generation, save namespace, player
  initialization evidence, source preservation, exit reason, and cleanup.
- Distinguish **Stop Test** from an unexpected crash-status exit.
- Show warnings and errors in a non-modal bottom-right notification with
  **Open Log** and **Dismiss** actions. It closes automatically after nine
  seconds when untouched; successful runs remain log-only.
- Add `--test-run-report <run-root>` and optional `--json` output for automated
  review of a completed run.
- Persist Maps/Collections browser expansion, provide optional Open Last Session
  on startup, restore the intended first-run dock layout, and correct disabled
  menu-item alignment.

## Automated validation

- Launcher result tests cover a verified run, a wrong-zone result, loaded
  payload hash correlation, and persisted-result analysis.
- The headless command validates deterministic runtime evidence without opening
  an editor window or modifying the game installation.

The final release matrix still needs representative live JMV runs. Rendering,
traversal, `drawall`, and in-game Save/Load remain manual checks; their runtime
identity, staging, source preservation, exit, and cleanup evidence is now
collected automatically.
