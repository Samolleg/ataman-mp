# EI Mapper: Endurance Edition 0.3.0-alpha.8

## Synthetic gameplay identity

- Unmapped MPR/MOB tests now stage a complete private `game` record instead of
  omitting `#maps`.
- The record uses the loaded MPR dimensions, the built-in `battle00` interface
  texture as a temporary minimap/objectives placeholder, and the selected Play
  from Here position as its only deploy entrance.
- No installed `map.txt`, texture archive, MPR, MOB, or GRP is modified.
- Generated AI graphs are recorded as owned staged artifacts and no longer
  produce a false source-integrity failure after cleanup.

## Particle catalog responsiveness

- Persistent ZoneExit, PortalStar, and Portal previews now start from bounded
  logical warm-up windows instead of replaying epoch-sized tick histories.
- This removes the GUI-thread freeze when opening the complete 83-object
  particle catalog without changing the intended steady-state preview.

## Focused validation

- The staged `texts.res` is freshly reopened and checked for one exact
  synthetic zone, dimensions, both placeholder names, and its deploy entrance.
- `res_archive_document_tests` verifies lossless preservation of every archive
  member other than `map.txt`.
- `particle_animation_tests` covers epoch-sized cold starts for all three
  affected emitters.

Runtime confirmation against the `00-empty-control` collection is still
required.
