# EI Mapper: Endurance Edition 0.2.1-alpha.24

Tester candidate combining the reviewed render-pipeline integration through
`191ac85` with an autosave live-cadence correction.

- Adds profile/database-driven humanoid visuals, equipment and idle animation.
- Adds render batching, pacing controls, cached vertex input and preparation.
- Fixes uncompressed MMP texture decoding used by affected creature textures.
- Applies changed autosave enabled/interval settings to the running timer
  immediately when Settings is applied; restart is no longer required.
- Retains alpha.23 autosave scheduling, generation deduplication and safe
  shutdown handling.

Focused tester checks:

1. With a dirty MOB, change autosave from 5 minutes to 1 and press Apply.
2. Confirm a scheduler line immediately reports `intervalMinutes:1` and the
   next tick occurs one minute later.
3. Change it back to 5 and confirm the next tick is rescheduled, not inherited
   from the previous one-minute timer.
4. Run the existing JMV hot-reload matrix; runtime bridge behavior is unchanged.
