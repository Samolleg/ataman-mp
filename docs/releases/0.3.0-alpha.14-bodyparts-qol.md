# EI Mapper Endurance 0.3.0-alpha.14

Focused closed-test build for MOB Parts preservation and workspace QoL.

## Changes

- Parts now displays and preserves every serialized body-part token, including
  `hr`, unknown/profile-future tokens, original order, and duplicates.
- Parts Copy/Paste uses the complete underlying array rather than only visible
  rows. A display-only filter makes long lists searchable.
- Applying Parts without a change no longer rebuilds the raw list.
- Renamed primary test MOBs overlay the installed catalog primary during family
  validation instead of being collision-checked against their own source map.
- Duplicate Map as Collection now offers to open the created collection.
- Loaded Map MOB context menus include Parameters, Script, Save, and Save As;
  Save is enabled only while that MOB is dirty.

## Validation

- Full Qt 5.12.12/MinGW release build and x86 runtime-component rebuild passed.
- `--ui-widget-check` passed, including exact Parts array/order/duplicate and
  display-only filtering regressions.
- Focused MOB family validation tests passed, including the renamed-primary
  overlay fixture.
- Supplied `zone3obrtest2.mob` passed structural validation and byte-identical
  round-trip checking. The artifact confirms the old bug; it is not silently
  repaired by this build.
