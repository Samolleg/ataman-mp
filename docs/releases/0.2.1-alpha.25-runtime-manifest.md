# EI Mapper: Endurance Edition 0.2.1-alpha.25

Closed-test candidate narrowing JMV direct-launch compatibility to the code
surface Endurance actually hooks.

- Only the exact supported Starter `game.exe` is a bridge manifest gate.
- Starter addon.dll, SpellAddonX.asi, JMV addon.dll, mutable Lua, and
  SpellAddon configuration no longer block editor discovery or Test Current
  Map.
- JMV addon.dll remains mod-owned gameplay code and may change independently.
- Play from Here, Godmode, and explicit supplemental-MOB bootstrap continue to
  use the temporary `AutoRunSpellAddon123.mob` convention. Their success is
  runtime evidence, not a global ASI-version requirement.
- Validation navigation can load an unloaded source MOB before selecting its
  proven object.
- The entrance/spawn OpenGL overlay clears inherited VAO/VBO vertex attributes
  before drawing, preventing the supplied NVIDIA driver access violation.

Focused checks:

1. Configure the JMV profile from the game root and confirm Test Current Map is
   available when the supported Starter game.exe is present, regardless of
   JMV addon.dll revision.
2. Launch an ordinary entrance test, then exercise Play from Here, Godmode, and
   a supplemental AddMob collection separately.
3. Open a validation finding whose source MOB is unloaded and select it.
4. Exercise entrance overlays on an NVIDIA system and confirm selection and
   launch do not crash.

Test Current Map remains an optional profile capability. Other mods and Starter
versions may receive post-1.0 runtime plugins only when their authors request
and validate support.
