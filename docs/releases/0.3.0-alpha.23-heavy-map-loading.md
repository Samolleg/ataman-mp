# EI Mapper Endurance 0.3.0-alpha.23 — heavy-map loading test

- Off-screen unit visuals no longer block the loading dialog.
- Repeated object geometry reuses an exact immutable assembly cache.
- Map loading reuses the Maps and Collections catalog snapshot.
- Workflow logs record complete MOB and mapped-workspace elapsed times.
