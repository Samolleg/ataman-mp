# EI Mapper: Endurance Edition 0.3.0-alpha.4

This closed-test build corrects the synthetic-map bootstrap introduced in
alpha.3. Runtime logs showed unmapped tests reaching `MainMenuReady` but never
invoking the New Game bootstrap, while a mapped control continued normally.

The bridge had been searching every process heap for the borrowed bootstrap
zone record on the game thread. Those heap locks could wait on engine worker
allocations and stall the process. The search is replaced by the supported
runtime variant's fingerprinted, byte-guarded map-table lookup. The returned
record is still structurally validated before Endurance applies a temporary
identity, dimensions, empty minimap metadata, and one entrance.

No installed map table or game data is modified. Manual runtime confirmation is
required with the empty particle control before the synthetic path is treated
as accepted.
