# 0.2.1-alpha.23 Autosave scheduler

Alpha.22 registered and persisted the autosave settings, but tester logs showed
that applying a one-minute cadence did not reschedule the already running
five-minute timer and no tick was recorded.

Alpha.23 uses a dedicated Settings Applied notification, logs the scheduled and
fired timer state, and adds **Autosave Now** and **Open Backup Folder** to
Settings > General. Autosave Now runs the exact same validated candidate and
versioned-backup path as the periodic timer.

The supplied alpha.22 logs also showed that Windows could destroy the viewport
surface before Qt tore down its remaining OpenGL members. Alpha.23 avoids that
unsafe destructor path during final process shutdown.
