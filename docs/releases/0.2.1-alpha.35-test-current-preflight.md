# 0.2.1-alpha.35 — Test Current Map preflight

This focused test build fixes two failures observed in alpha.34.

- JMV Test Current Map now compares the selected Endurance mod root with
  Starter's persisted `AddonPath` before staging. A mismatch shows both paths
  and refuses to launch instead of silently mixing another mod's menu,
  resources, or runtime components with the staged map.
- The initial New Game bootstrap now installs its game-thread message hook
  using the documented same-process form. The previous bridge-module form is
  retained as a fallback. A complete failure logs both Windows error codes and
  the target thread ID.

Starter may cache the active mod before the run-local bridge can virtualize
all consumers. Endurance therefore does not claim that a late process-local
registry override can replace correct Starter selection. It also does not
modify the user's Starter configuration or registry values.

## Focused test

1. Leave Starter on a mod other than the selected Endurance profile and press
   Test Current Map. Confirm Endurance refuses before launching and displays
   both paths.
2. Select the profile's mod in Starter and launch it once, close the game, and
   retry. Confirm the game proceeds from the menu lifecycle into the staged
   map.
3. Confirm `DIRECT_LAUNCH queued ... hook_module=process-local` appears in the
   test runtime log. If both methods fail, retain the log containing
   `local_error`, `module_error`, and `thread`.
