# EI Mapper Endurance 0.3.0-alpha.22

- Added a compact, persistent open/closed-eye visibility toggle beside the
  map-entrance selector.
- Hiding entrance overlays affects only their viewport areas and labels. The
  selected entrance, Test Current Map spawn, and Play from Here marker remain
  unchanged.
- Viewport overlay controls now own pointer input across their complete surface,
  so clicking labels or blank panel space cannot select objects underneath.
- Viewport overlays now repaint an opaque complete backing surface and invalidate
  both their old and new viewport regions when moved, resized, shown, or hidden.
  This prevents stale OpenGL/title/image fragments after changing widget size.
