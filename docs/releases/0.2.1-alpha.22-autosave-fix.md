# 0.2.1-alpha.22 Autosave activation fix

Alpha.21 displayed the new autosave controls but omitted their option names from
the General settings-category resource. The values were therefore neither
registered nor persisted, and the autosave timer remained disabled.

Alpha.22 binds and persists both settings, adds a UI regression check, and is
produced from a clean build so the runtime version agrees with the package.

## Focused check

1. Set the autosave interval to one minute and Apply.
2. Make a supported MOB edit without saving.
3. After one minute, confirm the workflow log records an autosave pass and the
   status bar reports a new recovery generation.
4. Close without saving and restart; Endurance should offer the recovery copy.
