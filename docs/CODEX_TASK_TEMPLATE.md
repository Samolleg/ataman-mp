# Задание для Codex соавтора

Заполните поля перед отправкой. Неотмеченные полномочия не подразумеваются.
Документ можно скопировать в новое сообщение Codex; открытие этого файла само
по себе не является поручением выполнять пример. Если конкретная задача ещё
не выбрана, поручите только проверку окружения и чтение документов.

```text
Работай в проекте EI Mapper Ataman, приватный репозиторий Samolleg/ataman-mp.
Корень моего checkout: <абсолютный путь на МОЁМ компьютере>.
Прочитай AGENTS.md, CONTRIBUTING.md, ROADMAP.md, docs/COAUTHOR_HANDOFF.md,
docs/PROJECT_CONTRACT.md и docs/TEST_BUILD_HANDOFF.md.

Основная задача и ID: <ID существующего пункта либо новый согласованный ID>.
Исходная проблема: <что происходит, шаги, карта/профиль, ссылка на свидетельство>.
Ожидаемый полный результат: <что пользователь сможет сделать>.
Критерии завершения: <воспроизведение, регресс, ручные/игровые проверки>.
Границы: <затрагиваемые области и файлы; что остаётся вне этой задачи>.

База: <полный SHA очищенной линии, согласованный с сопровождающим>.
Работай только в main от проверенной базы; новые рабочие ветки не создавай.
Не импортируй исходную неочищенную историю владельца или более новый Endurance.
Проверь путь, HEAD, VERSION, remotes и незакоммиченные файлы до изменений.
Исторические SHA и абсолютные пути в старых отчётах не подставляй как мои.

Разрешаю: <например: код в указанной области, необходимые тесты,
локальный scoped-коммит; явно укажи, нужна ли сборка>.
Сетевые действия: <без сетевых действий / только clone или fetch указанного
репозитория / отправить согласованный результат в GitHub main>.
«Сделай коммит» означает scoped-коммит в main; «отправь на GitHub» означает
обновить GitHub main. Отдельное разрешение на интеграцию не требуется.
Установка зависимостей: <не разрешена / конкретный согласованный набор и путь>.
Получение/копирование игровых данных для тестов: <не разрешено / точные пути,
источники и отдельная папка копий>. Изменяющие тесты — только на этих копиях.
Живые карты, мод и установку игры не изменяй без отдельного разрешения.
Сборка/передача: <не нужна / подготовить по docs/TEST_BUILD_HANDOFF.md>.
Путь к моей постоянной установке: <по умолчанию artifacts/
EI-Mapper-Ataman-2-first-test относительно моего checkout либо согласованный путь>.

Сначала воспроизведи дефект и найди первое неверное значение/состояние.
Для новой функции определи проверяемое поведение. Сохраняй чужие правки,
не переноси приватные ресурсы/код, сборки, JSON настроек, логи и секреты в Git.
Не убирай и не ослабляй проверки ради PASS; отсутствующий fixture, SKIP,
timeout, ошибка сборки/запуска — отдельный пробел доказательств.

Веди основной пункт ROADMAP и связанные дефекты; не сужай цель до последнего
симптома. Для отдельной правки/функции согласуй следующий VERSION по AGENTS.md,
обнови CHANGELOG; для одних документов/повторной сборки номер не увеличивай.
Не создавай новые чаты или подагентов без моего явного поручения.
Не открывай редактор/игру вместо меня для ручной приёмки.

В итоге сообщи причины, изменения, исходный случай и регрессы с exit code,
пропуски/нестабильные результаты, ветку, полный SHA, VERSION и следующий шаг.
Для сборки сообщи точный путь и результаты упаковки; не выдавай сборку или
автоматический тест за проверку работы в игре. Ручные пробелы укажи явно.
```

Сопровождающий и соавтор согласуют спорный объём задания до зависимых действий.
Чтение документов, проверка локального статуса и подготовка плана не требуют
повторного подтверждения уже полученного поручения. Доступ GitHub и одно
предыдущее разрешение на публикацию не означают автоматический push при каждом
коммите. Поручение «отправь на GitHub» уже разрешает обновление main.
