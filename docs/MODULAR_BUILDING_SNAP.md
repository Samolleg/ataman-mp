# Стыковка деталей зданий — Ataman 92

Первый этап предназначен для жёстких модулей архитектуры. Маппер совмещает
заданные стыки двух деталей и записывает обычные положение/поворот в MOB.
Никаких новых игровых полей или обязательной связи между объектами не появляется.

## Подготовка модели

1. Откройте витрину из создания объекта или его свойств, выберите модель,
   нажмите «Точки стыковки…».
2. Нажмите «Добавить», задайте понятное название и тип соединения.
3. Поставьте точку ЛКМ на поверхность модели. Уточните её X/Y/Z численно,
   если стык должен находиться между вершинами или за пределами поверхности.
   ПКМ или средняя кнопка вращает вид, колесо приближает его.
4. «Направление» — вектор наружу из соединяемой поверхности; «Верх» задаёт
   ориентацию детали вокруг направления. На обычной вертикальной стене верх
   равен `(0, 0, 1)`, направления левого/правого стыков — `(-1, 0, 0)` и `(1, 0, 0)`.
   Для горизонтального стыка направление можно задать `(0, 0, 1)`, верх — `(0, 1, 0)`.
   Нулевые или параллельные направление/верх не сохраняются.
5. Нажмите «Сохранить стыки». Отмена/Esc сохраняет прежний каталог.

Точки задаются относительно начала модели, в тех же координатах, что её
геометрия в маппере. Это не координаты карты. Тип можно вписать самостоятельно,
например `wall-4m` или `roof-edge`. Совмещаются только полностью одинаковые типы.
Название служит подписью и не влияет на совместимость.

## Размещение

Магнит не соединяет произвольные поверхности автоматически. У обеих моделей
должны быть сохранённые совместимые точки стыковки. Одно включение кнопки без
выделенной детали и перемещения ничего не переносит. Под кнопкой выбора стыка
показан следующий шаг или причина отсутствия захвата; список доступен только
во время перемещения детали с заданными стыками.

1. Создайте деталь или выделите одну существующую деталь и включите магнит
   на нижней панели. Начните перемещение `G`.
2. Подведите её стык к стыку размещённой детали. Деталь совмещается с ним:
   точки совпадают, направления смотрят друг на друга, верх согласован.
   Голубое превью означает свободное перемещение, жёлтое — захваченный стык.
3. При необходимости выберите исходный стык в списке рядом с магнитом.
   `Tab` или кнопка следующего варианта переключает доступные пары соединений.
4. ЛКМ подтверждает размещение. `Esc` возвращает прежнюю позицию и поворот;
   при создании удаляет неподтверждённую деталь. Одна Undo/Redo возвращает обе
   трансформации, а для нового объекта — отменяет/повторяет всё создание.
5. Сохраните MOB обычной командой. Стыки остаются редакторскими данными каталога.

Индекс доступных объектов сцены строится один раз при начале перемещения.
Кандидаты находятся рядом в XY и в пределах экранного радиуса захвата;
уже выбранная пара удерживается в большем радиусе, чтобы не прыгать между
соседними соединениями. Загруженные видимые соседние карты учитываются с
их смещением относительно активной карты. Незагруженные объекты не сканируются.

## Каталог и ограничения

Стыки хранятся в `model-catalog.json` рядом с `database.res` активного профиля,
в записи модели `models.<model-id>.connections`, вместе с её названием.
Существующие названия, категории, текстуры и неизвестные дополнительные поля
сохраняются. Некорректный или изменённый извне JSON не перезаписывается молча.

Пример поля `connections`:

```json
[
  {
    "id": "wall-right",
    "label": "Правый край",
    "type": "wall-4m",
    "position": [2, 0, 1],
    "normal": [1, 0, 0],
    "up": [0, 0, 1]
  }
]
```

Текущий этап перемещает одну деталь. Постоянные сборки/группы, шаблоны зданий
и импорт Blender-маркеров пока не реализованы. Точки не деформируются вместе
с изменяемыми параметрами FIG8 и анимацией: используйте жёсткие модули с
одинаковой геометрией вариантов. Полупрозрачное превью использует загруженную
геометрию; при её отсутствии или размере более 120000 вершин сохраняется
обычное отображение выбранного объекта. Сам магнит остаётся доступным.

Реальные Blender-модули и их экспортные оси требуют ручной приёмки владельца.
Автоматические проверки на временном MOB не заменяют её.
