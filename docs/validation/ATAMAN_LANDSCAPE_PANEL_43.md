# EI-LANDSCAPE-PANEL — 2026-09-20

Ветка codex/landscape-panel-v43, база установленной42. Пользователь разрешил
переработку панели по предложенной схеме и добавление иконок.

Причина растянутого скульпта: внешний QVBoxLayout растягивал обычные строки,
когда скрывалась единственная расширяемая область палитры. Теперь в режиме
скульпта свободную высоту получает нижняя пустая область, параметры компактны.
В рисовании параметры кисти перенесены выше палитры; палитра расширяется.
Общие действия в одной строке; подробный статус в подсказке выбора карт,
в кнопке видны включение и число карт. Дополнительно/Диагностика/Справка
сворачиваются. Все прежние действия и сигналы сохранены.
Иконки рисуются QPainter при двойном разрешении; внешние ресурсы не нужны.

Native UI-check адаптирован к новому порядку кисти/палитры и расширен проверкой
5 режимов при320x700,320x1200,600x1000, раскрытия диагностики и наличия иконок.
Снимки проверяемых режимов собираются только по EI_LANDSCAPE_SCREENSHOTS.
Результаты сборки, тестов, просмотра и установки будут записаны ниже.

Алгоритмы кисти/сохранения не менялись; открытые SWAMP и SWITCH-ATLAS
не закрываются переработкой панели. Пользовательский DPI/игровая работа
остаются отдельной ручной приёмкой.
