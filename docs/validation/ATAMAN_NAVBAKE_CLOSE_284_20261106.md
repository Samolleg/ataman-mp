2. Вопрос показывает последнюю начатую карту, завершённые карты/общее количество,
   профили текущей карты и очередь. До первого MAP_BEGIN честно указано, что карта
   ещё не начата; неизвестное количество не выдаётся за известное.
   Текст обновляется каждые100мс. «Дождаться» — default и Escape; Esc и закрытие
   диалога дают тот же результат. Закрытие отменяется, процесс и очередь продолжаются.
   «Прервать и закрыть» вызывает общий путь отмены панели, затем обычное закрытие.
   Когда процесс и очередь закончились при открытом вопросе, итог принимается
   обычным обработчиком, вопрос закрывается и обычное закрытие продолжается.
3. Отдельный полный текстовый журнал сохраняет строки сверх2000 UI-блоков.
   Общие drain/flush/save дочитывают stdout и stderr, включая остатки без LF.
   Прерывание добавляет причину, последнюю карту и число пройденных карт;
   отменённая очередь тоже перечисляется. Очередь после уже завершённого пакета
   получает отдельный отчёт, прежний успешный bake.log сохраняется побайтно.
   После успешного QSaveFile::commit флаг запрещает повторную запись.
   Отказ запуска также оставляет журнал. Ошибка записи сообщается в workflow.
4. Деструктор сохраняет защиту269: сначала блокирует сигналы панели и отключает
   QProcess/watchers, затем прерывает/дочитывает/сохраняет без обращения к виджетам,
   QSettings, contentChanged и разметке. Ожидание terminate2000мс, затем kill3000мс;
   если процесс всё ещё работает, это явно добавляется в журнал. Эта ветвь таймаута
   проверена по коду; отказ Windows выполнить kill специально не имитировался.
5. Workflow получает `Shutdown NavBake source:... decision:...`, карту и прогресс
   при запросе и решении. Поддержаны наблюдаемые Windows SC_CLOSE, событие
   application Quit, shutdown_headless и Windows session. SC_CLOSE означает
   системную команду (также Alt+F4/меню), а не доказанный клик по крестику.
   Обычный closeEvent не раскрывает вызывающего — там пишется unknown.
   Перехват Quit выделен в отдельный фильтр; прежний фильтр виджетов не менялся.
   Ни120-секундное ожидание background tasks, ни финальный teardown deadline не

атомарна отдельно, общей транзакции пакета/карты и автоматического отката нет.

отдельного опубликованного файла. Диалог прямо предупреждает об этом и предлагает
перед использованием заново запечь весь мод; прежние версии находятся в бэкапах.

Приватный исходный код не копировался ни в checkout, ни в Git, ни в комплект;
