## Исправление

`CUnit::setConstitution` теперь переопределён: сохраняет новое значение, инвалидирует только производный вид НПС и сохраняет последнюю полную экипированную сборку до готовности рендера. Не вызывает обычный `CObjectBase::recalcFigure`, который заменял разрешённые вещи сериализованной MOB-маской. Вне OpenGL-контекста не загружает текстуры/геометрию. Несколько входящих mouse deltas до кадра объединяются состоянием модели.

Общий вектор и три поля COMPLECTION_X/Y/Z в CUnit::applyParam проходят через тот же setter. Прямой вызов CView::scaleTo, числовая операция по оси и отмена используют виртуальный setter автоматически. В декларативном фильтре visual properties добавлены X/Y/Z, фильтрация позиционных/неотносящихся свойств сохранена.

После масштабирования сбрасывается признак последнего применённого анимационного кадра и статической позы: новые CPart получают правильную позу даже при том же logicalFrame. Клип, его fingerprint, clock, выбор оружия и серийные списки вещей не меняются. Существующий путь CharacterVisual вычисляет форму, иерархию, UV/материалы и проекцию на рельеф. Инвалидация всей базы/кэша на mouse event не добавлялась. Обычные объекты продолжают прежний немедленный rebuild.

## Неуспешные подготовительные прогоны

1. Первое ожидание шлема/оружия проверялось ошибочно через renderedBodyPartUvTriangles: этот helper намеренно исключает части с отдельными текстурами. Оснастка исправлена на реальные draw-parts. Первая компиляция дополнительного provider-запроса имела неверный namespace; исправлено только в тесте.
2. Добавление MPR в оснастку без attachLandscapeTools привело к AV до чтения NPC и в188, и в189. Подключена обязательная панель, последующие прогоны до исходного дефекта и до завершения прошли. Это не PASS и не исправление production из-за тестового AV.
3. Анимационный эталон первоначально получил другой NID (JSON-конструктор по дизайну не копирует mapId), а Qt processEvents при ожидании composite менял глобальные часы. Эталон теперь имеет исходный NID, время устанавливается перед каждым preload; сравнения формы и позы PASS.
4. Первая полная сверка Save/reopen использовала QHash по NID и путала legacy узлы без уникального серийного NID. Итоговая проверка сопоставляет каждый объект по исходному порядку и сравнивает полное JSON; все2025 совпадают. Правила ID и serializer не менялись.
