## Причина и проверка

В установленном229 (`build-ai-panel-229/source-final/source/ui/navmesh_panel.cpp:143`)
и текущем230 (`source/ui/navmesh_panel.cpp:189`) команда передаёт --game-root,
--mod, --output-root и --map/--mob либо --all, но не --report-root.
Новый запекатель требует `--report-root PRIVATE_DIR`.

1. Настоящий установленный запекатель вызван для DejaVu/zone1 с теми же
   параметрами, что маппер, кроме безопасного отдельного --output-root:
   **exit2**, stderr содержит Usage с обязательным --report-root.
   Обработка карты ещё не начинается.
   [Квитанция](../../build-bake-code2-audit-20261028/without-report.json).
2. Добавление только --report-root с отдельным каталогом отчётов устраняет
   отказ параметров: начинается обработка zone1, BAKE_BEGIN algorithm=21.
   Через25508мс процесс завершается **exit4**:
   `MAP_ERROR ... reason=Nav64: route-to-step release quality failures=4`;
   `BAKE_DONE maps=1 completed=0 missing=0 errors=1 skipped=0`.
   Это самостоятельный следующий блокер, а не успешное запекание.
   [Полный вывод](../../build-bake-code2-audit-20261028/with-report.json).
3. Чтец230 допускает только8/9/10 (`nav64SupportedAlgorithms()`);
   поддержка нового21 не подтверждена и простое расширение списка не является
   проверкой совместимости. Исправление одного запуска недостаточно.
