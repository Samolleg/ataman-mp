# Исправление разреженных покрытий на стыках карт121

Задача `EI-WORLD-OVERLAY-SEAM-FIX-121`, поручение владельца2026-10-06
«ИСПРАВЛЯЙ». Продолжает аудит отказа120 и материальные швы119.
База main `eb31ce00a3cfb31de3d00301a79d1c22a332c82a`, версия120→121.
Scoped-коммит реализации main `3f90d32a58bb589c07b5c15ca347dfc59dd20484`.
Разрешены код, проверки, локальный scoped-коммит, обычная сборка и обновление
единственной постоянной установки. Публикация и ZIP не запрошены.

## Причина и исправление

В119 отсутствующее покрытие ошибочно включалось в физический рисунок общего
стыка. В zone1:175,0 создавалась команда before0→after910 при available=false.
Защита `CTerrainEditModel::apply` правильно отказывала с overlay_inactive;
атомарность отменяла всю группу из восьми карт. Журналы и native воспроизведение
зафиксированы в [аудите120](ATAMAN_WORLD_TRANSITION_REFUSAL_AUDIT_120_20261006.md).

- `world_material_boundary.h` проверяет отдельный флаг наличия клетки с обеих
  сторон. Отсутствующая поверхность больше не даёт ни общего физического края,
  ни собственного семантического ребра. Материалы соседней воды не заполняют
  углы без собственного покрытия. Списки исправляемых клеток содержат только
  существующие клетки. Действующий atlas slot0 сохраняется.
- `view_world_terrain.cpp` повторяет проверку наличия перед сбором материалов
  общего рисунка и перед физической командой. Отказ подготовки команды/рисунка
  дополнен именем карты и слоем. Проверка overlay_inactive и общая атомарная
  транзакция сохранены.
- Opt-in native проверка теперь может прочитать действующий `deja-vu/gipat`
  из world-map-layouts.json без его записи, включить исходную группу из восьми
  карт и проверить маску поверхностей, пустые семантические вершины, точные
  состояния Undo/Redo и повторную операцию. Это проверка публичного кода маппера;
  приватный движок не использован.

Синтетические случаи проверяют type1 против type3, отсутствующее покрытие с
тем же packed0, что и действующий slot0, разрывы присутствующих поверхностей,
одностороннюю воду и неизвестные вершины; результат согласования не зависит
от порядка карт. Прямая команда на пустое покрытие по-прежнему отклоняется
без изменения сектора. Пять SKIP — optional installed-data варианты unit
набора; реальные карты отдельно читаются native проверкой release EXE.

Во всех пяти native прогонах подтверждены сохранность маски покрытий/пустых вершин,
runtime типов, исходных authored pixels и внутренних клеток соседей;
точная отмена/повтор восстановили секторные байты, оба текущих и базовых поля
материалов и каждый атлас. Повторное исправление не меняет эти состояния.
Все восемь MPR и их атласы сериализуются и открываются снова в памяти.
Исходные MPR и world-map-layouts.json имеют прежние SHA до/после. В паре4/6
после сохранения и чтения игровых DXT1 MMP обе общие кромки имеют0 pixel
mismatches. Native всего429 PASS /0 FAIL, без таймаута.

Общий UI тест не начался: native clipboard guard120 отказал безопасному
сохранению текущего `CF_BITMAP` (format2): «Native clipboard format 2 is not
preservable; check aborted before writes». Диагностика находится в
`ui-widget/check.err`; runner считает exit2 отказом, не успешным0 assertions.
Изображение владельца не очищали и guard не обходили. Это ограничение общего
UI прогона, а не отказ исправления переходов; интерактивная приёмка открыта.
