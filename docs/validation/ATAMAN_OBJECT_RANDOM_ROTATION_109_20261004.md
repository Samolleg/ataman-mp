# Ataman109 — отдельный рандом вращения X/Y, 2026-10-04

EI-OBJECT-RANDOM-ROTATION-109 продолжает EI-OBJECT-RANDOM-103. База main98a0770f83bf5ad833a77ea64b294e0c7983cb77, VERSION108→109. Владелец попросил добавить к «Рандом» отдельные кнопки вращения X и Y и подтвердил: «Отдельные действия поворота X и Y». Разрешены реализация, проверки, scoped-коммит и стандартная тестовая передача. Игровые данные и GitHub не меняются, открытая приёмка AI108 сохраняется.

## Поведение

В меню ПКМ кнопки «Рандом» два самостоятельных действия «Рандом вращения X» / «Рандом вращения Y» с существующей иконкой поворота. Своё поле «Поворот: ±…°», по умолчанию25°, диапазон0–180°, сохраняется в пользовательских настройках. Для каждого выделенного объекта мира выбирается независимый угол от −предела до +предела относительно его текущей ориентации. Поворот происходит по мировой оси вокруг собственной позиции; координаты, масштаб, ID и другие поля не редактируются. ЛКМ «Рандом» остаётся прежним действием масштаба/FIG-форм, его оси и проценты независимы от поворота.

Ориентация рассчитывается умножением кватернионов, без Euler round-trip. Команда хранит исходные и уже выбранные конечные кватернионы: одна Undo/Redo для всего набора, точное восстановление исходного quaternion даже около Euler gimbal-положения. setRot обновляет геометрию/границы штатным способом, dirty обновляется один раз для каждого владельца, история инвалидирует AI-preview. Некорректная исходная ориентация любого кандидата отменяет весь набор до создания команды.0°/нет выделения/неподдерживаемая ось/неверный диапазон — без истории; текущая операция/размещение запрещает рандомизацию. Поддерживаются те же объекты мира, что у прежнего «Рандом»; свет/существа не расширены этой задачей.

Ручная проверка: выделить несколько объектов мира → ПКМ «Рандом» → задать небольшой предел → «Рандом вращения X», затем Y. Проверить разницу углов, Ctrl+Z/Ctrl+Y;0° не меняет объекты. Перезапустить редактор и проверить сохранённый предел; ЛКМ и проценты масштаба должны работать как прежде. Вручную редактор/игра агентом не запускаются.
