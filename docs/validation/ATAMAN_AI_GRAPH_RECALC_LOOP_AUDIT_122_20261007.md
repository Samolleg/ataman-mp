Задача EI-AI-GRAPH-RECALC-LOOP-AUDIT-122-20261007. Запрос владельца2026-10-07: иногда после пересчёта AI-граф продолжает пересчитываться без новых нажатий. База main f25771611a34c6a9521a94c39b383a9e427a7f50, VERSION122. Разрешён аудит обычного кода, чтение журналов и собственные синтетические проверки. Реализация/сборка новой версии/установка и ремонт пользовательских карт не выполнялись. Недоступные навыки evil-islands/private-engine не использовались; приватный движок не читался.

## Подтверждённое поведение

Первое нажатие «Обновить граф» включает постоянный автоматический режим (`view.cpp:4344`). Успешное завершение расчёта его не выключает. Дальнейшее относящееся к навигации изменение истории Undo вызывает `scheduleAiGraphPreviewRegeneration()` (`view.cpp:2467–2475`); он помечает результат устаревшим, увеличивает revision и ставит single-shot таймер500мс (`view.cpp:4411–4429`). Таймер запускает полный расчёт всех слоёв без нового нажатия (`view.cpp:1709–1722`). Это отдельный полный расчёт маршрутов, не только обновление изображения.

Если вход изменён во время текущего расчёта, старый результат отклоняется и `finished` снова ставит таймер (`view.cpp:4352–4359`). Каждая последующая правка может повторить цепочку. Одновременно работает один worker; ожидающие изменения объединяются в следующий запуск, однако длительный расчёт может многократно тратить время на уже устаревший вход. В текущем журнале zone9 полный расчёт занимает4400–4618мс.

Кнопка «Скрыть», клавишаN и сворачивание панели меняют только отображение (`view.cpp:3755–3778`), автоматический режим сохраняется. Отдельного явного переключателя автопересчёта в панели нет. Переключение на встроенный/загруженный граф останавливает автоматическую очередь (`view.cpp:3865–3868`, `4432–4438`). Открытие другого источника и teardown также её сбрасывают. Поэтому после первого расчёта пользователь может продолжить обычную работу, скрыть граф и получать новые расчёты без повторного нажатия кнопки.

Смена слоя просмотра и обычное выделение не должны запускать полный расчёт: слой помечает только overlay dirty; история проверяет интерфейс `IAiGraphPreviewInvalidatingCommand`, в том числе дочерние команды (`ai_graph_preview_invalidation.cpp:45–56`). Полная маршрутизация вызывается только из фонового запуска и синхронной подготовки выбранного графа для явного теста карты/сохранения-экспорта (`view.cpp:4225`, `4407`; `main_window.cpp:4563`, `5156`). Восстановление высот встроенного просмотра использует только `navigationSurfaceHeights`, без построения маршрутов (`view.cpp:6025–6034`).

## Следующий шаг

При поручении исправить — сделать «Обновить граф» одноразовой явной операцией; изменение входа должно помечать созданный граф устаревшим, без скрытого запуска полного расчёта. Автоматический режим, если нужен, включать отдельным явным выбором и определить его поведение при скрытии. Сохранение/экспорт и тест карты должны брать актуальный кандидат, сохраняя независимый загруженный источник. Проверки: idle, правки/Undo/Redo, выбор объектов, источник loaded/generated, hide/collapse, очередь во время worker и свежесть сохраняемых данных. Если владелец подтвердит повторение без любых действий, нужен конкретный триггер и запись причин постановки revision/timer для этого случая; нельзя объявлять автоматический режим доказанной единственной причиной бесконечного idle-цикла.
