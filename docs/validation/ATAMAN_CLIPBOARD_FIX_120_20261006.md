## Изменение

Общий helper сохраняет значения MIME до передачи Qt, проверяет владение
буфером и фактическое содержимое после записи. При занятом Windows clipboard
повторяет запись примерно до одной секунды, обслуживая таймеры/native события
без пользовательских клавиш и socket callbacks. После передачи `QMimeData`
этот указатель не читается: Qt может удалить его при ошибке.

Проверяемая запись используется для свойств/компонентов, модели/текстуры,
ID, сообщений, ресурсных имён и кода предмета. Конечный отказ сопровождается
русским сообщением и звуковым сигналом. Стандартное выделение символов
копируется точно. Cut удаляет текст только после успешной записи, если поле
ещё существует и выделение не изменилось; Undo сохраняется. Контекстное меню
использует тот же маршрут, Paste сохраняет обычную проверку совместимости
и отдельное применение свойства. Меню защищены от удаления родительского
поля во время ожидания.

Внутренние typed values фиксируются только после успешной записи. Уникальный
MIME token связывает содержимое Windows с конкретным пакетом в памяти;
внешний/устаревший пакет не использует прошлое значение свойства.

Native UI checks отдельно проверяют свои записи и восстановление буфера.
Guard хранит реальные Windows format IDs, байты HGLOBAL и исходный приоритет
форматов. Восстановление сразу материализует данные Windows и проверяет их
перед завершением процесса. Это сохраняет двоичные зарегистрированные
форматы без повторного преобразования Qt aliases и порядок DIBV5/DIB,
от которого зависит чтение прозрачности. Неподдерживаемые indexed/device/
non-HGLOBAL данные останавливают проверку до её первых синтетических записей;
обычное пользовательское Copy этим ограничением не затронуто.

завершён только этот собственный диагностический процесс, затем развёрнут
его Qt/MinGW runtime. Пользовательский редактор не завершался.
