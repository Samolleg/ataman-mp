# Ataman 26 — редактор входов и переходов

Задача EI-TRAVEL-EDITOR, ветка codex/travel-editor-v26. Разрешение: «приступай».
Исходный результат: визуальное редактирование #deploy/#remove, новые связи,
сохранение изменённого map.txt в исходный texts.res при сохранении карты.

## Реализация

Общий CTravelDocument сохраняет исходную CP1251-таблицу и неизвестные поля через
CMapTableDocument. Панель и viewport используют один документ и QUndoStack.
Проверяется связь с текущим MPR; мировое смещение не участвует в координатах.
Прямая и обратная записи редактируются явно. Обратная запись не копирует
локальные координаты исходной карты без выбора пользователя.

Согласованное сохранение собирает готовые кандидаты texts.res, активного MOB,
MPR и зависимых ресурсов атласа. До замены файлов выполняются staging и backup.
CAS-проверки выявляют внешние изменения. При ошибке выполняется обратное
восстановление только собственных записей. При обрыве процесса остаются резервные
копии и JSON-журнал: это не обещание атомарности нескольких файлов при сбое питания.
