## Исправление

`util::constProp` теперь возвращает QSharedPointer по значению и возвращает null, если свойство отсутствует; null-элементы пропускаются. Убраны assert/back() и возможность подставить последнее чужое свойство. Все production-потребители этого поиска находятся в tablemanager.cpp и просмотрены: Model/Bodyparts уже проверяют пустоту; для составных XYZ, guard radius и полей import добавлены проверки наличия до создания редакторов. Неполная группа XYZ не создаёт некорректный редактор. Пустой набор очищает панель и безопасно проходит обычный путь; повторное заполнение и состояния сигналов сохраняются.

Поведение коллекций маршрутов/ловушек не упрощалось: отдельная full-width строка коллекции и effective trap targets при смешанном выделении остаются по прежним правилам CView. Выделение не снимается, параметры не подменяются; изменение данных и Undo/Redo продолжаются штатным путём. Структура игровых документов и сохранение не менялись. Версия182.
