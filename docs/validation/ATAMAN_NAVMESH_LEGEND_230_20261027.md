## Изменения

1. Единственный список Nav64 —8/9/10 в nav64SupportedAlgorithms(). Контейнер3/ABI прежние. Файл сопоставляется с картой по встроенным строкам MPR/MOB/профиля; имя файла — подсказка, переименование не меняет идентичность. Несовпадение с известным алгоритмом запекателя видно в панели и журнале.
2. Алгоритм запекателя берётся **только из BAKE_BEGIN** и запоминается вместе с SHA-256 запущенного EXE в QSettings. До наблюдения и для других байтов EXE он неизвестен. Нет каталога «известных хешей → версия». Сохранён один hook nav64BakerIdentity для будущего протокола версии. --version запекателя не вызывается.
3. bodies.navbody только читается: magic/version/algorithm/count, полная длина, UTF-8 basename, порядок/уникальность ключей, конечные shape/dimensions, неотрицательный радиус, положительные высоты, допустимые ground/levitation ID. Панель и журнал показывают **«Таблица тел:1757 образцов, алгоритм10»**, «нет», несовпадение либо ошибку. Маппер не сериализует и не редактирует таблицу. Перед внешним запеканием существующий вывод, включая таблицу, защищается бэкапом; новую таблицу пишет запекатель.
4. «Экспорт списка…» в виде «Потери проходимости» сохраняет CSV UTF-8 BOM, запятая, десятичная точка: карта, профиль, старый слой, потеряно/появилось, площадь м², центр X/Y и bbox_min_X/Y, bbox_max_X/Y в мировых метрах. Одна строка — четырёхсвязная область; bbox по внешним границам клеток. Сохранение атомарное через QSaveFile. Экспорт включён после завершения расчёта.
5. Свежесть осталась **приблизительной по датам**. Команда --fingerprint не вызывается и не является проверкой готовности. README производителя содержит её описание, но явное решение владельца для230 приоритетно. Автоматическое перепекание при сохранении и удаление fingerprint относятся к будущему X64NAVCORE.

Новых доков нет. Легенда, профили/слои, расчёт/области и экспорт находятся в «Навигации ИИ». Красные точки обычного слоя — центры островов кроме крупнейшего; оранжевые линии — короткие порталы, голубые прямые — границы тайлов. Легенда потерь показывает только действительно рисуемые элементы.
