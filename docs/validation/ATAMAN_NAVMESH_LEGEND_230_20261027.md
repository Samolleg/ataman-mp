## Значение цветов и точек

- Красные точки — средние центры связных компонентов полигонов, кроме крупнейшего компонента (острова). Это не выбросы высот, не off-mesh-связи и не порталы.
- Оранжевые линии — открытые рёбра-порталы короче диаметра профиля; приблизительные кандидаты узких мест на уже эродированной сетке.
- Голубые прямые — границы тайлов хранения. Контуры полигонов — зелёные в режиме «Контуры».
- Заливка — проходимая поверхность выбранного профиля, объединение разрешённых поз. Дыры означают препятствия/непроходимое.
- Area ID — редуцированный класс затрат пути из `aiMap` (`dwTerrains`), не исходный enum трава/песок/дорога. Легенда показывает реально присутствующие классы и общую таблицу затрат старого алгоритма. Для zone1 human: area3 ×34,96; area10 ×5; area13 ×2; area14 — обычная поверхность. Цвета взяты из той же функции, что использует renderer.

Легенда по умолчанию включена, переключается отметкой «Легенда», полупрозрачна и размещена рядом с миникартой без перекрытия видимыми контролами. В виде потерь перечислены только два цвета сравнения, клетка, слой и выделение; тайлы/острова/цвета областей в нём не рисуются и не перечисляются.

## Сопоставление и смысл измерения

| Navmesh | Старый слой по умолчанию |
| --- | --- |
| tiny | 1 — узкий / лёжа, 0,4 м |
| small | 1 — узкий / лёжа, 0,4 м |
| human | 3 — в рост человека, 1,6 м |
| large | 6 — широкий / высокий, 3 м |
| giant | 7 — очень крупный, 6 м |
| levitate_tiny | 0 — парящие, 2 м |
| levitate_small | 0 — парящие, 2 м |
| levitate | 0 — парящие, 2 м |

Это смысловое соответствие, а не биекция или равенство радиусов: у старого графа только один слой левитации, ширина задаётся Star3/5/7. Любой из восьми слоёв доступен для ручного переопределения, включая2/4/5; выбор сохраняется для каждого профиля.

**Сохранённый MOB/.grp не содержит исходной маски проходимости0,5м:** там узлы/связи4м. Поэтому режим сравнивает пересчитанную маску старого алгоритма по текущей сцене маппера. Это явно написано в панели. Сохранённый граф и его байты не заменяются. Коллизии могут быть приближёнными; это диагностика алгоритмов, не точное восстановление состояния старого игрового графа.

CPU-снимок передаётся фоновому worker. Классификатор использует ту же функцию, что полный старый построитель, без построения/сохранения маршрутов. Navmesh растеризуется по центрам клеток с проверкой выбранного clearance bit и высоты пола; привязки к ближайшему полигону через стену/дыру нет. Допуск высоты — max(0,5м, climb + 2×cellHeight). Клетка0,5×0,5м даёт0,25м²; связные области четырёхсвязные. Отменённые/устаревшие результаты не публикуются.
