# Ataman 119: совместные переходы на стыке карт

Дата:2026-10-06. Задача: EI-WORLD-MATERIAL-SEAM-FIX-119.
Ветка: `main`. База: `4877d7e44262d277ff28e44fad7d8875c9c1aca7`.
Поручение владельца: «исправляй», продолжение аудита118.
Разрешены обычный код, проверки, scoped-коммит, сборка и постоянная установка.
Публикация и ZIP не запрошены. Игровые MPR/MOB/RES и раскладка не записывались.

## Исходный отказ и исправление

В118 world resolver уже получал zone6, но оставлял конфликтующие материалы
без изменений. В исходной паре zone4/zone6 различались10 из130 граничных
семантических вершин и20 из129 физических кромок. Совпадение материалов
четырёх углов само по себе также не гарантировало общий рисунок двух масок.
Первое неверное решение зафиксировано в
[аудите118](ATAMAN_ZONE4_ZONE6_MATERIAL_SEAM_AUDIT_118_20261006.md).

Теперь команда планирует связную группу явно включённых карт из неизменяемых
снимков. На выровненной сетке общий семантический угол получает один материал:
чистый физический тайл имеет приоритет, равные по силе конфликтующие источники
разрешаются минимальным стабильным global material ID. Активная карта и порядок
обхода не участвуют в выборе. Старый консервативный planner остаётся доступен
своим прежним вызывающим путям; дробная фаза не получает выдуманной пары тайлов.

Обе стороны полного общего края принудительно получают физический переход
из одного детерминированно выбранного набора источников. Граница маски и фаза
текстур рассчитываются в мировых координатах по трём SEC-вершинам стороны.
Полоса края учитывает кодирование DXT1. Внутренняя часть использует действующий
канонический генератор. Покрытие с отсутствующей поверхностью не активируется.

Runtime tile types сохраняются. Новые переходы добавляются после полной
исходной страницы, включая её неиспользуемый хвост; нехватка места отказывает
в транзакции и не освобождает слоты прежней истории. Исходные страницы не
перерисовываются. Группа применяет preview, откат при отказе и одну историю
общей кисти. JSON-аудит теперь хранит дельты каждой карты, истинное общее
число изменённых ячеек и hash с идентичностью карты.

процесса и записанные exit0/exit1, не предположение о коде выхода.
