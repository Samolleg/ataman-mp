# EI-LIGHT-CREATE-56

- Причина: общий путь «технического объекта» требовал выбранную запись того же типа ради сохранения полных полей MOB, даже если пользователь создавал новый свет с нуля.
- Исправление: для LIGHT создаётся полный исходный подблок со значениями формы и собственной проверяемой provenance; остальные типы по-прежнему используют существующий защищённый путь.
- Release 56 собрано. Скрытый запуск готового EXE: `--version` = 56; `--database-creation-check` = exit 0, включая свет без выбранного объекта, защищённое сохранение, повторное открытие и Undo/Redo.
- `--ui-widget-check`: `travelEditorProductionRouteWorks=1`, но общий exit 1 из-за прежних проверок копирования и вставки свойств (`compatiblePastePreview`, `selectedComponentCopy` и родственные). Свет в игре и редактирование реального `texts.res` остаются ручными шагами.
- Итоговый проверенный EXE SHA-256 `E2591BEDD5630B6C2FF0641BB97BDDC3A6418F2581B23E174C182E2EA75E079E`. Тестовая папка `build-test-56-light-map` не является пакетом для передачи или постоянной установкой.
