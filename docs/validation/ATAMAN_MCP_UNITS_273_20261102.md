| Инструмент | Поведение |
|---|---|
| list_units / get_unit | ID, область272, прототип, Player/группа дипломатии, MOB; позиция/поворот/прототип/имя/ParentID, встроенные stats, все5 слотов поведения, радиусы/параметры/охрана/маршруты/взгляды; входящие ссылки с владельцами/строками |
| edit_units transform | Одиночный/групповой жёсткий поворот вокруг pivot/центра и сдвиг со всеми точками всех5 слотов; относительный Z юнита сохраняется плюс явно заданный dZ |
| edit_units points | Добавление/сдвиг/удаление патрульной точки и взгляда, сдвиг единственной точки охраны; азимут/дальность взгляда от его патрульной точки. Индексы с0, edits последовательны. Прочие параметры поведения сохраняются |

| validate_map | Прежние семейные ID/ссылки/структура/ресурсы плюс позиции юнитов и все точки логики вне карты; исходные данные не исправляются |

Формат исследован по `source/objects/unit.cpp`: CUnit::toJson/serialize,
CUnit::updatePos, CLogic::serializeJson/replaceFromJson,
CPatrolPoint/CLookPoint::serializeJson. Навыки evil-islands-modding и
evil-islands-private-engine-reference в этой сессии недоступны; приватный код
движка не читался и не копировался.

UNIT OBJ_POSITION.Z — смещение относительно рельефа. В ответе absoluteHeight
вычисляется отдельно и не записывается обратно. Координаты логики — мировые:
жёсткий transform применяет один поворот/сдвиг к сохранённым координатам всех
слотов. Он не вызывает CUnit::updatePos с его контекстным переносом только
первого/редактируемого слота и повторным прибавлением высоты поверхности.
На Undo возвращается точная исходная проекция логики, затем native serializer
возвращает исходные байты. `group` — штатный Player, группа дипломатии;
самостоятельной сущности дружины или новой модели групп не создаётся.

Скрипты SS_TEXT не копируются/не меняются. Ответ copy перечисляет исходные
сценарные ссылки и предупреждает, что они не перенесены. Копии получают
InScript=false и уникальные имена `<sourceName> [copy <newID>]`, чтобы исходный
GetObjectByName не привязался к копии. sourceName/nameAfter видны в ответе.
Внешние исходящие ParentID/цели сохраняются; внутренние переназначаются по
полной таблице группы. Статический поиск ссылок имеет прежние пределы272:
динамические выражения не исполняются.

Для каждого юнита и каждой результирующей точки preview/apply содержат
штатную проходимость выбранного слоя, inObject/inWater/outsideMap/inBounds.
Слой задаётся явно как в query_passability; layers по ID поддерживает смешанные
группы. Размер животного не угадывается по названию; сохранённый AIClassStay
доступен при чтении, но данные базы могут переопределять MOB stats. В тесте
НПС167 и собака183332 проверены на их сохранённых слоях3 и1. inObject — XY
footprint статической коллизии, кроме Ignored/Bridge; inWater — вода текущей
навигационной поверхности. Ничего автоматически не двигается и не ремонтируется.
Юниты динамические, не участвуют в статическом графе: их операции не инвалидируют
его, согласно штатной contributesStaticNavigationCollision. Предыдущее состояние
graphStale сохраняется.

Пределы:500 юнитов на чтение/операцию,200 edits и200 суммарных точек логики
на правку, включая guard placement всех5 слотов;512КиБ ответа;16384 графовых
ячейки для классификатора. Переполнение/неподходящий явный ID/отсутствующий слой/
неверный индекс дают отказ всему пакету. Молчаливого усечения нет. Развёрнутые
схемы, native имена полей и примеры: [AI_AGENT_MCP.md](../AI_AGENT_MCP.md).
