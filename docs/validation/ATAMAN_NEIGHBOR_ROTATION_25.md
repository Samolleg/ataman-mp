# Ataman 25 — повороты объектов соседей

Ветка codex/neighbor-rotation-v25 от 5c8e5106. Поручение владельца: исправить
различие zone1 как активной карты и как соседа zone2; обновить постоянную программу.

Причина: neighborStaticObjects копировал MOB wxyz в JSON xyzw без перестановки.
Активный CMobParser::readQuaternion выполняет эту перестановку. Единичный поворот
превращался в 180 градусов вокруг X. Изменено только преобразование поворота;
отсутствующий/некорректный массив по-прежнему получает единичный fallback.

Репродукция до правки: новый neighborRotationsPreserveTransformedVertices FAIL
на единичном повороте (build-rotation25-before.txt). Тест покрывает также поворот
вокруг Z, X, произвольный нормализованный quaternion, четыре пробные вершины,
отсутствующий rotation и неизменность сериализованного MOB. Исправлено ошибочное
ожидание в старом тесте копирования визуальных свойств. Скрытая интеграция дополнена
независимым сравнением всех статических поворотов с настоящим активным парсером.

Исправление проверено и установлено. Визуальная приёмка двух
исходных ракурсов остаётся отдельной: тест поворотов не доказывает равенство всех
эффектов, состава динамических объектов и освещения активной/соседней карты.
