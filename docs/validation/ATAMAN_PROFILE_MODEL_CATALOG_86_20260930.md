## Изменения

- pathForDatabase/loadProfile берут каталог из папки sourceArchivePath выбранной базы. При отсутствующей базе запись блокируется, скрытого отката к EXE нет. При отсутствующем новом JSON импортируются глобальные models (имена/категории/неизвестные поля) и только профилированный кэш/текстуры активного профиля. Существующий JSON имеет приоритет; старый файл остаётся восстановимым. QSaveFile/сравнение исходных байтов защищают атомарную запись и внешние изменения. Простое выделение объектов не пишет каталог.
- Создание и свойства используют один каталог, одну витрину/CPU-поставщика превью. Иерархия следует выбранной базе и сохраняет read-only импорт имён до первой явной записи.
- Свойства: отдельная read-only строка русского имени только при наличии; кнопка витрины возле модели; привязанные текстуры первыми, затем общий список; текущая текстура сохраняется при открытии. Модель/текстура применяются существующими undo-командами одним макросом, без изменения ID/позиции/имени экземпляра. Групповой undo восстанавливает разные исходные пары, включая повторяющиеся ID.
- Витрина свойств требует установленную текстуру, отмена/повторный выбор ничего не меняют; устаревшее выделение и смена профиля не получают результат чужого диалога. Запертый MOB не редактируется. Выбранные текстуры записываются в JSON при явном изменении. Неизменный JSON и scan metadata переиспользуются при частых перестроениях свойств (перемещение/вращение).
