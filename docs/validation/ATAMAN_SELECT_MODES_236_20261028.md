## Изменение

Единый activateObjectSelection для обычного выделения и выхода через Esc:
переход к объектам, завершение инструмента рельефа, восстановление Select и
соответствующей подсказки. Кнопка «Поведение»/Ctrl+Tab сохраняют редактирование
поведения и его специальные узлы; обычная кнопка «Выделить» возвращает все типы.
Первый Esc при незавершённом transform восстанавливает его снимок и сохраняет
режим поведения; следующий Esc возвращает к объектам. Из постоянного рисования
тайлов Esc выходит одним нажатием. Закрытие уже скрытой панели тоже выключает
кисть. Настоящая подсказка рельефа не стирается обновлением обычного Select;
после выхода она заменяется. Координаты показываются по hit и конечным XYZ,
без произвольного ограничения высоты. Результат «промах» не выдаёт координаты.
