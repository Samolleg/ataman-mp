# EI-TERRAIN-BAKE-STAGE-C — повтор однородного материала и цена слотов

Дата: 2026-10-11. Поручение владельца через Claude. Только исследование и
автономные Python-прототипы; код программы, версия, установка и карты не менялись.
База: main `57b998d3ee1f7b207cc866ca68879687eca97e49`, VERSION 138.

## Результат и рекомендация

Сравнены текущие варианты/повороты136, макро-тоны N4/N8, мировое смешивание двух
источников и настоящая стохастическая выборка по треугольной решётке (hex/blend).
Дополнительно испытан её конечный переиспользуемый банк K8: свободная мировая
выборка слишком дорога на больших картах. Все методы используют один реальный
участок Zone6 с восстановленными HD-источниками138.

**Рекомендованный следующий кандидат для реализации: конечный stochastic-банк
K=8 на `(материал, runtime class)` как отдельная выключенная по умолчанию опция
для выбранных изотропных травы/земли.** Он сильнее макро-тонов разбивает
узнаваемую орнаментальную структуру источника, а цена ограничена: 14 новых
слотов на участке; корпусная модель — median21/max92, все41 карты в2048.
Это кандидат для preview и художественной оценки, а не готовое устранение сетки:
сброс stochastic-фазы на ребре сохраняет клеточные швы; мелкий контраст ниже
исходного примерно на31%. Без принятия этого компромисса включать массово нельзя.

**Полное устранение ощущения сетки в заданном бюджете не подтверждено.**
Мировой hex даёт лучший результат на стыках однородного материала, но корпусная
модель помещает только26/41 карту в2048 и30/41 в4096. Его целесообразно оставить
отдельным качественным эталоном или режимом ограниченного участка с явным
расчётом слотов, а не предлагать по умолчанию для всех Dejavu.

Макро N8 можно реализовать отдельно как дешёвую цветовую вариацию: масштаб12
клеток, яркость±6%, относительная RGB-поправка±(1.2%,0.4%,-1.2%), один связанный
параметр тона. N8 даёт меньшие ступени, чем N4. Но мелкий повтор он практически
не меняет; выдавать его за решение исходной проблемы нельзя. Сочетание банка
K8 и N4/N8 здесь **не** растеризовано и **не** включено в приведённый бюджет:
при произведении состояний стоимость выросла бы до32/64 рецептов на identity.
Смешивание фиксированной пары источников отклонено: оно возвращает сильный
повтор через клетку даже при непрерывной мировой маске.

## Методы и точные параметры

**Current136.** Воспроизведён scalar uint32 FNV+avalanche selector из
`terrain_edit_model.cpp`: seed138, координаты и четыре одинаковых material ID;
выбор физического слота отдельно от поворота. Пулы отсортированы по physical
slot, runtime class сохраняется. На выбранной траве/земле нет route owner,
canonicalGeneratedRoute или запрета ротации; веса всех кандидатов1. Независимый
scalar readback проверяет182 назначения. Изменилось180 refs относительно
старого снимка; переходы остаются прежними. Seed138 выбран явно для сравнения;
это не обещание совпадения с текущим зерном пользовательского документа.

**Macro4/8.** Существующий baseline slot получает один из N равномерных уровней
[-1,+1]. Один smoothstep value noise в мировых координатах `/12` определяет
уровень по центру клетки: `floor((noise+1)*N/2)`, clamp0..N-1.
`RGB' = RGB * (1 + level * (0.06 + [0.012,0.004,-0.012]))`.
Тон постоянен внутри клетки. Ключ `(material,class,sourcePhysicalSlot,tone)`;
поворот хранится в SEC и новых слотов не создаёт. Не независимый hue×brightness
набор: иначе N умножился бы ещё раз. Нейтрального уровня у чётного N нет,
поэтому все реально выбранные tone-рецепты новые; исходные слоты сохраняются.

**Mix2-world.** Первые два доступных однородных источника одной identity;
вторая текстура имеет перенос(0.371,0.613) клетки и поворот90°. Маска непрерывна
в мировых координатах: `(noise(world/2.7)+1)/2`. Детальная текстура сохраняет
период1 клетка, маска меняется медленнее; уникальная маска/мировая фаза дают
новый физический тайл. Материалы с единственным вариантом здесь не изменяются;
переходы также остаются baseline.

**Hex-world.** Equilateral triangular lattice с шагом1 клетка, skew
`u=x-y/sqrt(3), v=2*y/sqrt(3)`. В каждой точке три вершины треугольника задают
источник, quarter-turn и случайный UV offset. Barycentric веса возводятся
в квадрат и нормализуются. Вершина имеет одно состояние для всех прилежащих
треугольников: это actual stochastic hex/blend sampling с непрерывной мировой
фазой, не просто три локальных тайла под независимым cell noise. Вместе с тем
это обычное RGB-смешение, без histogram-preserving преобразования и без новой
авторской графики. Общая граница однородных соседей C0; переходы не перепекались,
совместимость новой текстуры с сохранёнными stock-переходами не доказана.

**Hex-bank8.** Дополнительное сравнение конечного набора. K=8 coherent stochastic
рецептов на identity, source scale1, тот же exponent2. Для label используются
фиксированные offsets `(31.17+13.371*label,17.61+19.613*label)`; независимый seed
139 выбирает label по координатам, quarter-turn берётся из baseline136.
Мировая фаза внутри каждого рецепта coherent, но при стыке клеток сбрасывается.
Состояния общего ребра не согласованы. Бесшовным мировой вариант этот банк
не называется; именно его потерю непрерывности нужно учитывать при реализации.

Все выходы применены только к однородной траве/земле; остальные74 клетки
побайтно одинаковы во всех пяти новых вариантах. Исходная граница материалов,
runtime class, overlay, геометрия и реальные MPR/RES не ремонтируются.

## Визуальная оценка и диагностические метрики

Просмотрены preview, closeup, полный current136 и tone-map. Это оценка
исследователя, художественная/игровая приёмка владельца не выполнялась.

1. Baseline уже хорошо снижает точный повтор от соседней клетки, но не убирает
  симметричный/орнаментальный мотив внутри самой исходной травы и резкие стыки
  отдельных её выборок. Низкая pixel correlation не означает отсутствие
  воспринимаемой сетки: разные повороты узнаваемого рисунка остаются узнаваемыми.
2. MacroN4/N8 добавляют слабые крупные цветовые пятна и почти сохраняют исходную
  детализацию. Мотивы и основные швы остаются. На карте тонов явно видны
  ступенчатые области по сетке; N8 мягче, N4 даёт более крупную ступень.
3. Mix2-world на closeup всё ещё имеет отчётливый регулярный рисунок, местами
  мягче baseline. Непрерывная маска не устраняет период обоих фиксированных
  источников: лаг1 резко коррелирован. Метод хуже для этой исходной проблемы.
4. Hex-world сильнее всего разрушает прямоугольный орнамент и регулярный стык
  однородных клеток. Взамен появляется неоднородное размытие/потеря контраста
  там, где веса близки; переходы к baseline-кромкам могут выдавать смену метода.
  Эта потеря деталей существенна даже при HD256.
5. Hex-bank8 сохраняет выигрыш в разнообразии мотивов, но на большом поле всё
  ещё видны квадратные стыки/патчи. Относительная сила сеточного скачка почти
  baseline; низкий абсолютный скачок частично объясняется снижением контраста
  всей текстуры. Размытие и повторы конечного банка остаются. Повышать contrast
  умножением без контроля histogram/clipping здесь не испытано и не предлагается
  как уже проверенное исправление.

Метрики только на172 клетках доминирующей травы,286 их общих рёбрах. Highpass —
luma минус Gaussian blur3px. Grid ratio — среднее |Δluma| через SEC boundary
делённое на среднее |Δluma| соседних пикселей внутри клеток (8px inset).
Это диагностическое отношение, не абсолютный тест бесшовности и не art-рейтинг.

## Экстраполяция41 карт Dejavu

Резервируется весь существующий физический атлас, включая padding/неиспользуемые
места/анимации. Старые слоты не удаляются и не заменяются при прогнозе:
`append = ceil((allocated + new)/64)*64`. Quarter turns не создают слоты.
Полный stock+new budget надёжнее сравнения только с usedSlots.

Macro — точное количество конечных ключей моделируемой политики seed138,
равных weights, природной травы/земли и доступного uniform pool по class;
после raster-dedup число может уменьшиться. Full-corpus HD pixel bake, реальная
upstream palette selection и MP-animation eligibility всех41 карт не
выполнены; это прогноз, не гарантия новой production-публикации. Непроверенные
анимационные источники должны исключаться в реализации, старые слоты остаются
зарезервированными. Модель не меняет overlay/underwater/направленные материалы.

Мировые методы — один новый слот на eligible клетку (для mix нужны2 источника),
то есть оценка верхней границы перед corpus pixel dedup. Результат182 уникальных
слотов на выбранном участке поддерживает эту модель, но не доказывает её на
всех картах. БанкK8 — фактически выбранные label keys; новых материалов и
будущих импортов в прогнозе нет. Свободный доступный хвост старых страниц
здесь не переиспользован; предусмотрен консервативный append.

## Дальнейшая реализация и открытые ограничения

1. Реализовывать K8 как отдельный конечный банк с ключом material/class/source
  identity/generator version/label и сохранённым seed. Стабильное назначение
  label не зависит от состава группы; class/route/material identity сохраняются.
  Не кэшировать только по углам: у свободного мира это теряет фазу и маскирует
  ошибки бюджета. Quarter turns остаются в SEC, веса выбираются по physical
  recipe, не по числу его поворотов.
2. Параметры кандидата: K8, source scale1, simplex exponent2, UV translations
  как выше, rotations0/90/180/270 только для принятого изотропного материала.
  Направленные/анимированные/overlay/underwater/mixed-edge источники исключать;
  нет источников/бюджета — явный отказ, без замены материала и без скрытого
  перехода на blur/unique slots. Опция defaultOFF; включение после preview.
3. Отдельно проверить сохранение мелкой рисованной фактуры: histogram-preserving
  blending или selection вместо RGB averaging — гипотеза следующего опыта,
  здесь не проверена. Конечные shared-edge states или согласованный seam strip
  потребуют нового расчёта, могут увеличить K; гарантировать прежние92 нельзя.
  Запирать variation в interior fade также нельзя выдавать за решение сетки:
  этап1 уже показал повтор фиксированного ребра.
4. MacroN8 — только дополнительный цветовой слой со своим budget-preview и
  известными ступенями, не обязательная комбинация с K8. В начале достаточно
  ±6% и12клеток, hue связанный±1.2%. Менять тон переходов без их общего edge
  contract нельзя. Соседние карты требуют общих global coordinates/seed.
5. Production/игровые gates ещё не выполнены: настоящий atlas compile с UV/gutters/
  DXT1/mips, стыки uniform↔transition/sector/page/map, animation/overlay/classes,
  save/reopen, Undo/Redo, бюджет полного итогового атласа и память HD256.
  Этот отчёт не разрешает реализацию или установку. Ни source/render/view.cpp,
  ни source/app/main.cpp для offline результата не потребовались.
