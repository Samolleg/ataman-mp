## Изменение

CChangeLogicParam при обычной смене другого поведения на Path отделяет старые
точки в undo-команду. Начинается пустой маршрут. Undo возвращает исходные объекты
точек, look points и поведение. Другие свойства и неизменённый Path не очищают
маршрут. Использовать сохранённые точки можно отдельной кнопкой с явным названием.
Кнопки вынесены под переносимый заголовок, чтобы текст не вытеснял их вправо.
