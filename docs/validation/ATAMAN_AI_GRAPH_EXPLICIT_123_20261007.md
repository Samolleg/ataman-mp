## Причина и изменение

Первое нажатие «Обновить граф» в122 оставляло
`m_aiGraphAutoRegenerationEnabled=true`. Навигационные команды Undo запускали
таймер500мс; скрытие графа это состояние не меняло. Правка во время worker
отклоняла его результат и могла поставить следующий расчёт. Источник
generated снова включал автоматический режим. Подробности исходного аудита:
[аудит122](ATAMAN_AI_GRAPH_RECALC_LOOP_AUDIT_122_20261007.md).

В123 автоматическое состояние и политика запуска при переключении удалены.
Правки только инвалидируют свежесть и ревизию, очищают display-cache загруженного
графа и отмечают созданный граф устаревшим. Старый результат сохраняется для
просмотра до явного обновления. Кнопка запускает один расчёт; повторные нажатия
во время worker объединяются в один дополнительный запрос. Только этот запрос
может запустить deferred timer0мс после finished. Навигационная правка без
нажатия не создаёт очередь и не повторяет отклонённый worker.

Выбор loaded, смена карты и shutdown отменяют очередь. При ошибке подготовки
входа UI восстанавливается. Подсказка и сообщение о несвежем графе переведены.
Сохранение/экспорт выбранного generated использует существующий путь подготовки
актуального кандидата; выбранный loaded сохраняет точные исходные байты.
