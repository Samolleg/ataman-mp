594a511f630eebeb3f0b77f65c4dc6ace0bfca97 (последующие изменения только документов).
Ветка codex/distribution-v16. Код и игровые данные в ходе аудита не исправлялись.
Аудит охватывает сохранение MOB/MPR/RES/настроек, резервирование, мир JSON,
загрузку соседей, основные механизмы render queue и пакет. Это не исчерпывающая
проверка каждого UI-сценария, формата, игровой установки и оборудования.

## Подтверждённые дефекты

### AUD-01 — P2: диалог может изменить координаты без правки координат

Источник: source/app/main_window_world.cpp:280, :281, :297.
QDoubleSpinBox ограничен двумя знаками и диапазоном ±10 000 000. При заполнении
полей исходные значения уже округляются; на OK обе координаты переписываются,
даже если пользователь менял только имя или путь. JSON принимает более точные
конечные числа. Репродукция с тем же Qt: 0.125 → 0.13 без редактирования поля.
Крупные значения вне диапазона дополнительно ограничиваются контролом.
Доказательство: build-audit-16/probes/results.txt, precisionLossInCoordinateControl.
Рекомендация: сохранять исходное число, пока конкретное поле не изменено;
явно согласовать точность координат вместо неявного округления на открытии.

### AUD-02 — P2: точные размеры не возвращаются в документ мира

Источник: source/app/main_window_world.cpp:70–95;
source/documents/world_map_layout_document.cpp:307, :655, :150.
refreshEditorWorld читает размеры MPR и обновляет копию m_editorWorldMaps.
Внутренний m_zones документа остаётся с нулями у унаследованных записей.
При перемещении карты/добавлении другой карты документ сериализует эти нули.
Репродукция: legacy load → обновление UI-копии до 8×8 → setZoneOrigin → JSON 0×0.
Доказательство: build-audit-16/probes/results.txt, legacyMetadataAndExtensionLoss.
Вручную исправленный JSON пользователя сейчас не обнулится от одного открытия:
дефект относится к старым/неполным записям и рассинхронизации с изменённым MPR.
Рекомендация: единый источник метаданных, проверка из MPR при намеренном сохранении,
с сохранением координат; явно представлять неизвестные размеры.

### AUD-03 — P2: неизвестные поля JSON молча теряются при сохранении

Источник: source/documents/world_map_layout_document.cpp:142–168, :299–315.
Парсер принимает дополнительные поля, но хранит только фиксированную структуру;
сериализатор создаёт JSON заново. Пользовательское поле userNote на уровне корня
и карты исчезло после изменения только origin. Для schema 1 сохранится миграционная
копия; при обычных сохранениях schema 2 такой резервной копии код не создаёт.
Это воспроизведённая потеря дополнительных данных; потери стандартных полей
в выполненных проверках не обнаружены.
Доказательство: build-audit-16/probes/results.txt, legacyMetadataAndExtensionLoss.
Рекомендация: сохранять неизвестные свойства либо явно отказывать в записи
неподдерживаемого содержимого до изменения исходного файла.

### AUD-04 — P2: просмотр списка мира запускает полную перезагрузку соседей

Источник: source/app/main_window_world.cpp:239;
source/render/view.cpp:3037, :3077, :3082, :3106.
Вход в «Карты мира» безусловно вызывает refreshEditorWorld. Контекст каждый раз
очищает готовые сцены, увеличивает generation и запускает подготовку/загрузку
заново, когда соседи включены. Это происходит и при последующем закрытии списка
без изменений. Холодный refresh дополнительно разбирает все найденные MPR в
GUI-потоке (main_window_world.cpp:87), а не только пять отображаемых соседей.
Подтверждение: прямой путь вызовов, без условия изменения контекста. Длительность
задержки/FPS не измерялась; конкретный размер просадки не заявляется.
Рекомендация: не перестраивать сцены для простого просмотра; сравнивать ресурсы,
координаты и ревизии, обновлять только изменившиеся; чтение размеров вынести из UI.

### AUD-05 — P2: штатный валидатор пакета даёт ложный PASS

Источник: packaging/validate_distribution.ps1:145, :161–179.
Для целого VERSION нет контроля текущего changelog. Манифест проверяется на
запрещённые имена, но не на фактические SHA256, существование и покрытие файлов.
В отдельной копии пакета VERSION изменён на 999 и CHANGELOG.md удалён; штатный
валидатор всё равно сообщил «one current changelist» и PASS.
Доказательство: build-audit-16/package-probe-result.txt; изменялась только
build-audit-16/package-probe, не пользовательский пакет.
Реальный дистрибутив 16 отдельно прошёл полную проверку 100 хешей и покрытия,
поэтому эта находка не означает повреждение переданной папки.
Рекомендация: встроить независимые проверки договора передачи в штатный скрипт.

### AUD-06 — P3: испорчена строка подсказки размещения карты

Источник: source/render/view_world_placement.cpp:64;
translations/ei_mapper_ru.ts:10679.
В C++ в строке Place map находятся «вЂ”» и «Г—», а ключ перевода содержит «—» и «×».
Точного совпадения ключей нет: Qt не найдёт существующий русский перевод и
возвращает исходную английскую строку с испорченными символами.
Доказательство: build-audit-16/translation-probe.txt (exact TS match: False).
Рекомендация: восстановить UTF-8 строку и добавить проверку совпадения ключа перевода.

## Границы и порядок исправлений

Общий --ui-widget-check ранее многократно заканчивался timeout 120 секунд;
в этом аудите повторно не запускался. Это открытый пробел проверки, не PASS.
Полный интерактивный путь, реальные сохранения изменённых карт в игре, FPS и
поведение на другом ПК не проверены. Успех синтетических транзакций не доказывает
работу всех игровых форматов. Критическая ошибка сохранения MOB/MPR в выполненном
наборе не воспроизведена; это не гарантия отсутствия таких ошибок.

Рекомендуемый порядок: AUD-01 и AUD-03 (сохранность данных), AUD-02 (метаданные),
AUD-04 (отзывчивость), AUD-05 (качество передачи), AUD-06 (локализация).
Отдельно локализовать зависание общего UI-теста. Реализация требует следующего
поручения владельца; текущий запрос выполнен как аудит без исправлений.
