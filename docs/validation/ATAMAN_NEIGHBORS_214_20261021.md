активных объектов защищён отдельно. При этом геометрическое правило
`touchesActiveMap` и допуск не изменены.

После открытия этого пути скрытый framebuffer выявил второй дефект: объектный
shader применял ко всем соседям `borderFog` от96×192 активной MPR и полностью
закрашивал их цветом неба. Для backgroundScenery выключен только туман границы
активной карты, дистанционный туман сохранён. Instancing не объединяет объекты
с разным этим uniform. Новый снимок просмотрен: видны текстурированные деревья,
строения и камни, прежние сплошные голубые силуэты устранены.

## Кэш214

- Фон сохраняет CLandscape, секторные GPU-буферы, аренду атласа, загруженные
  статические визуалы, подготовленные LOD/записи отрисовки и поле солнца.
  При смене активной карты фон получает новое смещение, матрицы/пространственные
  группы перестраиваются по локальным позициям; GPU-атлас и секторы переиспользуются.
- CLandscape singleton сохраняет адрес для существующих потребителей. Между ним
  и фоном передаётся владение renderer state; секторные ссылки на таблицы
  материалов/анимации перепривязываются к новому владельцу. Бывший активный MOB
  перед удалением отдаёт копии статических визуалов с уже загруженными общими
  mesh/texture. Используемые составные текстуры удерживаются арендами.
- Содержимое MPR/MOB получает SHA256. Мемоизация SHA допустима только при
  неизменном native file ID, ChangeTime, размере и mtime Windows; изменение
  с восстановленными размером/mtime также обнаруживается. На других системах
  неподтверждённый native epoch не позволяет reuse хеша без чтения.
- Terrain key включает canonical path/content MPR и содержимое выигравших MMP
  страниц собственного атласа. Изменение чужого атласа в общем RES обновляет
  epoch/индекс, но сохраняет итоговый ключ неизменных страниц других карт.
  MOB/визуалы имеют отдельный ключ; публикация в HDPack_Terrain не заменяет
  статические объекты остальных карт. Видимость объектов проверяется заново
  относительно каждой новой активной карты, даже если они уже есть в кэше.
- Встроенные глобальные семейства и authored transitions собираются один раз
  из неизменного встроенного каталога. Привязки к дисковым атласам сохраняют
  действующие проверки; локальная палитра/семантика новой активной карты
  по-прежнему устанавливаются для её собственных данных.
- Завершённые глобальные material sources/identities повторно используются
  по отпечатку их фактического источника, предпочтительному namespace и размеру
  тайла. Для настроенного reviewed reference публикация другого атласа в HDPack
  не меняет этот ключ. Дополнительные палитры ограничены8 записями/64МиБ.
  Устранена квадратичная дедупликация кандидатов при сборке/гидратации каталога.
- Поле солнца остаётся у terrain state. Простое восстановление неизменного
  world document больше не инвалидирует его. Реальное изменение высот/покрытия
  или направления солнца сохраняет штатную инвалидацию.
- Разные активные MOB могут иметь разное солнце: для возврата сохраняются
  последние8 полей на карту. Общий CPU LRU128МиБ дополнительно связывает поле
  с фактическими высотами/покрытием и направлением. Поэтому смена атласа или
  новое чтение тех же высот не требуют нового трассирования рельефа; новое
  направление вычисляется один раз, изменённые высоты имеют другой отпечаток.
- Combined CPU/GPU budget renderer cache —1536МиБ, оценка консервативная:
  секторные CPU/GPU-буферы, атласы/тени, preview images, статические визуалы,
  pending uploads и удерживаемые текстуры. Невидимые записи вытесняются по LRU;
  текущие видимые карты закреплены. Поэтому бюджет ограничивает дополнительное
  удержание, а не запрещает показать сцену, которая сама больше бюджета.
  Журнал содержит chargedMiB/budget/evictions. При смене профиля и завершении
  все GL-владельцы освобождаются в контексте CView.
- На время одной workspace-транзакции вытеснение откладывается: все прежние
  фоны временно перестают быть видимыми, но ещё нужны для нового расположения.
  После выбора активной карты и её фонов LRU применяется вновь. Явный Discard
  инвалидирует снимки отвергнутых правок, dirty MOB после отказа от Save не
  становится снимком «сохранённого» фона. Перед переносом активных данных
  проверяется их соответствие текущему дисковому baseline.
- Размеры мира также ключуются содержимым MPR. Замена с прежними size/mtime
  не оставляет старую геометрию соприкосновения в metadata cache.

- Чистый editor preview освобождается перед превращением активной карты в фон,
  если её уже загруженный базовый атлас соответствует дисковому baseline.
  После перепаковки Save этот флаг сбрасывается: новый preview сохраняется до
  свежего чтения, старый base не может подменить сохранённое изображение.
  Несохранённая общая покраска сохраняет свой preview. Общие QImage пиксели
  палитры учитываются один раз; снимки не вытесняются из-за повторного учёта
  буфера, уже принадлежащего основному кэшу источников. При смене источника
  все зависимые палитры/привязки/пиксели инвалидируются вместе.
