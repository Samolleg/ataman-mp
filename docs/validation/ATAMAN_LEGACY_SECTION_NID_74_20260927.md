# EI-LEGACY-LIGHT-NID-COLLISION — проверка версии 74

Исходный случай: `MODS/test/Maps/zone1.mob` имеет колонну с ID 335 и старую запись Light-335. До исправления `--validate --json` не сообщал об этом совпадении. Реальное действие копирования, породившее старую карту, по журналу не восстановлено. Игровые и пользовательские MOB не изменялись.

Причина: строгий парсер считал секции LIGHT_SECTION, SOUND_SECTION и PARTICL_SECTION непрозрачными и не извлекал ID. Подбор ID в CMob и семейном валидаторе видел только обычные объекты. Массовая перенумерация также не проверяла локальную занятость семейного предложения.

Исправление: соответствующие контейнеры разбираются с сохранением исходных байтов; ID старых технических записей занимают то же пространство идентификаторов для создания, копирования, массовой перенумерации и семейного подбора. Диагностика сообщает о конфликтах; старые записи доступны только для чтения при предложении ремонта. Никакого автоматического изменения старых записей нет.
