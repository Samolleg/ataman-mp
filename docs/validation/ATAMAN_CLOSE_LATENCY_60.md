# EI-CLOSE-LATENCY-60

Дата: 2026-09-24. База: версия 59, commit `dcef99ab041c4cf95e75284639042b5306884e4d`.

Исходный журнал установленной версии 58 `artifacts/EI-Mapper-Ataman-2-first-test/logs/workflow-20260923-230124.log` фиксирует 40 мс в теле `CView::~CView` и 25960 мс на полное удаление viewport. Отдельная диагностическая сборка версии 59 повторила случай на zone15.mpr/zone15.mob из JamaisVu135, прочитанных без записи: после подготовки персонажей 1447 общих моделей, 67,97 МБ, тело деструктора 57 мс, поля 73 мс, сигнал уничтожения GL-контекста через 6745 мс, полное удаление через 6749 мс. Журнал: `build-audit-58-20260924/package-probe/zone15-glprofile.log`.

Снимок стека главного потока во время задержки (`build-audit-58-20260924/package-probe/zone15-gdb3-stack.txt`) показывает `nvoglv64!DrvReleaseContext` → `opengl32!wglMakeCurrent` → Qt `QOpenGLContext::doneCurrent` → callback `QOpenGLVertexArrayObject` при `QOpenGLContext::destroy`. Это конкретная тормозящая операция после уничтожения полей CView, а не ожидание фоновой работы. Каждая из тысяч сохранённых VAO-обёрток регистрировала callback контекста, который при уничтожении переключал драйверный контекст.

Исправление: после удаления MOB, пока GL-контекст ещё действует, удалить VAO-обёртки удержанных моделей и очистить их коллекции. VBO и остальные GPU-ресурсы остаются на прежнем штатном пути освобождения контекстом; очередь задач и сохранение данных не меняются.

Контрольный автоматический запуск с полной подготовкой 101 персонажа: zone15, 2171 общая модель, 104,56 МБ; явное освобождение VAO заняло 16 мс, уничтожение остальных полей 295 мс, сигнал `aboutToBeDestroyed` через 296 мс и уничтожение контекста через 300 мс. Процесс завершился штатно. Проверка выполнена на NVIDIA GeForce RTX 4070 SUPER, драйвер OpenGL 591.44. Измерение относится к диагностической сборке с таймерами; окончательный код без таймеров требует повторного прогона и широкого регресса.

Данные игры и исходный Endurance не изменялись. Проверка в пользовательской интерактивной сессии и на других видеодрайверах остаётся открытой.
