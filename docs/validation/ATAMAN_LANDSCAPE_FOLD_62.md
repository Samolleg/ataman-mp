# EI-LANDSCAPE-FOLD-WIDTH-62

Дата: 2026-09-24. База: версия 61, commit `0d6bb0f079247eb21520946858047571bf021032`.

Встроенная `--ui-widget-check` на установленной версии 58 и свежей диагностической версии 61 в текущей среде возвращала `landscapeRedesignGeometry=0`. При ширине 320 пикселей раскрытие двух разделов инструментов ландшафта добавляло 15 пикселей горизонтальной прокрутки. Измерение вложенных элементов показало минимальную ширину 297 пикселей при ширине области прокрутки 282 пикселя; до раскрытия прокрутки не было. Снимки диагностического запуска сохранены в собственной папке `build-audit-58-20260924/package-probe/ui-61-shots`.

Исправление: раскрываемый раздел использует горизонтальную политику размера `Ignored`, сохраняя вертикальную `Maximum`. Содержимое может сжиматься до ширины панели, вертикальное раскрытие и кнопки остаются штатными. Диагностическая сборка с этой единственной UI-правкой вернула `--ui-widget-check` exit 0 и `landscapeRedesignGeometry=1`; прочие проверки той же команды также прошли. Окончательная свежая сборка версии 62 и ручная оценка читаемости остаются следующими шагами.
