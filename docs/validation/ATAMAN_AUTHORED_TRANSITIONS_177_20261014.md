## Причина и изменение программы

Сохранённые zone11 тайлы177/392 воспроизводят исходный дефект без генерации.
Их происхождение ведёт в `zone11_96774500b145`, где рядом с исходными авторскими
тайлами находятся математические переходы. В старом `zone11` есть реальные
переходы Stone / Gray + Snow / Common с рваным рисунком. Номер первой версии,
создавшей конкретные сохранённые дуги, не установлен.

В коде131 `resolve()` уже умел находить утверждённую маску без материала кисти,
но `reviewGeneratedBlend()` и `worldBoundaryTile()` обходили это правило:
общий `reviewedMaskStyleMaterial()` разрешал контекстный fallback только для
частного случая Ice. Теперь один и тот же поиск прежней утверждённой маски
используется всеми этими путями. Существующие формулы геометрии не менялись.

Для многоматериальных стыков доступный вариант выбирается отдельно по каждой
авторской маске: отсутствие первого варианта грунта не подменяет его кругом,
когда в ресурсах утверждён только второй вариант. Явные предпросмотры кисти,
runtime-классы поверхности и приоритет существующих точных тайлов сохранены.
