# EI-WORLD-BRUSH-ZONE4-QUARTER-RIM — проверка 2026-09-26

Сообщение владельца: общая кисть меняет рельеф рядом с zone4, но оставляет границу. В журнале установленной v71 10:39–10:40 мазки завершились с `maps=1` и `maps=3`, `protectedBoundarySamples=0`; эти счётчики сами по себе не подтверждают правку кромки. Запись пользователя не использовалась как источник координат мазка.

Из `world-map-layouts.json` только чтением получены origin zone6 `(704, 63.5)` и zone4 `(960, 189.25)`; номинальные границы совпадают при X=960. Сетка Y сдвинута на 0.25, а MPR хранит XY-смещение целым числом с масштабом 1/254. Для парных вершин точные одинаковые XY недостижимы. Исходный тест на реальных MPR до изменения кода: `installedZone6Zone4QuarterShiftReadOnly` — FAIL, «Положение соседних карт не позволяет точно совместить вершины в формате MPR». После допуска округления выяснилась вторая причина: защита смещённого края оставляла кромку zone4 без изменений при мазке Raise; проверка изменения обеих кромок — FAIL.

Исправление: для локально согласуемых парных вершин обе карты сохраняют ближайшее представимое смещение, а план всех шести кистей использует одну логическую координату узла. Защита несовместимых цепочек по-прежнему действует, но не замораживает узлы, уже совместно согласованные на разрешённых картах. Отключённая соседняя карта не меняется. Программа не переписывает размещение карт или игровые файлы автоматически.

Проверка после исправления: 39 тестов `world_terrain_sculpt_tests` — PASS, 0 FAIL, 0 SKIP.
