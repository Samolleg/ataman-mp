## Разрядность и формат

Проверено без запуска маппера:

- Канонический доступный kit из EI_MAPPER_QT_BIN / EI_MAPPER_MINGW_BIN:
  Qt 5.12.12, QMAKE_SPEC `win32-g++`, `g++ -dumpmachine` →
  `x86_64-w64-mingw32`.
- `objdump -f` установленного EIMapperEndurance.exe → `pei-x86-64`.
  Менять разрядность маппера не требуется.
- DetourNavMesh.h при DT_POLYREF64 использует uint64_t для dtPolyRef/dtTileRef.
  Фактическая совместимость нативного tile payload MSVC producer / MinGW reader
  ещё не проверена сборкой и тестом; одной разрядности для такого вывода мало.
- README описывает container v1 / algorithm 4 / library 0x010600,
  little endian, polyrefBytes=8, профиль и fingerprint; координаты game Z-up
  преобразуются в nav `(x,z,-y)`.

**Вопрос контракта выбора файла:** описанный container v1 не содержит имени
сцены/карты. Имя файла — fingerprint. В fingerprint входят нормализованные
геометрические входы и настройки, которыми маппер сейчас целиком не располагает.
По одному заголовку нельзя надёжно связать произвольный файл из каталога с
открытой картой. Нельзя брать первый файл, угадывать по дате или считать его
подходящим только по границам. Нужен согласованный индекс сцена → fingerprint
от запекателя либо явное решение о метаданных/выборе файла. Это открытый вопрос
контракта, а не реализованная эвристика. Статус актуальности до полноценного
расчёта fingerprint должен оставаться «не проверено».
