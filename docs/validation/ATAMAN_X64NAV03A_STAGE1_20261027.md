## Реализованное поведение

- Только container3/algorithm7, Detour1.6.0/DT_POLYREF64, little endian.
  Списки поддерживаемых версий — nav64SupportedContainers/Algorithms в одном
  модуле; неизвестные/старые варианты дают просьбу перепечь/обновить маппер.
- LZMS через системный cabinet.dll по абсолютному System32-пути. Проверяются
  лимиты/длины, неизменённый заголовок и размеры массивов до unshuffle;
  затем индексы/float/detail/BV/ABI и отсутствие служебных firstLink до addTile.
  Detour сам восстанавливает связи. Чисто CPU-загрузка в QtConcurrent.
- Единственная функция findNav64ForScene сопоставляет встроенные MPR/MOB/profile;
  имя файла только ускоряет поиск. При резервном поиске дубликаты отвергаются.
  Cache64/Nav не используется.
- Док Navmesh рядом со старой панелью AI и в меню инструментов:8 профилей,
  радиус/высота, detail-треугольники по областям, рёбра и тайлы; переключение
  старого AI-графа/Navmesh. Исходный MOB и его AI-граф не изменяются.
- Геометрия группируется по тайлам; вне frustum не отправляется в OpenGL.
  Острова — связность Detour по всем высотным флагам, маркер на компоненте
  вне крупнейшей. Узкие порталы — приблизительная подсказка по длине ребра
  относительно диаметра на уже эродированной сетке. Это не измерение сырого
  прохода, не анализ конкретной позы и не игровая приёмка пути.
- Актуальность приблизительна по mtime MPR/MOB/.navsrc и несохранённым правкам.
  Полный fingerprint не вычисляется: нормализация эффективной геометрии,
  моделей, архивов и настроек остаётся у EIRebuild64. Изменение модели либо
  сохранение исходного mtime этим индикатором не обнаруживаются.
- Одна граница запуска startBake: QProcess, CREATE_NO_WINDOW, аргументы
  передаются списком; путь настраивается, default game-root/Engine64.
  --output-root — корень вывода: producer добавляет Maps/Nav64 сам.
  По умолчанию это корень мода. Перед перезаписью создаются штатные
  CBackupManager snapshotBeforeSave, leases держатся до завершения процесса.
  Только явная кнопка владельца разрешает продуктовую запись в мод.
- Журнал PROFILE/MAP_DONE/MAP_ERROR/MAP_MISSING/BAKE_DONE, отмена только
  принадлежащего панели процесса. Успех: normal exit0 + BAKE_DONE с
  completed=maps, missing=0, errors=0. Частичный журнал/код5 не являются успехом.
  После успеха слой повторно читается из каталога вывода для той же пары карт.
- .navsrc: только отключённое место в UI/коде. Формат/семантика авторинга открыты.
