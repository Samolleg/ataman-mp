# Ataman170: сохранение сцен соседей при навигации

Задача EI-NEIGHBOR-SCENE-REUSE-170, 2026-10-13. Принятая база main
`805d5f03ea299040a16546f4d16ccb97251bd7dc`, установленная169.
Поручение: исправить полную повторную загрузку соседей при переключении активной карты.
Владелец остановил дальнейшие тесты и выбрал собственную интерактивную проверку.

## Изменение

Навигация сохраняет готовые фоновые ландшафты, атласы и объекты остальных карт,
переносит их относительные смещения. Один фон активной карты удерживается для
обратного перехода. Изменение ближнего/дальнего положения и MOB обновляет объекты
отдельно от ландшафта. Изменение MPR, профиля или ресурсных источников инвалидирует
соответствующий кэш; незавершённая публикация и отменённые CPU-работники не принимаются.
Обычное открытие/выключение фона/завершение освобождают сохранённые сцены.
Рабочая модель общей кисти удерживается вместе с её preview; камера сохраняет
абсолютные координаты. Активная карта загружается обычным редакторским путём.

- Fresh Release170 и текущие x86 runtime-компоненты собраны из изолированной копии
  принятой базы плюс файлы этой задачи. Исходники сборки сверены с рабочими файлами.
  Журналы: `build-neighbor-170-20261013/build-release.log`,
  `build-release-repair1.log`, `validation-identity.json`.
- Первый native сценарий через настоящий MouseButtonDblClick и production
  MainWindow завершён без функциональных отказов: A→B→A→B на трёх приватных копиях
  реальной zone1. Карта C сохраняла CLandscape, GPU-атлас, все1532 фоновых объекта
  и исходный CNode. Несохранённая общая правка, её Undo/Redo и камера сохранились.
  Проверены дальняя/ближняя роль, MPR/MOB revision и отмена worker-поколения.
  Это исходная сборка170 до последнего усиления проверки публикации; результат
  не обозначает приёмку финального EXE. Журнал: `nav-reuse.stdout.log`.
- В финальном EXE те же три настоящих перехода подтвердили сохранность ландшафта,
  атласа, объектов, камеры и общей правки; Cancel обычного открытия сохранил текущее
  рабочее пространство. Native снимки `nav-reuse-final/before-c.png` и `after-c.png`
  содержат реальную сцену и просмотрены. Строгое равенство пикселей выделенной области
  дало FAIL; причина различия не установлена, визуальная приёмка остаётся открытой.
  Повторный native прогон остановлен по прямому указанию владельца, поэтому он
  не PASS. Его оставшиеся проверки, отдельный UI-widget-check и новая интерактивная
  проверка не выполнялись. Журнал: `nav-reuse-final.stdout.log`, exit=-1 после
  завершения только собственного скрытого процесса.
- Qt NeighborPerformanceTests:6 PASS/0 FAIL; четыре существующих контракта
  навигации/камеры/ввода/освобождения ресурсов PASS. Отдельные unit/контрактные
  результаты не заменяют native или интерактивную приёмку.
- Игровые оригиналы и пользовательский маппер не изменялись тестами. Работа
  выполнялась лично, без делегирования; посторонние правки сохранены.
