# Исправление витрины Ataman 89

Задача EI-GALLERY-PERFORMANCE-89 начата2026-10-01; проверки и передача продолжаются2026-10-02. База аудита:5e5d462737032b71ae016a58f4c5b8c74e48f94d, ветка `codex/gallery-performance-v89`. Поручение владельца — «исправляй» после измеренного аудита88.

## Причины и изменения

- G1: тысячи строк добавлялись в подключённую модель QComboBox/QCompleter. Теперь список с теми же raw ID, группами и невыбираемыми заголовками строится отдельно и подключается целиком. Исходные модель/текстура передаются конструктору из создания и свойств, исключая второе заполнение при открытии.
- G2: подходящие текстуры повторно вычислялись для готовых плиток. Результаты, включая пустые, кэшируются на окно; revisions каталога/scanCache обновляют этот кэш. Повторные неизменные иконки не присваиваются.
- G3:40мс паузы между заданиями и потеря всех кэшей при закрытии. Следующая видимая плитка ставится в очередь без искусственной паузы; одновременно один CPU worker. Общий кэш изображений ограничен64MiB, два набора ресурсных индексов/сцен/текстур сохраняются между окнами (по16/32MiB на набор). Набор определяется порядком путей, размером и временем изменения RES; модель и текстура входят в ключ картинки. Смена ресурсов, профиля или назначения не использует чужую картинку. QObject/view/GL не используются в worker.
- Свежий scanCache из JSON восстанавливается при открытии витрины свойств и сохраняется в снимке панели после завершения диалога. Условное чтение изменённых MOB остаётся отдельным GUI-сканером; это не объявляется устранением неподтверждённой гипотезы повторного чтения всех MOB.
- G5: функциональный регресс дополнен497 моделями/7165 текстурами, бюджетами открытия/выбора/поиска, группами/автодополнением, начальным выбором, видимой очередью, прокруткой/возвратом/повторным открытием, сменой ресурсов/текстуры/каталога. Сохраняются исходные проверки русских имён, категорий/островов, сохранения JSON и Esc.
