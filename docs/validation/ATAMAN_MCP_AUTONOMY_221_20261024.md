## Результат и база

Выполнен автономный путь подготовки MPR/MOB через MCP без управления окном,
мышью и буфером. База main `1d141383ea2adc60e5cc94b181ed3387f29d261e`,

- create_map работает при пустом редакторе: явная MPR профиля, текущая чистая
  MPR либо первая по имени в доступном mapRoot. Используется buildNewCanvas/
  commitNewTerrainCanvas213. Источник не изменяется; имя допускает дефис.
  Явный template не подменяется другим ради материала: при отсутствии
  однородного тайла предлагается создать без material и затем покрасить.
- open_map/close_map — асинхронная навигация по ключу каталога, имени файла
  или зоны. Перед сменой отклоняются dirty MPR, соседние документы, MOB,
  travel, БД и черновики скрипта. Primary MOB берётся из раскладки или
  одноимённого файла; MPR без MOB тоже открывается для create_mob.
- place_map_in_world/set_world_position — активная или выбранная карта,
  абсолютные координаты либо сосед N/S/E/W с выравниванием края. Размеры
  читаются из MPR; пересечения площадей запрещены. Опорный ID и все изменения
  сохраняются через тот же CWorldMapLayoutDocument::applyChanges, что и ручное
  размещение: compare/lock/QSaveFile и резерв миграции. Игровые map.txt/MOB
  координаты для размещения не переписываются.
- create_mob — пустой основной MOB рядом с активной MPR. Параметры217 читаются
  из MOB профиля с явными copy-флагами; объекты/AI/VSS не копируются. Добавление
  связи MOB в раскладку входит в операцию; при отказе этой записи созданный
  MOB выгружается и удаляется с проверкой владения. Неполный rollback явно
  возвращается как ошибка с путём. Save использует штатный MPR и MOB save.
- Начальные записи MPR/атласа, MOB и мира требуют человеческой галочки Save
  как при запросе, так и перед commit. API не включает режимы и не запускает
  редактор. Навигация очищает прежнюю историю; остальные операции имеют одну
  Undo там, где применимо. Undo создания сохраняет начальные файлы на диске,
  как219. MCP Undo раскладки требует Save; конфликт внешней записи возвращает
  ошибку. Диалоги решений скрываются/отклоняются, агент получает понятную ошибку.
