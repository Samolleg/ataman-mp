# EI-WORLD-BRUSH — Ataman 40, 2026-09-20

Ветка codex/world-landscape-brush. База пользовательской 37, DEFAULT38,
TOOLS39 (6159de0d), SEAMS40. Пользователь разрешил все три пункта и обновление
постоянной программы. Исходный Endurance и игровые данные не изменялись.

## Реализовано

1. Общая кисть включена по умолчанию, все доступные карты выбраны; ручные
   исключения сохраняются. Соседние документы подгружаются по области мазка.
2. Общие высоты, Noise, скульпт покрытий, Modern/Classic/Manual,
   создание/удаление покрытий. Отдельные атласы и таблицы жидкостей каждого MPR.
   Общий мазок планируется до применения и отменяется целиком. Смена режима
   не закрывает сессию. Центр кисти может быть за границей текущей карты.
3. Ремонт переходов сравнивает материалы по мировому соприкосновению карт,
   считывает собственный атлас соседа, включает изменения поля в Undo ремонта.
   Зазоры, перекрытия, углы и неоднозначное сопоставление исключены.

## Сохранение

MPR и RES подготавливаются и перечитываются до commitMapSaveBatch; внешний
конфликт, разные данные одного namespace или неготовый ресурс отменяют запись.
Неизменённые DXT-блоки сохраняются. Каждое сохранение создаёт резервные копии.
Успешная публикация всех карт — checkpoint: очищается история общей кисти,
о чём предупреждает диалог. Это не атомарность файловой системы между томами.
Поле материалов теперь сериализуется по размерам сетки тайлов, не высот.

## Границы доказательств

материалов/карт и игровая загрузка сохранённого мира не проверены автоматически.
Синтетический roundtrip подтверждает структуру MPR+атлас+покрытия; не является
проверкой игры. Полная UI-публикация в живые ресурсы не запускалась.
