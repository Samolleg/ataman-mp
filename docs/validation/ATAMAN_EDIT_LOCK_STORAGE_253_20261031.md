# Ataman253 — служебная папка блокировок, 2026-10-31

Поручение: убрать появившиеся рядом с MPR файлы `.mapper-edit.lock`, сохранив защиту от одновременного редактирования. База main `0dbceb5b1668a96d4e9ef7d0464743ec8b64c8a4` /252. Работа не изменяет игровые документы, профиль, данные мода или настройки владельца.

`CProcessEditLock` хранит lifetime edit/resource leases в `.mapper-service/locks` физического каталога документа; имя содержит SHA256 канонического пути и тип замка. MPR и одноимённый MOB по-прежнему разделяют замок. Хранилище определяется документом, а не установкой, приложением, профилем или Windows-пользователем. Отказ создания папки/файла блокирует операцию; запасного незаблокированного пути нет.

Адресная проверка обнаружила, что Qt5.12 `QFileInfo::canonicalFilePath` не разрешает каталог junction. Для хешируемого ключа это давало два разных имени. Физический путь теперь читается через Windows `GetFinalPathNameByHandleW` с разделяемым дескриптором без доступа к данным; для новых целей разрешается ближайший существующий родитель. Сохранённый MinGW7.3 требует динамического получения адреса функции. Исправление проверено с существующей MPR и созданием новой MPR через junction; тест удаляет только собственный junction без обхода цели.

Native `process_edit_lock_tests`: **12 PASS / 0 FAIL / 0 SKIP** (включая init/cleanup). Проверены отсутствие sidecar среди документов и неизменные байты MPR/MOB, общий MPR/MOB-ключ, регистр/`..`, другой процесс и копия EXE с другим именем приложения, независимость разных карт/RES, удержание до последней ссылки, отсутствие смены ключа при создании файла, аварийное завершение собственного процесса и восстановление, живой/аварийный старый edit/resource-sidecar, отказ при недоступной служебной папке, junction для существующей и новой карты.

Native `minimap_export_tests`: **21 PASS / 0 FAIL / 0 SKIP**. Связанный регресс проверяет отказ экспорта при занятом новом resource-lock и прежнем save-lock, неизменные байты при отказе, успешный экспорт после освобождения, коллизии/внешние изменения, атомарную публикацию и сохранность других членов RES. Оба набора используют только синтетические данные в собственной рабочей временной папке. Полный большой headless225-набор и несвязанные GUI/игровые наборы не запускались.

Предупреждение: в `resourceAndSaveLocksRefuseExport` Qt сообщил невозможность сразу удалить собственную временную backup-папку; после завершения в ней остались только пустые каталоги, без файлов замков и документов. `CBackupManager::scheduleCleanup` использует фоновый QtConcurrent. Это отдельная гонка очистки тестовых директорий; функциональные проверки экспорта прошли, программа ради её устранения не менялась. Журналы и исходные результаты сохранены в `work/edit-lock-storage-253/`.

Миграция: новый процесс учитывает уже существующий старый sidecar, а оставшийся после аварии снимает штатным QLockFile. Все одновременно используемые редакторы должны быть253 или новее: старый редактор, открытый после нового, не знает новое хранилище. Массового удаления старых файлов в живых картах нет; восстановление происходит при открытии соответствующего документа.

Сборка и установка: ожидаются. Следующий шаг — чистый source archive, свежая Release253 со штатными runtime, проверка raw/staged версии и SHA, finalizer против принятой252 и guarded installer в постоянную папку. Интерактивный редактор/игра не запускались; ручная приёмка остаётся владельцу.
