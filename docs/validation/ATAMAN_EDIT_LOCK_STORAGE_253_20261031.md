Поручение: убрать появившиеся рядом с MPR файлы `.mapper-edit.lock`, сохранив защиту от одновременного редактирования. База main `0dbceb5b1668a96d4e9ef7d0464743ec8b64c8a4` /252. Работа не изменяет игровые документы, профиль, данные мода или настройки владельца.

`CProcessEditLock` хранит lifetime edit/resource leases в `.mapper-service/locks` физического каталога документа; имя содержит SHA256 канонического пути и тип замка. MPR и одноимённый MOB по-прежнему разделяют замок. Хранилище определяется документом, а не установкой, приложением, профилем или Windows-пользователем. Отказ создания папки/файла блокирует операцию; запасного незаблокированного пути нет.

Адресная проверка обнаружила, что Qt5.12 `QFileInfo::canonicalFilePath` не разрешает каталог junction. Для хешируемого ключа это давало два разных имени. Физический путь теперь читается через Windows `GetFinalPathNameByHandleW` с разделяемым дескриптором без доступа к данным; для новых целей разрешается ближайший существующий родитель. Сохранённый MinGW7.3 требует динамического получения адреса функции. Исправление проверено с существующей MPR и созданием новой MPR через junction; тест удаляет только собственный junction без обхода цели.
