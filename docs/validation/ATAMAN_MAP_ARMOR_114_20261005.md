# Ataman114: добавление брони из каталога предметов

Задача EI-MAP-ARMOR-114, поручение владельца2026-10-05. База main
d8e8503d9ba053912b3c77960d39d12254ab3710;113→114. Игровые данные только
читались на месте, приватные исходники не исследовались. Исходная проблема:
MapWeaponCatalog принимал только db_weapons/Weapon и исключал db_armors.

## Результат реализации

- «Создать → Предметы» принимает оружие и броню из mapweapons-catalog.json
  рядом с активной БД и модели из указанного mapweapons.res.
- Все7 типов: шлемы, доспехи, поножи, рубахи, штаны, сапоги, перчатки.
  Русские названия/поиск и название с выбранным материалом из texts.res.
- Armor metadata необязательна для прежнего schema2 weapon-only каталога.
  При наличии проверяется договор items.armors; связи проверяются по имени,
  armor_type, model_index, texture_variant и material_type активной БД.
  Устаревшие связи исключаются. Архивы/каталог не сканируются по MOB и не пишутся.
- Общая геометрия нижней брони берётся из каталога; индекс и вариант текстуры
  принадлежат конкретному предмету БД, а не имени общей модели.
- DejaVu: оружие/шлемы используют .x2, остальные типы брони .x4. Это соответствует
  существующему equipmentTextureName в profile_visual_resolver_support.cpp.
  Обычный профиль использует имя без high-resolution суффикса. Исходные UV
  полного атласа сохраняются, map-текстура автоматически не изобретается.
- Размещение штатным обычным объектом, точные primary/secondary texture и код
  предмета/материала; Escape, ID, Undo/Redo и сохранение MOB сохранены.
