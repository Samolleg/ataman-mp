## Причина и изменение

buildLandTex возвращал один сырой указатель нескольким картам из кэша.
clearNeighborLandscapes сравнивал glTexture соседей только с glTexture активной
карты. При наличии рабочего атласа активной карты это другой указатель:
общая исходная текстура попадала в releaseTerrainTexture и удалялась.
m_baseAtlasTexture активной карты оставался висячим. Эта последовательность
в коде подтверждена; сам освобождающий вызов не восстановлен из crash dump.
Есть второй дефект старого алгоритма: glTexture соседа может быть рабочим
атласом, который уже удаляется деструктором CLandscape.

Теперь buildLandTex приобретает ссылку при создании и каждом cache hit;
unloadMpr освобождает свою исходную текстуру. Последний владелец удаляет её
из кэша и GPU. CView только освобождает владельцев карт. Предпросмотры по-прежнему
принадлежат конкретной карте. Ключ кэша имеет terrain-префикс и число страниц.
