# Ataman 169 — область удаления поверхности

Поручение: в168 при «Удалить поверхность» нет области под мышью. База main `4c45e55cb2668168bed9920bc339052993c3861b`, программа168. Исправление лично; игровые оригиналы только читать. Native использует собственные копии zone1.mpr/HDPack_Terrain.res, изменения только в памяти, без сохранения игровых данных.

## Причина и исправление

Cell-preview требовал выбранный материал даже для удаления топологии. Рамка удаления теперь независима от материала/миниатюры; текстурная плитка-превью для удаления не показывается. Подбор удаления следует реальному лучу поверхности, затем земле в пустом месте. Перенос XY земля→поверхность оставлен только добавлению: для удаления этот перенос смещал рамку от мыши при разных высотах. Кэш точки сбрасывается при изменении поверхности. Неподвижный press/release сохраняет XY первого штампа до окончания жеста, чтобы удаление центра не добавляло второй штамп по открывшейся земле. CPU-точка края принимается только на луче мыши; при неточной точке применяется существующий точный overlay pick.
