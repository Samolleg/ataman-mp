не означают, что луг надо нарезать на одинаковые квадраты такой площади.

Пресеты `plain`, `hills`, `mountains`, `coast`, `swamp`, `river_valley` содержат
масштаб/амплитуду, долю ridged, warp, непрерывные уступы, уровень воды и пороги
материалов. Калибровка задаёт характерные масштабы и правила; точного совпадения
гистограмм каждой авторской карты не заявляется. Сухая равнина поднята над водой,
для реки выбран грунт, для моря песок; камень следует крутизне, дорога остаётся
на суше. Все параметры и ID материалов можно переопределять.

## Реализация

- Отделённая метровая сетка: пятиоктавный fBm с поворотом октав, ridged-компонента,
  domain warp, изломанные непрерывные уступы, берег/бухта, заболоченная низина,
  долина, явно заданный уступ. Детерминированный seed, без повторяющейся синусной
  решётки куполов219.
- Ограниченная термальная эрозия переносит материал вниз; гидравлическая модель
  распределяет воду, переносит взвесь и осаждает её при падении ёмкости потока.
  Русло по линии имеет меняющуюся ширину, монотонное дно, склоны и пойму.
- Автопокраска: высота, уклон, кривизна, близость к уровню воды и вычисленный
  сток; пространственно связный шум порогов, ordered rules, варианты, тропа по
  линии. Штатные shared corners, авторские источники и Modern131 resolver.
  Необязательная настоящая вода через native overlay activation/flatten.
- `generate_terrain`, `erode`, `carve_river`, `auto_paint` в прежнем worker219:
  актуальная revision, preview/apply, одна Undo «ИИ: …», отмена/отключение до
  commit без частичной правки, общий стык через131/215. Старые tools сохранены.
- Новые пиксели auto_paint приводятся к DXT1 до применения кандидата; точные
  сжатые блоки удерживаются до штатной публикации. Это устранило обнаруженную
  разницу изображений до/после Save. Старый serializer не заменён.

[Аргументы и пример карты по заданию](../AI_AGENT_MCP.md#природный-рельеф220).
Человеческая кнопка отложена: следующий шаг — диалог пресета/seed/параметров в
панели ландшафта поверх этого же расчёта и истории.

## Снимки и оценка

Настоящий скрытый desktop GL маппера220, без запуска старой сборки или игры.
Слева эталон Dejavu, справа новая карта8×8; сверху вертикальная камера, снизу
наклонная. Полные framebuffer и центральные квадратные вырезки сохранены в run7;
композиции ниже только размещают пиксели рядом. Полные размеры эталонов различны,
снимки нормированы камерой к их протяжённости, это не сравнение в одном масштабе.
Объекты/деревья не подставлялись: проверяется рельеф и подложка.

Оценка: исходные одинаковые купола заменены связанными неровными формами,
площадки чередуются с уступами; камень следует склонам, река имеет берег/пойму.
Горы дают читаемые гребни и проход. Побережье заметно улучшено после первого
варианта, но оно положе и проще островного/болотного эталона zone7; луг и
экологическая композиция менее разнообразны авторских карт. Это рабочая основа
для дальнейшего редактирования, не утверждение о равном художественном качестве.
Игровая и художественная приёмка владельца не выполнялись.

## Сборка и передача

Qt5.12.12/MinGW7.3 x64, штатные x86 runtime-компоненты. Release из git archive;
исправленные inputs также перенесены только через git archive, после каждого
относящегося изменения пересобраны. Каталог:
`build-natural-terrain-220/source3/build-release-220`. Финальные production inputs
сверяются с main; описание MCP отдельно проверяется после исправления anyOf для
пересекающихся схем preview. Данные алгоритмов run7 при этом не менялись.

Свежий staging: `build-natural-terrain-220/build-staging-220-natural-terrain`.
Raw/staged SHA, обе версии220, manifest и finalizer — в
[stage receipt](../../build-natural-terrain-220/stage-receipt.json).
После финализатора staging не запускается. Полный SHA scoped-коммита main и
production identity — в [commit receipt](../../build-natural-terrain-220/commit-receipt.json).
Автор/коммиттер Codex &lt;codex@localhost&gt;, требуемый Co-Authored-By сохранён.
Чужой хвост ROADMAP побайтно сохранён и исключён из коммита, `.mcp.json` не добавлен.

Ограничения: одна рабочая сетка до1100000 отсчётов/256 секторов; эрозия приближённая,
