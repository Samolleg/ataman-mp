# Ataman183 — глубина земли в выделении мышью

Дата2026-10-15. EI-RECT-SELECTION-183, продолжение EI-RECT-SELECTION-REGRESSION-182. База main4a6847a7431b8b77ee134f8f6cac6a3649818fac/182. Поручение владельца: найти причину полного пути выделения рамкой, когда выбираются соседние объекты снаружи, и исправить. Реализация лично в main; игровые оригиналы и чужие изменения сохранены.

## Причина и путь

Запись20261015-1202-31.6910125.mp4 показывает182/zone3obr: рамка по земле ниже частокола, после отпускания выбран частокол. Прежняя правка116 сохранена; это не повторная потеря alpha cutoff или преобразования QRect. См. ATAMAN_RECT_SELECTION_RECHECK_182_20261015.md.

CView::mousePressEvent/mouseMoveEvent/mouseReleaseEvent → COperation → CSelect сохраняют собственный anchor и передают одну нормализованную QRect. CView::pickObject создаёт query FBO и раньше очищал его depth, затем рисовал только модели. В отличие от видимого кадра, глубины земли там не было. Заглублённые полигоны модели получали корректный ID в экранной области, где пользователь видел только землю. getColorFromRect считывал этот ID внутри правильной рамки, сопоставление отмечало весь объект, затем recordSelectionChange/нормализация сборок/панель сохраняли результат. Первое неверное состояние — отсутствие видимого рельефа в depth query, до рендера ID.

Механизм доказан на собственной плоской карте: mesh post пересекает землю; independent reference без земли содержит ID в рамке, reference с глубиной земли не содержит ни одного. В182 полный press/move/release всё равно выбирает post. Затем узкая надземная модель внутри той же рамки даёт именно смешанный случай: inside+посторонний post в182, только inside в183. Геометрия, shaders и команды используются production. Условия записи воспроизведены этим контрольным сценарием; точный исходный жест/камера/ID объектов zone3obr из записи автоматически не повторялись и остаются ручной приёмкой владельца.

## Исправление

CView::drawSelectionTerrainDepth использует тот же CLandscape/CSector draw и мировые transforms, что видимый кадр. Перед ID-проходом заполняется только глубина видимой земли, цветовая запись отключена и восстановлена. Активная карта и видимые соседи учитываются с frustum culling; скрытая/выключенная земля не препятствует выбору. Прозрачные покрытия не добавлены как непрозрачные препятствия. Helper применяется обоими picking overload: рамка/обычный клик и выбор из переданного списка. Путь alpha/UV, коллекции, сборки, команды истории и панель182 не изменены. Нет нового ядра переходов, изменений игровых данных или сериализации.
