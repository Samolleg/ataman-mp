## Воспроизведение и исправление

Новый содержательный QTest на коде95: старый JSON копируется из каталога автора
в каталог получателя, разные ключи корней; ожидаются2 подходящие текстуры,
получено0, exit1. Журнал build-tests-96-portability/baseline-qtest.txt.

В96 корневой modelTextures представляет переносимую библиотеку этого JSON
рядом с database.res. Старые непротиворечивые привязки читаются в память
один раз при загрузке, без обязательной перезаписи файла. При обычном сохранении
библиотека записывается, старые profiles/scanCache, русские имена, категории,
стыки, сборки и неизвестные поля сохраняются. scanCache не переносится под чужой
ключ и не признаётся проверенным кэшем другого компьютера. Точные старые
профильные переопределения поддерживаются; различные старые наборы для одной
модели не объединяются. Явная новая привязка обновляет переносимую библиотеку,
сохраняя уже известные варианты. Выбор фильтруется по реально доступным именам
текстур текущего профиля; JSON не заменяет игровые ресурсы.

EXE-side импорт при совпавшем старом профиле сохраняет его прежнюю изоляцию;
при сменившемся пути сохраняются исходные записи и применяется та же проверка
непротиворечивости. Сам источник не переписывается. Неправильный JSON и внешние
изменения остаются защищены прежней атомарной записью/проверкой исходных байтов.

С готовыми связями создание/витрина не перечисляют/не разбирают все MOB
автоматически. Кнопка «Обновить связи из MOB…» запускает прежний постепенный
сканер текущих корней явно; обновление сохраняет локальный кэш и не меняет объект
при отмене выбора. Без каталога первоначальное заполнение остаётся доступно.
Создание с готовым каталогом не заменяет непосещённый scanCache пустым кэшем.
