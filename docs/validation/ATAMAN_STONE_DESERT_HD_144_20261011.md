## Первоначальная проверка строгого равенства (история)

Задание одновременно требует строгого побайтного совпадения декодированных
SD-пикселей и HD для zone19:43/44/45 через zone18:463. Прототип прямо различает
две SD-обработки одного рисунка. Повторное декодирование это подтвердило.

Проверка: `build-tests-stone-144/check_exact_alias.py`, exit **1**.
Receipt: [exact-alias-prerequisite.json](../../build-tests-stone-144/exact-alias-prerequisite.json).
Скрипт использует существующий Snapshot/декодер прототипа, сравнивает массивы
RGBA напрямую и ищет SHA всех четырёх поворотов в двух каталогах stock-снимка.
SHA всех четырёх RES и каталога проверены; RES повторно сверены после чтения.

| Слот zone19 | Различающихся RGBA-байт с zone18:463, 0° | 90° | 180° | 270° | Точное совпадение |
|---|---:|---:|---:|---:|---|
| 43 | 22413 | 46634 | 46952 | 46657 | нет |
| 44 | 0 | 46621 | 47070 | 46621 | да, 0° |
| 45 | 22413 | 46634 | 46952 | 46657 | нет |

Всего в каждом массиве 65536 байт (128×128×4).
Каталоги содержат 16576 записей JamaisVu и 20864 Dejavu. Среди записей SD128
точные совпадения 43/45 найдены только у zone19:43 и :45 в обоих банках,
без дополнительных поворотов. Для 44 найдены zone18:463 и zone19:44.
Поиск не является доказательством отсутствия источника вне этих банков.

SHA с префиксом размера, в принятом формате аудита:

- zone19:43/45: `33982089439b4db72e7c34589c3899361031ee7dab5e9ae05b83784c031cd46e`.
- zone19:44 и zone18:463: `7466a4ce24c4539832414349def0b574149a932d2aa87f2884284f1bf966bcdd`.

Это не неоднозначность нескольких HD-кандидатов, а отсутствие требуемого точного
равенства для двух из трёх слотов. Сходство рисунка из прототипа нельзя назвать
побайтным псевдонимом. Нечёткое сопоставление или исключение для zone19 не добавлялось.

## Промежуточное решение и измерения (история, правило отменено)

Сопровождающий уточнил: различие двух SD-обработок не является дефектом данных.
Помимо строгого псевдонима разрешено отдельное правило «HD через перекодированный
SD-дубликат» с сохранением семантики. Кандидат должен иметь подтверждённый HD,
совпадающий материал/семейство; сравнение RGBA в исходном размере, четыре поворота.
Пороги: MAE ≤3, P99 ≤16, корреляция яркости ≥0,98; второй кандидат должен быть
хуже по MAE минимум вдвое либо не проходить пороги. При провале для 43/45 дано
прямое поручение остановиться и передать метрики/PNG, не подгоняя пороги.

Измеритель: `build-tests-stone-144/check_recoded_alias.py`, exit **1**.
[Полная квитанция](../../build-tests-stone-144/recoded-alias-prerequisite.json).
Слоты 43/45 побайтно равны, поэтому их результаты одинаковы.

| Пара 43/45 против zone18:463, лучший поворот 0° | Значение | Порог | Результат |
|---|---:|---:|---|
| Средняя абсолютная разница RGBA | 2,2024078369140625 | ≤3 | PASS |
| P99 абсолютной разницы RGBA | 19 | ≤16 | **FAIL** |
| Корреляция яркости | 0,9740495192337739 | ≥0,98 | **FAIL** |

MAE и P99 посчитаны по всем 65536 компонентам RGBA, P99 с линейной интерполяцией.
Alpha у обоих изображений 255. Для справки, только RGB: MAE 2,9365437825520835,
P99 20. Яркость: 0,2126R + 0,7152G + 0,0722B по декодированным каналам 0…255,
без линеаризации sRGB; корреляция Пирсона по 16384 пикселям. Масштабирования,
фильтрации, повторного BC1-кодирования перед измерением нет.
Остальные повороты reference имеют MAE RGBA 17,449234…17,819351,
P99 79…80, корреляцию 0,066455…0,079035; ни один не проходит.

Проверены **4668 уникальных SD128-изображений × 4 поворота = 18672 сравнения**
из обоих stock-каталогов. Дубликаты одинакового рисунка объединены по RGBA SHA,
но все исходные идентичности сохранены в квитанции. Следующие ближайшие рисунки:

| Источник | Минимальный MAE RGBA | P99 | Корреляция яркости | Допуск |
|---|---:|---:|---:|---|
| zone19:43/45 | 0 | 0 | 1 | сам целевой SD, не свидетель HD |
| zone18:463 / zone19:44 | 2,202408 | 19 | 0,974050 | FAIL P99 и корреляции |
| zone19:184 | 7,368805 | 42 | 0,834728 | FAIL, материал не назначен |
| zone19:117 | 7,526428 | 47 | 0,890036 | FAIL, материал не назначен |
| zone19:181 | 7,634842 | 44 | 0,806752 | FAIL, материал не назначен |
| zone19:182 | 7,886124 | 42 | 0,796553 | FAIL, материал не назначен |

Последние четыре строки — диагностические соседи вне допустимого семантического
набора, а не подтверждённые HD-доноры. В Stone / Desert каталог содержит только
два разных SD-рисунка (целевой и zone18:463) и один HD bz16h:463. Второго отличного
допустимого SD-кандидата с подтверждённым HD в предоставленных свидетельствах нет.
Запас уникальности не может компенсировать провал абсолютных порогов.
