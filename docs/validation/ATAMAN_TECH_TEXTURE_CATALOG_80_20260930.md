# EI-TECH-TEXTURE-CATALOG-80 — проверка подбора текстур

Дата: 2026-09-30. База `de9c794ce64221223ded0ce0470b0a7521d90033`, ветка `codex/technical-object-textures-v80`. Игровые данные читались без записи; исходный Endurance не менялся.

## Исходный случай и изменение

В режиме «Технические объекты» поле основной текстуры раньше показывало общий каталог без связи с выбранной моделью. По доступным MOB DejaVu проверено 151 файл без ошибки чтения: 41 891 объект с моделью и основной текстурой, 268 моделей, 377 различных пар, 50 моделей имеют более одного варианта.

Новый каталог читает поля MOB `B006` (модель), `B007` (основная текстура), `B008` (вторичная) через существующий валидирующий загрузчик. В UI точные и доступные в ресурсах варианты для модели стоят первыми по числу встреч; остальные установленные текстуры идут ниже. Если точной пары нет, пользователь выбирает из общего списка. Автоматически выбирается только самый частый точный вариант, когда основная текстура пуста; уже выбранное значение не перезаписывается при обычном обновлении UI. Смена модели очищает старую текстуру. Типы без основной текстуры скрывают выбор. Поле MOB остаётся источником истины при сохранении; никаких сторонних каталогов в игровых данных не создаётся.

Сканирование запускается только при входе в режим технических объектов, по одному MOB в событии Qt. Повторное открытие не перечитывает неизменные файлы; одноимённые карты в последующих корнях профиля не смешиваются с приоритетной картой. При ошибке чтения показывается число отказов.

## Ограничения

Точный вариант определяется по встречаемости в MOB и фактическому наличию текстуры в ресурсах, а не по имени модели или предположению о совместимости произвольной запасной текстуры.
