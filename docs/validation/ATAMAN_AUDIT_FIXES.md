# Исправления аудита Ataman 16

Ветка codex/audit-fixes. Общее поручение владельца: все пункты аудита.
Каждая правка получает отдельную версию и коммит; конечная сборка общая.

## 17 / AUD-01

Координаты редактируются текстом с точным round-trip double (17 значащих цифр),
без диапазона/округления spinbox. На OK проверяются конечность и корректность;
исходные значения не меняются от переименования карты. Новый текст переведён.
Проверка: world_coordinate_edit_tests, точные дроби/большие значения,
намеренное изменение и отказ NaN/Inf/пустого ввода.
## 18 / AUD-02

updateResourceMetadata обновляет только размеры соответствующего MPR в памяти
документа; проверяется совпадение пути и идентичности. Чтение не пишет на диск.
Следующая явная правка сохраняет проверенные размеры вместе с координатами.
world_map_layout_document: 19 PASS, 1 optional SKIP; проверены отсутствие записи
на просмотре, сохранение размеров, отказ устаревшему пути и обновление размеров.
## 19 / AUD-03

Сохранение объединяет известные поля с исходными JSON-объектами по ID профиля,
мира и карты. Неизвестные поля корня/профиля/мира/карты/origin сохраняются;
удалённые карты не восстанавливаются, метаданные пустых контейнеров сохраняются.
Тест миграции v1, повторной записи v2 и удаления: PASS. Общий документ:
20 PASS, 1 optional SKIP. Конкурентные изменения по-прежнему блокируют запись.
## 20 / AUD-04

Контекст отображения сравнивается по выбранным картам, координатам, размерам,
ревизиям MPR/MOB и архивов. Повторный refresh не очищает сцены и не отменяет
workers. Изменение размещения/ресурсов инвалидирует контекст. Холодное чтение
размеров остальных MPR выполняется в QtConcurrent; результат сверяется с ревизией
файла, callback перечитывает текущий профиль. Worker не захватывает MainWindow.
Список диалога использует снимок записей, чтобы фоновое обновление не меняло
соответствие строки и карты. Размер активного открытого рельефа доступен сразу;
в документ пишутся только подтверждённые дисковые метаданные.
Сборка 20 PASS. Скрытая интеграция: 41 PASS, включая отсутствие смены поколения
для неизменного контекста и смену поколения после перемещения. FPS не измерялся.
