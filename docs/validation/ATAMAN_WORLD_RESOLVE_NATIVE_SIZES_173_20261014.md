## Изменение

- Общий канонический банк материалов нормализуется для каждого размера целевого атласа. Его raster-контексты кэшируются отдельно128/256; существующий рисунок mixed-edge передаётся в своём native размере. Одинаковый размер всей группы не требуется; пустые/неквадратные и неприменимые входы по-прежнему отклоняются.
- Импорт банка вниз по разрешению использует native размер цели; меньшие авторские переходы не растягиваются в HD-цель. Новые слоты размещаются после авторских страниц. Исходные изображения, MMP-пиксели, namespace и исходные данные не меняются автоматически.
- Water runtime и любые ссылки на animation ranges, включая их semantic corners, защищены от автоматического ремонта. Этим клеткам не назначаются статические canonical boundary tiles. Импорт канонического native body другого размера разрешён только при наличии в исходном атласе такого размера с тем же runtime type.
- Mixed-edge рассчитывает размер по native максимуму целевого атласа и включает его в recipe key. Общий Save пересобирает изменённые исходные страницы в размере именно этой страницы; первая водная128-страница не уменьшает остальные256-страницы.
- При активации допускается новый CPU document только если baseline bytes, все sector payloads, authored/active images и tile types неизменны. Настоящие рабочие правки/источники всё ещё требуют согласованного готового preview или обычной загрузки.
