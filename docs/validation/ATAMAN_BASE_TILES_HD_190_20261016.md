# Ataman190 — EI-BASE-TILES-HD-190

2026-10-16. Отдельная команда «Перевести базовые тайлы в HD» в дополнительных
инструментах покраски. База main `a212585e3ee6fcd57668a6b036e96170f8d8509f` /189.

## Реализация

- Локальный банк `hd-library`: проверяются SHA страниц, декодированные пиксели
  вариантов и исходников. Используются однородные материалы/физические классы,
  визуальное соответствие SD/HD и сохранённые кромки вариантов. Вода,
  анимационные диапазоны, overlay-ссылки и смешанные сигнатуры исключены.
- Вариант и допустимый поворот выбираются по координатам/зерну; выбранные
  физические ссылки входят в одну команду Undo. Повороты допустимы только при
  точном совпадении защищённого края, включая видимую UV-кромку.
- Исходные MMP-страницы сохраняются побайтно. Новые варианты добавляются на
  отдельные страницы256. Подбор не изменяет файл карты до обычного сохранения.
  Undo/Redo сохраняется после Save; необязательный новый генератор переходов
  и код132–176 не возвращены.
- Рабочие изображения сохраняют native128/256; общий GPU-холст использует
  максимальное разрешение без уменьшения HD. Временное nearest-увеличение SD
  существует только в отображении/рабочих входах синтеза. Исходные файлы SD
  остаются прежними. Повторное изменение одной клетки обновляет существующую
  GPU-текстуру, а не перезагружает весь атлас.

HDPack_Terrain.res прочитаны для копии; их SHA проверены неизменными после теста.
Банк пользователя не изменялся. Новый участок программы не использует приватный
код движка; проверка игры остаётся отдельной приёмкой.

  19671 изменённая клетка,15 исходных тайлов,26 вариантов в выбранных наборах,
  24 реально использованных физических выхода. Подтверждено разнообразие
  нескольких вхождений одного старого тайла, а не только разные материалы.
- Точные исходные SEC после Undo; точный Redo; обычный Save, Undo/Redo после
  Save, второй Save и unload/reopen. Все исходные MMP-страницы после обоих Save
  побайтно прежние; сохранены native-размеры воды/переходов, материалы, анимации,
  overlay-ссылки и физические классы заменённых клеток.
- Прямой GPU readback совпадает с полным HD256 и nearest SD128. Проверены
  загрузка после reopen, изменение одной HD-клетки, сохранение texture ID и
  восстановление исходного GPU-содержимого.
- **7/0/0 QtTest**: смешанные native-страницы, добавление страниц другого размера,
  точные исходные payload, metadata/padding и повторная рабочая загрузка.
  **8/0/0 связанный регресс**: импорт, классы, staging-copy и ориентация страниц.
- **18 guard PASS**, `guards18.out`: отмена не выдаёт транзакцию, повреждение
  страницы при неизменном размере обнаруживается по SHA, исходный атлас не
  меняется. Проверены исходные материалы/анимации сохранённой копии.
- **24 PASS /0 FAIL /3 SKIP**, `widget-results.txt`: отдельная кнопка испускает
  только свой сигнал, регресс панели ландшафта. Три GL-теста недоступны в
