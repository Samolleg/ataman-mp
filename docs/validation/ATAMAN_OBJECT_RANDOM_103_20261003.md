# EI-OBJECT-RANDOM-103 — кнопка рандомизации

Дата:2026-10-03. База main cc1cc8a546f0c781d6432b2c4d9d8bbdf2b730be, версия102→103.

## Поведение

Кнопка «Рандом» с векторным значком кубика расположена справа от «Сборки». ЛКМ меняет масштаб выделенных масштабируемых объектов активного MOB; ПКМ открывает семь взаимно исключающих вариантов X/Y/Z/XY/XZ/YZ/XYZ и силу0–100%. Значения по умолчанию XYZ/±25%; настройки хранятся в QSettings ui/objectRandomAxes/ui/objectRandomStrength и восстанавливаются при запуске.

Каждая выбранная ось каждого объекта получает независимый множитель из [1-p,1+p], где p=сила/100; основа — текущее значение объекта. При0% нет изменений/Undo. Не выбранные оси сохраняются точно; нулевое значение остаётся нулевым, отрицательное сохраняет знак. Свет/прочие немасштабируемые узлы пропускаются. Незавершённое перемещение/размещение сначала требуется завершить. Неконечные значения и переполнение результата отвергают операцию до изменения объектов.

Скриншот показывает samtr01 с восемью встроенными формами. В обычном коде CFigure.calculateConstitution форма интерполируется по COMPLECTION XYZ; CWorldObj.applyParam вызывает recalcFigure. Реализация использует этот штатный путь. Другой идентификатор модели/текстура не выбираются автоматически: в каталоге нет подтверждённого контракта групп отдельных моделей. Уточнение было предложено владельцу; без ответа принят смысл встроенных форм со скриншота. Для работы приватные источники движка и специальные навыки не требовались; исследован код редактора.

Один QUndoCommand хранит точные исходные/сгенерированные векторы и воспроизводит их при Undo/Redo. Геометрия пересчитывается по объекту, таблица обновляется один раз для операции; владельцы MOB помечаются изменёнными, пространственный индекс/AI-preview получают штатную инвалидацию. Карты и каталог этим действием не сохраняются на диск.

Связанная необходимая защита: recalcFigure раньше разыменовывал nullptr при отсутствующей геометрии. Теперь пустой предпросмотр допускает изменение сериализованного масштаба; проверка отсутствующей фигуры проходит без падения.
