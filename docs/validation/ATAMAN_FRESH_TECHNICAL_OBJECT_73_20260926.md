# EI-FRESH-TECHNICAL-OBJECT-73 — создание без выделенного шаблона

Исходное сообщение владельца: «Почему если я размещаю новый объект мне надо использовать шаблон? А на новых картах как мне добавлять объекты где нет других объектов?» Скриншот показывает модальное требование выбрать существующий объект того же типа. Проверка кода подтвердила первое неверное состояние: `CCreateObjectForm::on_buttonCreate_clicked` возвращался до создания узла для всех технических типов, кроме света, если не был выбран объект с сырой provenance.

Изменение: при отсутствии выбранной записи текущего MOB редактор сериализует новый технический объект во временное дерево MOB, проверяет строгий разбор, точное повторное чтение свойств и требуемые поля, затем прикрепляет собственную полную исходную запись для защищённого сохранения. При выбранном объекте того же типа в текущем MOB сохраняется старый путь копирования сырой записи с неизвестными полями. Выбор на соседней карте не используется как несуществующий локальный шаблон. У магической ловушки формат жёстко задаёт модель `efcu0` и текстуры; неподдерживаемые значения отклоняются.

Тест `--database-creation-check` на свежей Release73 в комплекте с зависимостями: exit0. На отдельном пустом синтетическом MOB прошли восемь типов — объект мира, рычаг, факел, ловушка, звук, частицы, свет и персонаж. Каждый был сохранён, открыт, удалён; после удаления байты исходного MOB восстановлены. Отсутствующая модель объекта мира и неподдерживаемая модель ловушки отклонены. Старые проверки создания из базы (персонаж, предмет, рычаг), Undo/Redo и света прошли. Игровые MOB не записывались. `--version` вернул `EI Mapper Endurance Edition 73`.

Ограничения: `--ui-widget-check` exit1 на ранее известных отказах проверок буфера обмена. `--scenario-layer-check` дал 48 PASS / 2 FAIL из-за невозможности создать тестовый резервный каталог, в том числе с изолированными APPDATA/LOCALAPPDATA; это не PASS. Ручное нажатие «Создать» в пользовательском окне, внешний вид, игра и сохранение пользовательской карты ещё не проверены. Редактор не меняет игровую карту автоматически.

Release73 подготовлен в новом каталоге `build-release-73-fresh-technical`; свежий и staged EXE имеют одинаковый SHA-256 `53E0DD50E3920F43CD591ED1DC883ACDA7660582FF076CF100611E5884F4CB1C`. До финализации staged `--version` вернул `EI Mapper Endurance Edition 73`, exit0. Новая staging-папка `build-staging-73-fresh-technical` финализирована и независимо прошла `validate_distribution.ps1`: 127 управляемых файлов, SHA-256 манифеста `6957643F1A9F25200E626320C335562812280E4089C6976C282B5C20D19266A0`. Финализированная программа не запускалась.

Четыре управляемых файла заменены, 127 сверены с новым манифестом, инвентарь 15089 неуправляемых пользовательских файлов не изменился.
