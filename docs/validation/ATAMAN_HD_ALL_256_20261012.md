## Implementation and defect cause

The previous conversion left ordinary homogeneous tiles at 128 px when no exact HD match existed, and kept ambiguous/unrecognized transitions at 128 px. Animated ranges also prevented converting their pages as a whole. The conversion now selects a deterministic 256 px same-material/class/layer variant (reading the optional variant bank or using a matching HD source), regenerates recognized transitions through the existing transition/recipe path, and upscales unresolved transitions and other unmatched static slots with a reason recorded in the receipt. The animation page keeps its original frame range; its static replacements are packed in HD pages.

The repeat-conversion synthetic case exposed a second-pass defect: already-empty animation-page slots could be appended again as HD replacements, adding an extra page. The repeat pass now excludes empty/padded slots; page bytes and output slot count remain stable.

The user-owned variant bank is read only. Synthetic index caches and real-map output were confined to `build-tests-hdall`; no live maps, game files, mod archives, or permanent installation were changed.
