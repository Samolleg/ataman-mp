# Ataman84: вращение группы вокруг общего центра

Дата:2026-09-30. EI-GROUP-ROTATION-84. Ветка codex/group-rotation-v84, база83:1794a8dfdad3bcb037612cce52e15d10a1cba092.

## Причина и изменение

rotateTo прибавлял углы Эйлера к ориентации каждого объекта, не меняя позицию. Наклонённые объекты не получали одинаковое вращение относительно мировой оси; Backspace последнего символа не возвращал превью в исходное состояние. Snapshot хранил только Euler. До исправления команда R на синтетической группе дала8 FAIL в18 проверках (build-tests-84-group-rotation/baseline.out).

Теперь gesture snapshot хранит позиции, исходные quaternion и movementState юнитов. Общий центр — midpoint покомпонентных min/max позиций только объектов активного MOB, которым разрешено вращение. Центр фиксирован на начало операции, вращение позиций и ориентаций вычисляется от snapshot с составным quaternion относительно мировой оси. Расстояния/масштаб сохраняются; один объект вращается на месте. Все изменения группы входят в одну macro undo; существующий CChangeProp сохраняет точный объект по указателю, а не ищет повторяющийся map ID. Esc/смена оси/очистка числового ввода возвращают позиции, ориентации и состояние движения/патруля. Enter подтверждает также мышиное превью.
