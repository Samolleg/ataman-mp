## Реализация

- Штатные пользовательские QSettings, как у остальных настроек доков:
  `ui/aiAgentMode` (0/1/2, без значения или при неверном значении — Выкл),
  `ui/aiAgentAllowSave` (без значения — false). Запись/sync только при выборе
  режима/галочки человеком; кнопка «Отключить» запоминает Выкл.
- Конструктор CAiAgentServer восстанавливает выбор и запускает QLocalServer
  до открытия стартовой карты. stop(), closeEvent, уничтожение CView и деструктор
  закрывают транспорт/отменяют операции, не перезаписывая сохранённые полномочия.
  Секрет/ID сеанса не сохраняются. Ошибка открытия канала оставляет доступ выключенным.
- В Выкл/Только чтение галочка неактивна; её сохранённое значение возвращается
  при переходе в Правку. Проверки мутаций по режиму сохранены;
  get_revision сообщает эффективное allowSave=false в Только чтение.
- Док и постоянный QLabel строки состояния показывают фактический режим и число
  аутентифицированных соединений. Закрытый док не скрывает индикатор строки состояния.
- connect_instance допускает отсутствие instance. Обычные tools и чтение context
  resource также выбирают единственный доступный включённый маппер автоматически.
  При нескольких — понятная ошибка с list_instances/явным ID. Явно выбранный
  здоровый поток сохраняет выбор; disconnect_instance подавляет автовыбор до
  следующего connect_instance. Агент не запускает редактор и не включает доступ.
- Сохранены постоянный поток, непробное обнаружение и backoff1–60с223.
  После перезапуска новый ID сбрасывает задержку, повторный запрос выбирает
  единственный маппер. Прежние operation ID не возобновляются; мутации автоматически
  не переигрываются. После разрыва агент перечитывает контекст/ревизию.
