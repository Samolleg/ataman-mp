## Изменение

Общая кисть передаёт состояние до штампа в previewWorldPaintState. Для активной карты сравниваются точные SEC payload до/после; для загруженного соседа — payload его собственного рендера, с исходным сектором в качестве начального состояния. Обновляются только отличающиеся секторы. Undo/Redo передаёт правильную сторону полного исторического состояния. Восстановление, повторная привязка и откат после ошибки без известного предыдущего состояния сохраняют полный путь публикации секторов.

CLandscape удерживает QImage-снимок последней успешной публикации атласа. Неизменённые изображения при том же layout не загружаются; изменённые слоты идут через существующий in-place путь с восстановлением прежних пикселей при ошибке. Изменение размера/layout использует полный путь. При очистке GL preview снимок сбрасывается; после отказа оптимизированной публикации следующая попытка не доверяет снимку. QImage sharing не копирует неизменённые пиксели на каждом штампе.

Алгоритмы стыковки180, подписи материалов, генератор131, правила выбора авторских вариантов, сохранение и модель истории не менялись. Новое ядро132–176 не возвращено. Обновление таблиц материалов, picker, shadow invalidation и рабочих состояний сохранено.

Подтверждено:

- Все16 проверяемых клеток общего стыка имеют точные запрошенные семантические сигнатуры; packed-результаты180/181 совпали.

- Настоящие sector VBO/UV и текстуры отрисованы в диагностический FBO. Кадр оптимизированной публикации побайтно совпадает с полной перепубликацией всех секторов/атласа и с180.
