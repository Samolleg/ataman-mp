# EI-LANDSCAPE-PANEL-147 — проверка панели ландшафта

Дата выполнения: 2026-10-12. База: `main` `2d4a27c068e3b5b327c5089c69df6acc777cdef0`, VERSION 146. AGENTS.md SHA256: `F4B7FDD5EA82FCDF43D002D23D64EC36BE853650F054EDF70376527CD6432EC3`.

## Результат

Правая панель сгруппирована в сегменты «Покраска / Рельеф / Поверхности». Общие форма и размер кисти сохраняются между режимами; покраска показывает параметры, чипы, слои, поиск, фильтр и палитру с переключаемым размером. Исходные и HD-варианты выбранного материала расположены отдельной полосой. Контекстные угловые кисти постоянно вынесены под подпись «Только у стыков», поэтому миниатюры с переходными углами не попадают в основную палитру.

Classic Auto убран с видимых страниц и горячих клавиш; настройки Classic мигрируют в современную покраску. Ручное размещение доступно удержанием C и вкладкой «Слоты атласа». Все прежние действия поверхностей, sculpt, карты и диагностики сохранены.

## C и физические слоты

При нажатии C обработчик выбирает `ETerrainPaintPaletteMode::Manual`, вкладку физических слотов и прямую запись выбранного физического слота/поворота. Пока C удерживается, палитра и обработчик используют тот же manual-путь, что существовавший режим Manual; отпускание возвращает Modern. Ручной режим не появляется как отдельный пункт списка.

`classicSettingsMigrateAndCUsesManualOnlyWhileHeld` проверяет миграцию, две видимые вкладки без Classic и переход Manual→Modern при отпускании. `manualPaletteFiltersNonNullPaddingAndRestoresPhysicalIdentity` проверяет сохранение физической идентичности тайлов и поворотов; основной диспетчер записи тайла не менялся.

## Диагностика 0xC0000602

Сбой разработки не считался отказом готовой проверки. Отладочный прогон показал fail-fast при повторном использовании освобождённой layout-обёртки после перестройки панели; её время жизни закреплено за панелью. При проверке контекстных штампов тест также перестал читать указатели на кнопки после `setPaintMaterials`, который пересоздаёт эти виджеты. Отдельный отладочный запуск сначала завершался `qt_message_fatal` из-за отсутствующего пути Qt `plugins/platforms`; путь QPA исправлен. `QT_FATAL_WARNINGS` не устанавливался. После исправлений Release и Debug UI-тесты завершились нормально; свежая архивная Release тоже прошла `--ui-widget-check`.
