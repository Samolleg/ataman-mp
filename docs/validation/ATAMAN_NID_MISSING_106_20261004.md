## Исправление

На местной zone19 версия105 отказывала до поиска свободного ID: в строке2034 скрипта ссылка на отсутствующий Autozone19Alarm1.mob. Отсутствующий файл теперь остаётся неполнотой семейного отчёта и предупреждением в журнале, но допускает авторинг по доступным записям. Сам отсутствующий MOB не может быть владельцем создаваемого объекта. Не подменяется zone19alarm1.mob из Base, игровые скрипты и существующие ID не ремонтируются.

Существующий нечитаемый файл/непригодный живой кандидат, неразрешённый динамический AddMob и исчерпание эффективных диапазонов остаются блокерами. Кандидат проверяется среди известных связанных файлов, актуальных объектов и auxiliary ID всех открытых MOB и сессионных резервов Undo/Redo. При отказе создания любой детали пакет отменяется целиком; локальный запасной ID не возвращён.

Missing-зависимость больше не сбрасывает структурный кэш на каждом добавлении. В digest отслеживаются её имя и метаданные во всех поисковых корнях профиля/открытых MOB/запрашивающего файла: восстановление файла требует свежего отчёта до следующего выбора ID. Модели/текстуры и готовый каталог этот путь не сканирует и не записывает. Предупреждение выводится при построении снимка, не143 раза для143 участников.
