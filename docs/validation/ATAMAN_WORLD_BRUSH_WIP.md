  правильность всей цепочки ресурсов и рендера.

  независимых рабочих атласов соседей ещё НЕ реализованы. Нельзя считать
  второе требование пользователя выполненным.
- Сохранение общей сессии пока рассчитано на MPR без изменённого атласа:
  рабочие расширения RES по-прежнему требуют следующей реализации.
