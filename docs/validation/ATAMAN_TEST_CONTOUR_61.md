# EI-TEST-CONTOUR-61

Дата: 2026-09-24. База: версия 60, commit `f6fd03c1442acfd9fb979fbb4ed9d3d84b28b800`.

Исходный аудит версии 58 (`ATAMAN_FUNCTIONAL_AUDIT_58_20260924.md`) воспроизвёл два отказа сборки и четыре отказа тестов: путь заголовка отчёта ID; устаревший вызов панели ландшафта; текстовое совпадение публикации атласа; ожидание выбора RES при уже существующем HDPack; разреженные порядковые записи `#exit`; fixture, привязанный к глубине каталога EXE. После восстановления сборки ландшафтный набор обнаружил ещё четыре устаревших ожидания до перепроектирования панели.

Исправлены тесты: заголовок берётся из проектного include path; `setWorldTerrainStatus` вызывается с шестью аргументами; публикация проверяется чтением страницы и профиля из пересобранного архива, а не по имени локальной переменной в исходнике; существующий `HDPack_Terrain.res` выбирается автоматически, отсутствие архива требует выбора; ссылки `#exit` используют реальные порядковые номера при сохранении геометрических ожиданий; fixture запуска карты находится через `QFINDTESTDATA`. Тест панели открывает свёрнутые разделы и проверяет актуальные подписи и подсказку у управления кистью. При невозможности создать тестовый прогон launcher выводит точный путь.

Свежая широкая пересборка в `build-audit-58-20260924` собрала все 42 набора. 41 набор прошёл в обычной среде: 1010 успешных проверок, 0 отказов, 40 пропусков. Набор `jmv_map_test_launcher_tests` отдельно получил доступ к своей папке `AppData/Local/qttest` и завершился с 56 успешными, 0 отказов, 3 явными пропусками. Итого: 42 собранных и прошедших набора, 1066 успешных проверок, 0 отказов, 43 пропуска. Подтверждения: `build-audit-58-20260924/suite-results-61-all.json`, файлы `*/results-61-all.txt`. Пропуски включают проверки реальной игры, приватного корпуса и OpenGL-контекста, недоступного через offscreen plugin; они не считаются PASS.

При обычном ограниченном запуске 11 проверок восстановления launcher не могли создать папку `C:/Users/samol/AppData/Local/qttest/jmv_map_test_launcher_tests/test-runs`; сообщение с точным путём подтвердило ограничение доступа. Повтор всего набора с разрешённой записью только в его изолированную Qt-test папку прошёл. После точечного теста, полного прогона и широкой пересборки тестовый EXE остался на месте с тем же SHA-256 `A035C74CAB482FF1D283D4962D7D11FE5021044C69A9A65D2A400D2CF602C6E4`. Историческое отсутствие EXE при повторе аудита не воспроизведено; старые журналы не фиксируют операцию его удаления, поэтому причину того отдельного исчезновения нельзя доказательно приписать тесту, антивирусу или сборщику. Новый прогон явно проверяет наличие EXE после компиляции.

Игровые карты и исходный Endurance не изменялись. Интерактивная проверка UI и игровая проверка остаются отдельными ручными воротами.

Встроенная `--ui-widget-check` в текущей среде выявила дополнительный узкий случай: при ширине панели 320 пикселей раскрытие двух разделов ландшафта добавляет горизонтальную прокрутку 15 пикселей. Установленная версия 58 повторяет тот же результат; аудит версии 58 запускался при другом состоянии экрана и тогда проходил. Измерение показало минимальную ширину 297 пикселей у вложенного свёрнутого раздела при доступных 282 пикселях. Этот UI-дефект относится к отдельному исправлению после версии 61; он не объявлен успехом этого тестового исправления.
