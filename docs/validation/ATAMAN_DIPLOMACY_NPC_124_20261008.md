## Результат и границы

- Кнопка «Дипломатия» расположена непосредственно после «Поведение» в нижнем
  меню; иконка и размеры соответствуют соседним кнопкам.
- Окно показывает группы0–31, начальное количество НПС, список участников,
  ID, прототип, исходный MOB и возможные назначения скриптом. Есть фильтр
  по MOB и поиск; фильтрация списка не меняет полные счётчики групп.
- Снимки загруженных MOB берутся из текущих объектов, включая несохранённые
  правки; удалённые узлы исключены. Скрипт берётся из открытого внутреннего
  редактора, если есть неприменённый текст, иначе из текущего MOB.
- Рекурсивные литеральные AddMob читаются из папки источника и настроенных
  корней карт. Нормализация пути, повторные подключения и циклы не дают
  повторных НПС. Загруженный файл или его рабочая копия имеют приоритет перед
  установленной исходной версией с тем же логическим именем. При нескольких
  открытых одноимённых MOB неоднозначность сохраняется явно.
- Фоновый анализ получает только значения, без живых узлов/виджетов. Изменения
  объединяются таймером250мс; результат прежнего поколения отклоняется.
  Окно повторно используется; закрытое окно не запускает анализ.
- Чтение MOB использует CMobDocument и сырое поле OBJ_PLAYER0xB011.
  Модели, текстуры и каталог объектов не сканируются. Игровые файлы не пишутся.
- SetPlayer связывается с НПС только при однозначном литеральном ID или имени.
  Повторные ID, коллизии с обычными объектами и повторные имена созданий не
  выбирают произвольного участника. Начальная группа никогда не подменяется
  предсказанием условного скрипта.
- Места AddUnitToServer показаны отдельно: число запусков циклов/условий и
  исходная группа из вычислений во время игры здесь не известны. SetDiplomacy,
  GetDiplomacy и Group-команды доступны на вкладке скриптов; скриптовые группы
  не приравниваются к группам дипломатии.
- Таблица отношений32×32 показывается без редактирования; явная кнопка
  открывает существующий редактор отношений для выбранного загруженного MOB.
  Прежняя транзакция параметров и Undo не заменены.

## Неуспешные промежуточные попытки

- Первая diplomacy-native остановлена собственным90с таймаутом после14 PASS:
  стартовый диалог ресурсов тестового MainWindow ожидал ответа. Добавлен
  скрытый guard только собственного CResourceSetupDialog и изолированы
  QSettings; пользовательский редактор не закрывался.
- diplomacy-retry1 завершилась access violation после24 PASS. Ожидание лишь
  QFutureWatcher::isRunning могло закончиться до доставки GUI completion и
  чтения очищенного результата. Pending-состояние теперь снимается при
  доставке finished; последующие завершённые прогоны36/37/38 PASS.
  Отладчик первоначально не запускался из-за wrapper/локальных DLL и Python;
  после настройки собственного процесса ранний прогон под ним не прошёл
  ожидание снимка. Ни один из этих запусков не объявлен PASS.
- ui-widget-retry1 и retry2 остановлены guard до синтетических записей:
  Native clipboard format49349 (retry1) /2 (retry2) is not preservable. Пользовательский буфер
  не очищался и не подменялся ради проверки. Полный169 UI регресс на конечном
  EXE остаётся неподтверждённым;38 целевых проверок новой UI-функции завершены.
- На промежуточном корпусе обнаружено ложное предупреждение неполной семьи:
  сравнивался непереведённый префикс с переведённым сообщением первого
  однофайлового прохода. Сравнение исправлено; отдельный тест рекурсивной
  семьи и сравнение GUI/worker диагностики прошли на конечной сборке.
