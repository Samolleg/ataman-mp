## Причины и изменения

- CTableManager создавал отдельную строку русского имени; CComboDynItem/QStringListModel знал только ID. Теперь QLabel расположен справа от поля, без отдельного свойства. Попап показывает код + имя, поиск находит подстроку обоих без учёта регистра. Display/search отделены от Raw/UserRole/EditRole: редактор и completion возвращают только код, русская подпись не записывается в MOB. Создание объекта использует такие же подписи/поиск списка моделей. Неизвестный текущий код сохраняется; отмена фильтра не применяет изменение.
- setPreferredOptions лишь переставлял названия единого списка. Свойства и витрина теперь содержат невыбираемые заголовки «Текстуры этой модели» и «Другие текстуры профиля» с разделителем; подходящие варианты исключены из второй группы. При отсутствии связей есть явное сообщение. Заголовки не попадают в подсказки свойств и не могут стать значением. Открытие сохраняет текущую текстуру.
- Combo не очищал ранее выделенные ячейки таблицы при получении фокуса. Это воспроизведено FAIL до правки. Теперь вход/нажатие очищают выделение свойств, compound-контейнер и combo поглощают всплывающий drag. Выделение объектов в сцене не меняется; выбор нескольких свойств через таблицу и native text clipboard сохранены. Простой синтетический drag старого контейнера сам по себе проблему не воспроизвёл: полная идентичность жесту владельца не доказана, нужна ручная приёмка.
- Подпись получает часть ширины строки, полное имя доступно в tooltip. Существующие undo-команды/типизация, Enter/Esc, отмена и прототипы сохранены. JSON профиля и игровые данные не менялись.
