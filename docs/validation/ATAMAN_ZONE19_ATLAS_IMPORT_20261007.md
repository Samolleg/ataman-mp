  payloads/encoded names/timestamps и все 216 ресурсов Zone19: **PASS**.
- Независимый потоковый Python parser проверил границы, уникальность имён,
  CP1251 и действительный поиск каждого имени от hash bucket через NextIndex,
  а также SHA256 каждого payload. Точное множество добавлений — только 183
  ресурса Zone19; все прежние члены сохранены: **PASS**.

  копируются целиком; проверены соответствие textureCount/slots, наличие всех
  страниц каждого из 15 атласов и связанного семантического поля: **PASS**.
