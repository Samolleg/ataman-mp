## Причина и результат

У неизменённой `zone5_1.mpr` namespace `zone5_1`, три страницы /192 слота.
Страницы находятся в HDPack_Terrain.res, отдельного встроенного профиля нет.
Профиль корректно формируется при открытии, но кнопка сравнивала его JSON с
пустым RES payload и ошибочно требовала сохранить карту. Перед commit стояла
такая же безусловная проверка.

249 допускает отсутствие служебного профиля. При наличии профиль сначала
читается штатным декодером; форматирование JSON и поддержанная миграция схемы
не считаются пользовательским изменением. План сохраняет точные исходные
bytes/отсутствие member; добавление, удаление, неоднозначность или замена после
расчёта отклоняются перед записью.

У точной исходной zone5_1 все192 слота нужны: сжатие сообщает «Атлас уже
упакован. Файлы не изменены». Перестановка кадров анимации и нормализация старых
SD-полей MP при HD-страницах сами по себе не являются экономией. Новый namespace
создаётся при уменьшении страниц или физического объёма текстур. Принудительная
публикация при Save по-прежнему создаёт собственную identity и native MP sizes.

Связанная инъекция отказа выявила прежний пробел commit: сравнивались только
декодированные базовые пиксели. Усиленная проверка сохраняет SHA всех полных MMP
и один раз читает каждую страницу перед записью. Изменения mip-уровней,
обрезание и замена той же длины теперь также отменяют публикацию.
