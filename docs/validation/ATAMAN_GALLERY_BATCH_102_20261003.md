# EI-GALLERY-BATCH-102 — витрина и пакетное добавление

Дата: 2026-10-03. Ветка main, база 86de5a7f51c124e57e4868a1514f99021a0bf3ef, версия 101 → 102.

## Причины и изменения

- Открытие создания/витрины запускало повторные loadProfile/registerModels/save и при отсутствии связей сканирование MOB. Таблица свойств также сохраняла выбранную текстуру автоматически. Эти действия удалены: обычный просмотр читает существующий профильный JSON. Кнопка обновления связей из MOB удалена; ручное сохранение имени, текстурной связи, раздела и точек стыковки остаётся явным действием.
- Деструктор витрины синхронно ждал фоновой миниатюры. Ожидание удалено; рабочая задача владеет копией provider и shared-состоянием ресурсов, не обращается к уничтоженному диалогу. Уже начатая миниатюра может закончить вычисление после закрытия.
- Создание заполняло большой список текстур при подключённом completer и дважды обновляло объект при выборе модели/текстуры. Теперь модель списка готовится отдельно, свойства применяются вместе. Каталог базы/текстов повторно используется до смены профиля, корней или метаданных texts.res.
- «Витрина» справа от «Создать» открывает каталог напрямую. Ctrl/Shift позволяет выбрать 1–512 моделей. Пакет располагается сеткой с шагом 4, размещается одним действием, отменяется Esc и имеет общий Undo/Redo; объекты остаются независимыми, сборка в каталог не записывается. Из формы создания одиночный выбор заполняет форму, множественный начинает пакетное размещение.
- Текстура требуется для каждой выбранной модели; некорректная ручная текстура не заменяется молча. Структурная проверка целостности MOB при добавлении сохранена и выполняется на пакет.
