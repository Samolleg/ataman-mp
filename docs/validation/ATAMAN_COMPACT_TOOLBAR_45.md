# EI-COMPACT-TOOLBAR — Ataman 45

Ветка codex/compact-toolbar-v45, база установленная44. Пользователь разрешил
компактные иконки нижней панели, отдельные Рельеф и Тайлы суши и быстрые
Появления и переходы, Сценарий карты, Создать объект, Скрипт MOB.

Кнопки30x30 с иконками22x22, подсказками и accessibleName. Новые иконки
рисуются QPainter в2x без внешних изображений. Рельеф/Тайлы выбирают режим
CLandscapeTools; повторный клик закрывает открытую панель этого режима.
Состояния синхронизированы с панелью. Прежняя клавиша Landscape Tools
продолжает переключать панель. Новые команды используют существующие QAction,
включая enabled/checked. Камера: компактная шкала скорости и иконка
телеобъектива; числовые значения/направление сохранены. Алгоритмы не менялись.

Проверки: Release build-release-45-toolbar PASS; native --ui-widget-check exit0,
compactToolbarWorks=1. Проверены11 кнопок, иконки/подсказки/accessibleName,
icon-only/размер, реальное переключение TilePaint/Sculpt. Остальные проверки
UI, включая камеру, PASS. Снимок screenshots/compact-toolbar.png просмотрен.
Упаковка и установка ожидаются; ручная приёмка на рабочем DPI открыта.
