## Поведение и первое прежнее ограничение

В109 верхняя QActionGroup обязательна и эксклюзивна; нижние QAction выполняют самостоятельные команды сразу. Совместного выбора и единого выполнения нет. В110 настоящие QCheckBox внутри QWidgetAction сохраняют меню открытым: один верхний масштаб либо ни одного, независимые повороты X/Y. ЛКМ собирает текущие галочки и применяет одну атомарную команду. Выбор галочки сам ничего не меняет на карте. Сохранение ui/objectRandomAxes (0 допускается), ui/objectRandomRotateX/Y, ui/objectRandomStrength, ui/objectRandomRotationDegrees. Старые настройки109 совместимы; по умолчанию XYZ/25%, обе нижние выключены/25°.

Масштаб сохраняет интерполяцию встроенных FIG8 форм. Повороты мировые, сначала X, затем Y, вокруг собственной позиции; независимые углы для каждого объекта. Данные проверяются до первой мутации. Прежние wrapper API оставлены для регресса. Позиция, ID, модель, текстуры и остальные поля не меняются; невыделенные/удалённые и неподдерживаемые типы пропускаются. Точные исходные/выбранные значения хранятся в одной Undo-команде.

## Оптимизация и границы замеров

Прежний apply/Undo/Redo вызывал ownerMob для каждого объекта, а тот линейно ищет node в каждом MOB. Для k выбранных при N узлах это O(k*N). Новая команда хранит исходный MOB, проверяет его присутствие и один раз строит QSet принадлежащих ему узлов; затем O(1) проверка каждого, включая безопасность QPointer/удалённых узлов. Сложность этого этапа O(N+k). При смене активного MOB Undo сохраняет исходного владельца.

При одновременно выбранных повороте и масштабе quaternion устанавливается через CNode::setRot до applyParam(COMPLECTION); последний пересчитывает FIG геометрию, bbox и проекцию сразу с окончательным поворотом. Это исключает отдельный проход по старой геометрии. Состояние dirty, свойства и перерисовка обновляются один раз на команду, а не три. Существующий CPU-кэш общих сборок уже ограничен384MiB; менять его не потребовалось. Независимые масштабы всё равно требуют своей интерполяции и геометрии для каждого объекта.
