# Ataman95: перенос каталога и текстур, 2026-10-02

EI-CATALOG-PORTABILITY-95. Владелец сообщил: у товарища тот же DejaVu и скопированный JSON, но модели без текстур. Разрешено исследование; код/игровые данные в этом аудите не изменены. Конкретный путь игры и положение JSON у товарища ещё неизвестны.

Подтверждён дефект переносимости95: TechnicalModelCatalog::profileKey (source/documents/technical_model_catalog.cpp) хэширует нормализованные абсолютные пути mapRoots. textureChoices читает только profiles[текущий ключ].modelTextures. Названия/категории/стыки моделей глобальны, поэтому могут работать при отсутствии привязок. Наличие тех же моделей и текстур по другому пути не сохраняет ключ. Кэш сканирования MOB тоже содержит абсолютные пути; он не обеспечивает перенос библиотечных привязок.

На реальном JSON владельца воспроизведено без записи в профиль: текущие корни C:/GOG Games/PZ/MODS/DejaVu/Maps и C:/GOG Games/PZ/Base/Maps дают сохранённый ключ45f2000ca87facf1356cb614f4b1fffa001323b1997fe4053b03dc62c0f59cc2 и522 привязки моделей. При замене префикса на D:/Portable/PZ в том же JSON текущий ключ другой, соответствующего профиля нет и явных привязок0. Доказательство: build-tests-95-catalog-portability/reproduction.json. Это проверка алгоритма/данных, не интерактивный запуск компьютера товарища.

Витрина textureForModel выбирает первую подходящую привязку; при отсутствии подходящих вариантов возвращает пустую текстуру. textureChoices также проверяет наличие имени в ресурсах активного профиля. JSON содержит имена и связи, сами .mmp/.mod ресурсы он не переносит. При одинаковом пути дополнительными причинами остаются неправильное положение JSON или активный профиль ресурсов; их нельзя объявить исключёнными без данных товарища.

Пакет95 содержит тот же код3cbf3cedb9390cc1d490de000592d0b7b7006319, EXE5A96196B1B1664CC615E4CD2EC34501795D4C55AA3738477A111D52D402639B3. DLL-комплектность не проверяла переносимость связей JSON между машинами. Это недоработка каталога95, не доказательство отсутствующих Qt DLL.

Следующее исправление: сделать переносимые библиотечные привязки моделей/текстур с совместимым импортом старого JSON; машинный кэш и экземпляры MOB оставить отдельно. Проверять ресурсы текущего профиля и не объединять автоматически конфликтующие каталоги разных модов. Регресс: разные корни того же мода, старый JSON, несколько профилей/конфликты, отсутствующая текстура, отсутствие повторного сканирования всех MOB, сохранность неизвестных полей/имён/стыков/сборок и внешних изменений JSON. Пользовательские каталоги не править автоматически.
