## Реализация

- `--agent-headless`: скрытие всех верхних Qt-окон до показа/Polish, без заставки,
  нативных диалогов и Windows crash prompts. Скрытая GL-поверхность сохраняет
  штатную загрузку/запись форматов. Вопросы отвергаются и попадают в журнал/ошибку.
  Читаются те же endurance-options.json/профиль/пути. Последняя карта владельца
  автоматически не открывается. QSettings копируются во временную область,
  JSON и состояние окна владельца не записываются. Режим/Save224 перечитываются
  из исходного хранилища при запросе и перед применением, также раз в секунду.
- Мост до запуска проверяет224: Выкл — «Владелец выключил доступ агентов в доке»
  без создания EXE. initialize/list_instances/metadata сами не запускают маппер.
  Первый рабочий запрос запускает EXE рядом с мостом, с ограничением готовности45с.
  Межпроцессная блокировка старта объединяет конкурентные мосты; процесс держит
  Windows named mutex и lifetime-lock. Стартовые журналы отдельные, stdout MCP
  не смешивается с stdout дочернего процесса. Неопределённые мутации не переигрываются.
- `connect_instance target=auto|background|editor`: отдельная карта — background;
  auto выбирает фон, если обычного маппера нет или владелец имеет несохранённые
  изменения. Существующий выбранный сеанс удерживается. Несколько обычных
  редакторов требуют ID. В фоне includeNeighbors по умолчанию false;
  явный true требует всех карт и отклоняется целиком при занятом соседе.
  В обычном окне прежняя общая кисть сохранена.
- MPR и одноимённый MOB имеют общий физический ключ блокировки. Дополнительно
  удерживаются leases загруженных MOB, затронутых world-session документов,
  detached edit plans и всех целей сохранения. Открытие пары проверяется до
  выгрузки прежнего рабочего места. Человек получает немодальный отказ,
  агент — MCP error. Закрытие освобождает lease; dead-PID снимается штатно QLockFile.
- Публикация нового атласа213 и обычный Save удерживают resource-lock до чтения
  актуального RES и публикации; общий batch повторно проверяет исходные hashes.
  Координаторы замены/добавления членов RES сливают независимые изменения,
  конфликт того же члена отклоняется. Полная замена устаревших raw bytes и
  устаревший streamed source отклоняются с требованием перечитать источник.
- Раскладка: QLockFile + чтение под lock + трёхстороннее слияние независимых
  записей + QSaveFile. Конфликт той же записи, повреждённый источник либо новое
  пересечение не заменяют файл. Сохраняются неизвестные свойства документа.
  MCP не пишет map.txt/списки регистрации. Ручные экспорты остаются явными действиями.
- Backup/recovery имеют leases повторно занимаемых process slots. Новый процесс
  не пишет чужой editor-session.json и не чистит чужие поколения; после аварии
  свободный слот сохраняет recovery. Прежние224 файлы в старом корне оставлены,
  доступны по прежнему пути, автоматически в новые slots не переносятся.
- Журналы процесса: logs/headless-<pid>/workflow.log. Общий журнал действий и
  всех целей операций — logs/agent-workflow.log, append/rotation под lock;
  последние события поднимаются в доке следующего обычного окна. При занятом
  lock общий append не блокирует GUI, полный event остаётся в процессном журнале.
- Общий terrain RES больше не вызывает модальный вопрос и полный сброс живой
  сцены: обновляется асинхронный индекс браузера; соседние сцены обновляет214.
  Несохранённая активная карта владельца не заменяется внешним состоянием.
  Добавлен live-trigger214: раз в секунду сравниваются нативные file identity/
  change time раскладки, MPR/MOB соседей, sidecar и ресурсов. Hash cache для
  изменившихся файлов прогревается на worker до входа в GUI; стабильный снимок
  запускает штатное согласование world/neighbor cache без сброса активной карты.
  Загрузка, жест, modal interaction и alignment preview откладывают обновление.
- `shutdown_headless` отказывает для обычного окна, dirty/busy/preview. Чистый
  фон закрывается через10мин без рабочих запросов либо после отключения мостов;
  metadata не считается работой. Длительность операции не считается простоем,
  перед закрытием повторно проверяются новая активность, jobs, запись и dirty.
  Незавершённое штатное закрытие дожидается background tasks. Dirty сохраняется
  в памяти, штатный recovery autosave продолжает работать.

## Границы

Функция требует маппер225 и новый мост225; для уже работающего старого моста
нужен один штатный reconnect после будущей установки. Межпроцессная защита
рассчитана на участвующие мапперы225. Установочный договор закрывает прежнее окно.
Режим/Save человек выбирает один раз. Общий стык карты с занятым соседом
не разрешает менять его документ: после освобождения карт можно явно включить
includeNeighbors либо согласовать только свою границу по прочитанному состоянию.
Ручная визуальная/игровая приёмка владельцем отдельно; native/build evidence её не заменяют.
