# EI-SELECTION-PERF-87-AUDIT — задержка при выделении

Дата: 2026-10-01. Версия87; ветка codex/model-picker-usability-v87; HEAD bbd30c279f19ee51dc44e40f6a9ad109c08e8fde, код fd1cb0d386b3ead52701d60658176815d60f5da4. Диагностика, без исправления/установки и без изменения игровых файлов.

## Путь выполнения

- CView::selectNodes вызывает viewParameters. viewParameters проходит объекты видимых уже загруженных MOB для сбора выделения. selectionSnapshot/clearSelect/hasEditableSelection также работают с загруженными объектами. Это не чтение всех MOB-карт с диска и не пересчёт их геометрии.
- CTableManager::setNewData сбрасывает редакторы свойств и создаёт новые CComboDynItem. Каталог JSON перечитывается только при изменении source token (профиль/путь/размер/mtime). Дисковый MOB scan refreshSources/scanNextFile находится в обработчике открытия витрины, не в обычном выделении.
- setModelNames немедленно заполняет все модели. setPreferredOptions немедленно заполняет все текстуры, затем clear и повторно добавляет их по одной строке с заголовками групп. QSignalBlocker(this) блокирует сигналы самого combo, но не сигналы его модели и подключённого proxy/completer.

## Измерения

Диагностический main связан с существующими Release87 object files (все штатные объекты, кроме main.o). Исходник/команды/сырые результаты: build-audit-selection-87/benchmark.cpp, build_benchmark.py, compile.rsp, link.rsp, benchmark-results.log. Скрытая Qt offscreen QApplication, окно редактора пользователя не запускалось. Первоначальный запуск диагностического EXE без полного локального runtime не дал результатов и был остановлен; измерения ниже получены после размещения DLL и offscreen-плагина в собственной диагностической папке, EXIT=0.

Названия ресурсов получены чтением только RES-индексов двух resourceRoots текущих настроек DejaVu: 7164 уникальных MMP и493 MOD. Профильный model-catalog.json прочитан без записи. MOB/MPR не загружались; коллекции ресурсов изменены только в памяти отдельного процесса.

Контроль меняет только связь completion proxy в отдельном диагностическом процессе; это не готовая правка, поиск в таком контроле отключён. Размер списка и алгоритм построения строк сохранены. Подтверждён основной источник: поэлементные уведомления при повторном построении списка с подключённым автодополнением. Рост близок к квадратичному. Этот путь вызывается при каждом выделении, даже если список текстур не открыт; замер без MOB воспроизводит секундную задержку.

## Ограничения и следующий шаг

Не измерено суммарное время реального клика с картой и другими панелями; не исключены дополнительные меньшие задержки. Чтение всех MOB с диска на обычном пути выделения не найдено. Исправление не выполнено в диагностическом запросе. Требуемая реализация: готовить список групп без подключённых UI-потребителей и подключать его целиком, либо лениво при раскрытии; сохранить поиск, русский alias/raw ID, невыбираемые заголовки, рекомендуемые текстуры, undo и clipboard. Проверить производительность на7164+ ресурсах, а не только маленьком fixture. Версия/установка/прежние задачи не изменены.
