## Запрос и границы

Владелец поручил подготовить правила и документацию соавтору. Изменяются только
документы, с локальным scoped-коммитом. Новый push, доступы/участники GitHub,
merge/main, сборка приложения, установка и игровые данные не входят в поручение.
Номер версии не увеличивается для документации. Открытые продуктовые задачи
не объявляются завершёнными.

## Следующий шаг и ограничения

Документация подготовлена локально для передачи. Публикация конкретного
документального коммита требует нового поручения по AGENTS.md; исходные
неочищенные ветки не отправляются напрямую. Для владельца применяется экспорт,
для соавтора после клонирования — обычная очищенная линия.
Доступ соавтора и сборка на его компьютере не проверены, данные ему не передавались.
Первый согласованный запуск там должен сверить реальные пути/toolchain и отдельно
зафиксировать отсутствующие fixtures и ручную/игровую приёмку.
