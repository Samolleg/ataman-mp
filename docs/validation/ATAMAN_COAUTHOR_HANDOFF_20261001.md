## Запрос и границы

Владелец сначала поручил подготовить правила и документацию соавтору. Изменяются
только документы, с локальным scoped-коммитом. После передачи комплекта он явно
поручил «да, опубликуй»: публикация комплекта и фиксации результата разрешена.
Доступы/участники GitHub, интеграция в исходный локальный main, сборка приложения,
установка и игровые данные не входят в поручение.
Номер версии не увеличивается для документации. Открытые продуктовые задачи
не объявляются завершёнными.

## Следующий шаг и ограничения

Соавтор начинает с `docs/COAUTHOR_HANDOFF.md` и `docs/CODEX_TASK_TEMPLATE.md`
в приватном репозитории. Исходные неочищенные ветки не отправлялись напрямую.
Для владельца применяется экспорт, для соавтора после клонирования — обычная
очищенная линия. Будущие публикации требуют своего соответствующего поручения.
Доступ соавтора и сборка на его компьютере не проверены, данные ему не передавались.
Первый согласованный запуск там должен сверить реальные пути/toolchain и отдельно
зафиксировать отсутствующие fixtures и ручную/игровую приёмку.
