# EI-GITHUB-ATAMAN-MP-20261001 — первоначальная публикация исходников

## Запрос и границы

Владелец попросил создать GitHub-репозиторий `ataman-mp` и явно выбрал
приватную видимость. Репозиторий `Samolleg/ataman-mp` создан без автоматически
сгенерированного README/лицензии/коммита; API подтвердил `visibility: private`,
основную ветку `main`, права владельца и пустое первоначальное содержимое.

Исходная линия: Ataman88, `ae23eb7391447113ddf0e8cf44bb7377568db327`.
Код приложения версии88: `2aa8369d1133995ba6c52d3d0fac753e1f2a7ce8`.
Подготовка: `codex/github-ataman-mp`. Номер88 не меняется: реализация приложения,
тестовые ожидания, игровой профиль и установленная программа не изменяются.
Публикуется только выбранная линия в удалённую `main`; остальные локальные
ветки и теги не отправляются. Локальная принятая `main` не интегрируется и
история не переписывается.

## Проверка состава

Для точного исходного SHA проверены все достижимые Git-объекты:

- 1821 коммит, 20741 объект, 11076 уникальных blob, 862441340 байт blob до сжатия.
- Максимальный blob — 10401064 байта; объектов более100MiB нет.
- Проверка текстовых blob на форматы GitHub/OpenAI/AWS-токенов и заголовки
  закрытых ключей: совпадений нет. Это проверка известных шаблонов, а не
  гарантия обнаружения любых произвольных секретов.
- Сохраняются LICENSE.txt, NOTICE.md, upstream-история, авторы и лицензии
  зависимостей. `assets/resources/auxData.res` — исторический ресурс самого
  редактора, используемый его QRC; это не установленный архив игры/мода.
- Существующий corpus `tests/fixtures/ai_graph_native/2026-08-02` содержит
  игровые графы для внутренних тестов. Его README явно ограничивает хранение
  приватным репозиторием и требует удаления из публичной истории перед
  открытием доступа. Исторические release DLL/EXE остаются частью исходной
  upstream-истории; новые сборки не добавляются. Полная история сохраняется
  именно в приватном репозитории; публичное распространение этих fixtures
  этой задачей не разрешено.
- Исходники runtime bridge используют публичные интерфейсы/локальные
  временные профили; совпадения `private ... source` обозначают временные
  файлы запуска, а не включённые приватные исходники движка.

Исключены из новых коммитов и переноса рабочего дерева: чужие изменения
ROADMAP.md, отчёта52 и QM; незакоммиченные отчёт86, настройки, каталоги профиля,

Игровые/модовые файлы установленного профиля не читаются для публикации и не

## Подготовленные изменения

README, CONTRIBUTING, AGENTS и вводная договора отражают адрес приватного
репозитория и точное исключение local-only режима по текущему поручению.
Отдельное разрешение на будущие публикации и интеграцию main сохраняется.
Шаблон bug report использует номер Ataman вместо исторического Endurance.
Код, VERSION, CHANGELOG, LICENSE и NOTICE не изменены.

Проверки публикации: `git diff --check`, точный staged diff, отсутствие чужих
файлов в staging, Git-доступ к пустому репозиторию. Результаты конечного push,
удалённого SHA и сохранности локального main будут записаны после передачи.
Повторная сборка и игровые/интерактивные проверки не требуются для изменения
документов; публикация исходников не подтверждает исправность редактора.
