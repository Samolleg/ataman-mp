## Реализация

Нативное QTreeWidget только для иерархии, другие плоские панели сохранены. MOB→тип с отличимой иконкой→модель/прототип→каждый экземпляр, в том числе одиночный. Русская подпись читается из прежнего JSON; отсутствующие подписи не выдумываются. ID/количество отдельны, числовая сортировка имён. Группы невыбираемые: клик раскрывает, контекстные команды выбирают найденные/все экземпляры. События native ExtendedSelection синхронизируют сцену, включая Ctrl-toggle, Shift-range, стрелки и столбец ID. Двойной щелчок сохраняет наведение камеры/явную активацию другого MOB.

По умолчанию активный MOB, переключатель показывает все загруженные с меткой Locked/Hidden; одиночный выбор не меняет активный документ. Поиск включает alias/name/model/ID и прежние поля. Tooltip счётчика сообщает выбор вне списка. Поведение показывает существ/ловушки, их слоты/точки; native выбор точки и виртуального слота назначает правильный индекс/владельца.

Строки согласуются по ключам MOB+innerId (не по потенциально повторному игровому ID). Существующие строки сохраняются, меняются текст/положение/родитель и состав. Раскрытие, выбор и прокрутка сохранены. Обновление порядка поведения использует тот же путь, не оставляет карту ключей со старыми удалёнными QTreeWidgetItem. Модель/имя/ID/MOB не исправляются автоматически.

При тестировании5000 объектов найдена задержка layout после расширения. gdb hang-stack.log показал QFontEngine/QTextLine→QStyledItemDelegate::sizeHint→QTreeView::sizeHintForColumn→QHeaderView. ResizeToContents числовых колонок запускал повторное измерение строк. Переход на ограниченные ширины по текущему шрифту и кэш иконок устранил задержку: отдельный уточняющий прогон целиком1223 мс, populate68/refresh60/layout9 мс. В финальном параллельном прогоне83 populate91/refresh79/layout19 мс. Это синтетическая CPU/UI проверка, не замер FPS или загрузки реальной карты.
