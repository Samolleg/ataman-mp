## Результат

В «Создать нового MOB → Скопировать настройки из» добавлены:

- прежние загруженные документы;
- MOB каталога активного профиля с zone ID, именем карты и именем файла;
- остальные MOB его mapRoots, включая AutoZone и незарегистрированные файлы;
- «Выбрать файл…» с диалогом открытия `.mob`.

Пути из каталога и папок не дублируются по canonical path; при выборе файла,
уже представленного в списке, используется существующая запись. Полный путь
есть в подсказке. Ширина диалога остаётся650, раскладка формы сохранена;
длинные записи не увеличивают ширину формы, список ограничен12 видимыми строками
с прокруткой. Новые строки переведены на русский.

`CMob::readTemplateParameters` читает файл через `QIODevice::ReadOnly`, закрывает
его до разбора и проверяет полную структуру через `CMobDocument`. Временная
проекция содержит только role marker, MAIN_RANGE/SEC_RANGE, SS_TEXT,
DIPLOMATION и WORLD_SET; объекты не создаются, ресурсы и sidecars не загружаются,
backup/recovery для источника не создаются. В диалоге хранится лишь извлечённое
состояние параметров. Все четыре флажка используют прежний генератор нового MOB.

Ошибка чтения/повреждение показывается отдельным понятным RU-сообщением,
предыдущий выбор сохраняется; можно выбрать другой источник или продолжить
без копирования. Отмена выбора тоже сохраняет предыдущий источник. Сохранение
нового MOB поверх выбранного файла-шаблона запрещено. Выбор «Не копировать
настройки» сбрасывает флажки и возвращает доступность ручных полей.

   сохранён прежний выбор; выбор исправного источника, создание и reopen успешны.
   Несуществующий источник отдельно возвращает непустую диагностику.

   После каждого create/save/reopen исходный файл побайтно равен исходным bytes.

тестового драйвера; run2 выявил вызов readMob без обязательного attach/progress
в тесте; run3 исправил выбор AutoZone по подстроке вместо точного zone1.mob.
Эти ошибки harness исправлены; исходные логи сохранены. Для финального run4
использованы свежие копии входов. Production-код не менялся после финального
archive-снимка; повторных неизменённых прогонов после PASS нет.
