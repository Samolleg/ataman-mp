## Причина и изменение

Существующая команда холста направляла пользователя только в Save As; низкоуровневый helper специально запрещал один source/destination, а MOB сохранялся отдельно. Новая кнопка «Применить к текущей MPR» готовит и валидирует общую пачку: текущая MPR, точный sidecar-атлас, перенесённое семантическое поле материалов, все открытые/одноимённый/зарегистрированные для карты MOB, их группировка и `.mpr.navigation-stale.json`. Пачка использует проверку исходных байтов, резерв, atomic replacement, readback и rollback при ошибке. После записи открываются прежние пути, сохраняются активный MOB/видимость; начинается новая история Undo/Redo. Перед подготовкой разрешаются черновики окон MOB.

Рельеф, offsets/normals, материалы и покрытия переносит канонический resize без rebuilding serializer. Неравные сектору смещения ретайлят данные; расширение продолжает кромку земли, без добавления покрытия снаружи. Высоты на закрываемой кромке изменяются только по явному флажку. Объекты за границей блокируют применение, пока пользователь явно не разрешит удаление. Переносятся все пять наборов unit guard/patrol/look и зоны/cast points ловушек, сохраняются ID/сырой Z. Сопутствующий старый MOB helper прежде переносил только первую логику; исправление сохраняет и восстанавливает полный movement state, включая подготовку/отмену кандидата.

Старые embedded и external graph bytes сохраняются для сравнения. Навигация считается устаревшей после reopen; её нельзя незаметно использовать или автоматически пересчитать при подготовке игровой карты. Явная кнопка создаёт новый preview по новым размерам MPR, затем требуется публикация. Стойкая отметка снимается только когда свежий граф действительно владеет runtime-навигацией; экспорт, перекрытый старым embedded MOB, недостаточен. Переключение на старый внешний файл блокируется.
