# EI-MAPTXT-DIRECT-EDIT-55

- Реализация: кнопка «Редактировать map.txt…» в панели переходов открывает полный текст текущего `texts.res/map.txt`.
- До применения проверяются представимость CP1251 и структура зон. Отмена не меняет документ. Применение проходит через Travel Undo/Redo; запись остаётся в штатной транзакции Ctrl+S с проверкой внешних изменений архива и сохранением других членов RES.
- Встроенный `travelEditorIntegrationCheck` дополнен проходом через диалог и Undo/Redo. На итоговой Release 56 проверка `travelEditorProductionRouteWorks=1`. Изменённый диапазон текста заменяется без пересборки неизменённых байтов файла; смешанные окончания строк за пределами диапазона сохраняются. Проверка на пользовательском игровом ресурсе не проводилась.
