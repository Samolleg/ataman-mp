# Ataman 118: общая сетка тайлов соседних карт

Задача EI-NEIGHBOR-TILE-SNAP-118, поручение «приступай» от 2026-10-06.
База main: `7b373f3ebfb358381ae737db3e37dad0463a16a0`, переданная версия117.
Проект: [согласованное решение](ATAMAN_NEIGHBOR_TILE_SNAP_DESIGN_117_20261006.md).
Разрешены реализация, локальные проверки, scoped-коммит и обновление постоянной
установки. GitHub, изменение установленных игровых данных и запуск пользовательской
GUI не входят в этот шаг. Родительские ручные приёмки сохраняются.

## Причина и результат

Прежнее округление origin до0,25 не совмещало ряды тайлов с шагом2. Независимые
поправки по X/Y в добавлении могли притягивать карту к продолжению далёкого края.
Теперь оба пути вызывают `CWorldMapSnap::place`: сетка определяется постоянной
опорной картой компонента, а не текущей активной картой. Фаза дробной опоры
сохраняется: `anchor + 2 * floor((requested-anchor)/2 + 0.5)`.

Магнит проверяет реальный общий отрезок или угол, совместимость сетки и отсутствие
перекрытия для кандидата. Порог задаётся12 пикселями, переведёнными на плоскость
перетаскивания; удержание выбранного стыка уменьшает дрожание. Совместимые швы
рисуются зелёным через штатный OpenGL overlay. Старые несовместимые соседи
не меняются автоматически; рядом с ними предлагается явное выравнивание.

В «Отображение» добавлены «Привязка к тайлам» (по умолчанию включена) и
«Выровнять по тайлам…». Галочка сохраняется; выключение разрешает точные свободные
координаты. Диалог показывает текущие и будущие координаты, позволяет снять
галочки со строк и предварительно двигает сцену. Опорные и уже ровные карты
остаются на месте. Esc/«Отмена» возвращают точный исходный вид, «Применить»
сохраняет выбранную группу одной командой Undo/Redo.

Перетаскивание и добавление также входят в Undo/Redo. Команда принадлежит
раскладке JSON: она не помечает MOB изменённым и не перестраивает его индекс.
Сохранение группы выполняется один раз с проверкой ожидаемых записей,
блокировкой, защитой от внешнего изменения и QSaveFile. При ошибке состояние
не публикуется частично. Проверенные асинхронно размеры MPR сохраняются при Undo.

При размещении над соседней картой высота плоскости берётся с видимого соседнего
рельефа. Включение расстановки отменяет прежний инструмент; Esc теперь отменяет
реальный drag, а не только размещение новой карты. Вход overlay учитывает drag
самостоятельно, даже когда в сцене нет других диагностических подсказок.

## Проверки

Все данные проверок созданы в собственных временных каталогах. Native-пробник
строит три плоские1×1 MPR из распространяемого synthetic fixture проекта;
игровые карты и ресурсы не копировались. Исходный случай4 карт из схемы пользователя
проверяется математическим тестом; точные файлы этой пары владельца не определены.

| Свежая release118 | Сборка EXE, Bridge и RuntimeHost успешна; `--version`118 |

Core покрывает четыре стороны, углы, T-стык, схему4 карт, разные размеры,
дробную опору, отрицательные координаты, равные расстояния, гистерезис,
несовместимую фазу, свободный режим и отсутствующую опору. JSON-контур проверяет
legacy opening без ремонта, целую группу Undo/Redo/reopen, добавление/отмену,
невалидные ресурсы, дубликаты, удаление опоры, внешний write и lock без частичного
сохранения, а также сохранность уточнённых размеров.

Native выполняет настоящие mouse/key handlers, переключатели и production-диалог
MainWindow: загрузка фоновых MPR, preview без write, release commit, Esc,
Undo/Redo, свободный drag, новая карта на той же сетке, прежняя double-click
навигация с точными world origins, выбор строк, отмена диалога и Apply группы.
Точная зелёная линия проверена пикселями production OpenGL overlay в собственном
FBO. Это проверка прохода renderer, не ручная приёмка видимой пользовательской GUI.
Все три MPR после операций byte-identical.

Промежуточные отказы не записаны как PASS: первая сборка обнаружила повторное
объявление helper; первые core-тесты — отсутствующие файлы fixture. Native
выявил ожидание асинхронной загрузки, Esc, плоскость размещения и условие входа
overlay. Front-buffer скрытого окна не является надёжным кадром; проверка
отрисовки использует контролируемый FBO. После исправлений финальные focused
проверки прошли; исходный UI clipboard baseline остаётся ограничением.

Локальные логи: `build-tests-118-tile-snap/`, сборка:
`build-release-118-tile-snap/`. Чужой `translations/ei_mapper_ru.qm` восстановлен
byte-exact после lrelease: SHA256
`EDA31955A912758ACB5A7BDE043BBF2EB5F8A2606FA32DC52AFA4156CA74ED9F`.
Установленная игровая раскладка прочитана только для сверки; её SHA256 остался

Владелец должен повторить исходную пару карт: «Отображение» → «Соседние карты» →
«Расставить карты», проверить зелёный стык, ряды тайлов, Esc/Ctrl+Z/Ctrl+Y,
добавление карты и сохранение/повторное открытие. Для уже дробно расположенной
группы использовать «Выровнять по тайлам…» и сначала оценить preview.

Origin-snap совмещает сетку. Локальные XY-смещения вершин, высоты и материалы
границы автоматически не исправляются. Файлы MPR/MOB сохраняют локальные
координаты; раскладка задаёт редакторское соседство, а не изменение мировых
координат установленной игры. Полная приёмка исходных карт остаётся открытой.
