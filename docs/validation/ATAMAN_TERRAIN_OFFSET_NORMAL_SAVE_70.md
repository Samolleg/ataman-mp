# Ataman 70 — сохранение XY-сдвига вершины общей кистью

Дата: 2026-09-25. Задача `EI-WORLD-TERRAIN-OFFSET-NORMAL-SAVE-70`.

## Исходный отказ

На снимке версии 68 «Сохранить все карты» остановилось на `terrain.land_normal_integrity` для `zone2.mpr`, `zone2004002.sec vertex 159,96`. Это отказ защитной проверки до записи повреждённой карты, не вылет процесса. Снимок создан до установки версии 69; этот участок кода в 69 не менялся.

Отдельный тест `offsetOnlyTerrainEditCanBeSaved` создал неплоскую карту, сдвинул одну вершину только по XY и попытался подготовить проверяемую SEC-транзакцию. До правки он получил тот же `terrain.land_normal_integrity` для соседней вершины 16,15. Первая неверная величина: множество нормалей при сохранении строилось только по отличию высот от исходных. В `apply` нормали обновлялись и после XY-сдвига, поэтому корректное состояние предпросмотра ошибочно отвергалось на записи.

## Исправление

`CTerrainEditModel::appendSectorEdits` считает геометрически изменённой вершину, когда изменена высота **или** исходное смещение X/Y. Нормали вокруг такой вершины включаются в ту же каноническую транзакцию. Последующая проверка высот, смещений и нормалей каждого SEC оставлена без ослабления. Для отсутствующей ссылки на сектор не вызывается `first()`.
