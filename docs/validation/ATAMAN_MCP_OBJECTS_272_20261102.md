## Реализация

| Инструмент | Поведение и предел |
|---|---|
| `edit_objects` | Размещение статических прототипов; transform/copy/delete по ID либо прямоугольнику/полигону3..128 вершин, фильтры типа/прототипа. До500 объектов, preview точных целей, одна штатная Undo. Поворот группы вокруг pivot/центра, сдвиг XYZ; размещение с относительным Z, поворотом, комплекцией FIG, текстурами/частями/тенью из ручной модели |
| `query_passability` | До200 точек, слои0..7 панели, радиус0..32м, ближайшая проходимая и расстояние; явный `graphStale`. Слой3 — human-sized. Штатный классификатор по текущим статическим коллизиям, сетка0,5м |
| `rebuild_ai_graph` | Все8 слоёв штатного построителя, раскраска/проверка совместимости, до16384 графовых ячеек. Preview/отмена/одна Undo, встроенный граф основного MOB в памяти; отдельный `save`. Старый `.grp` и Nav64 не изменяются |
| `validate_map` | Семейство MOB, ID, ссылки, парсер, ресурсы, устаревший граф. Info отдельно; Warning/Error в `findings`, уровень/код/сообщение/ID/путь/доступные координаты. До2000 находок/512КиБ; переполнение даёт ошибку, без молчаливого усечения |

Лимит500 ограничивает объём Undo, синхронное обновление моделей/дерева и размер
ответа; пакет не делится скрытно. Юниты не редактируются и не создаются.
Свободные ID выделяются штатным семейным распределителем с учётом AddMob,
юнитов, технических узлов, сценарных ссылок и резервов сессии/Undo.
Перенос/удаление отклоняются при входящих ParentID, литеральных сценарных
обращениях, InScript, явных объектных ID логики и переходах map.txt; force нет.
Динамические выражения сценария не исполняются: это предел статической
проверки, а не доказательство поведения игрового сценария.

Операции используют существующие revision → preview/operation_status → apply/
cancel, штатные CMob/CView/QUndoStack и семейный сериализатор. Ревизия учитывает
полную проекцию MOB; перед apply сверяются дисковые зависимости семейства и
map.txt. Долгая подготовка — в работнике, GUI snapshot отложен до выдачи op ID.
Изменения немедленно обновляют сцену, дерево, параметры и dirty; save остаётся
штатным действием с сохранённой галочкой владельца. Каталог222 обновляется
через `tools.listChanged`. Схемы, примеры и пределы: [AI_AGENT_MCP.md](../AI_AGENT_MCP.md).

`search_database` сохраняет прежние записи и дополнительно показывает статические
модели штатной витрины с авторскими привязками из model-catalog рядом с БД;
дополнение существует только в отделённом MCP snapshot, каталог не записывается.
Отсутствующая привязка текстуры даёт понятный отказ.
