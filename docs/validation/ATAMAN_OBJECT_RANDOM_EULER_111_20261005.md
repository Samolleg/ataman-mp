## Воспроизведение

CNode::getEulerRotation применяет matrix→normalMatrix→quaternion→toEulerAngles; collectParams/getParam панели берут эти значения. Ручная правка eObjParam_ROTATION_X/Y берёт этот Euler и конвертирует через util::eulerToQuat. Прежний Рандом умножал quaternion на fromAxisAndAngle мирового направления.

Детерминированный Qt5.12 reproducer по скриншоту: исходно (2.5613,24.6983,-76), старый worldX+15 даёт (16.1452,25.7574,-69.5356): меняются все три поля. Требуемое componentX+15 даёт (17.5613,24.6983,-76), componentY+15 — (2.5613,39.6983,-76). Доказательство build-tests-111-random-euler/repro.cpp/repro.out; архивы/карта не изменялись.

## Исправление и границы

Выбор значений по X/Y теперь производится в показанных Euler-полях, с конвертацией util::eulerToQuat как ручное редактирование. X/Y выбираются независимо и преобразуются одним quaternion. Z остаётся исходным. Кандидат проверяется тем же matrix-путём панели до любой мутации; один атомарный набор, точные before/after quaternion для Undo/Redo. Предварительная валидация всех объектов и оптимизация110 (один индекс MOB, одна проекция итоговой геометрии, одно dirty/свойства/update) сохранены. Подсказки меню исправлены на поля вместо мировых осей.

Euler X имеет каноническую область±90°; переход через неё переворачивает Y/Z на180°. Сэмплирование X ограничено пересечением исходного±силы и[-89.9,89.9] без такого перехода. Y циклический по360°. Обычная float-погрешность остальных полей проверяется≤0.0001°; при |исходногоX|>85° из-за вырожденного представления допуск≤0.02°. Кандидаты со скачком неприменённых полей отвергаются (максимум32 пробы); если представление не сохраняет поля, весь набор отклоняется до изменения. Это не ремонт карты и не нормализация исходных quaternion при Undo.
