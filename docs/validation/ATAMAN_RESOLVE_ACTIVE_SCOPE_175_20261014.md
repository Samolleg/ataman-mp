# Ataman175 — область «Исправить переходы»

Поручение14.10 уточняет продолжающееся исправление174: ремонт активной карты
и только примыкающих к ней тайлов соседей. База main
070c50d30397fdddbad355c2da2b8f1828dbcecc, установленная174.

Подтверждённая причина: `resolveWorldMaterialBlends` рекурсивно собирал всю
связанную группу. `preserve` ограничивал исходный поиск соседних тайлов,
но последующий connected mixed-edge обход и повторный обход внутри генератора
не соблюдали это ограничение. План и финальный рисунок стыков включали также
границы соседей между собой. Проверка174 не проверяла допустимую область.

В175 выбираются только непосредственные соседи активной карты; seam sides
включают только пары с активной. Маска допустимых тайлов устанавливается до
семантического плана, ограничивает connected search и остаётся в силе при
генерации. Повторный неограниченный обход отключён. Перед общей транзакцией
проверяются packed-тайлы и материалы защищённых ячеек; нарушение отменяет
всю подготовленную операцию.

## Критерии и текущее подтверждение

Проверки ещё не выполнены. Нужны адресные проверки области и связанного
поведения: активная zone1, три её непосредственных соседа при выбранных8
картах; только верхний ряд zone2, западные ряды0..111 zone3obr и128..159 zone7.
Остальные4 карты должны сохранить точные модели/атласы, остальные тайлы
соседей — packed presence и материалы. Отдельно отмена, общий Undo/Redo,
native-вода/анимации и повтор с0 rasterization. Синтетический тест проверяет
также стык соседей между собой и остановку connected search на маске.

Живые игровые файлы только читаются. Используются уже существующие приватные
копии174 без сохранения в них. Ручная визуальная/игровая приёмка владельцем
и исходная цель172 остаются открыты.
