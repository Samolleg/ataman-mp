# Публикация исходников Ataman 98

Задача EI-PUBLISH-98-20261003. Владелец прямо поручил сделать коммит и отправить
текущий результат на GitHub. Исправление98 уже закоммичено:
ba8873184b417afcf8275f837d1e8c805409f778, результаты передачи:
87a3c0c763cb10a59c3489f6bb65d58375bd6d15.

Перед работой проверены действующие правила, roadmap и dirty state. Чужие
11 строк ROADMAP, отчёт52, QM и untracked отчёт86 сохраняются и не публикуются.
Исходный локальный main ce9dc97473b9efc64c8052602116940dcada3586 не изменяется.

Git ls-remote подтвердил на GitHub только main:
f12645f5f63e737d6c3fa28b8006e5f23879bdea (версия88/документация соавтора).
Изолированный очищенный экспорт продолжает эту линию до текущей98, включая
необходимые предшествующие изменения89–97. Точная публикация идёт отдельной
веткой codex/zone9-paint-v98, без изменения main, force, остальных веток/тегов.
Игровые ресурсы и готовые сборки исключаются из всей достижимой истории;
auxData.res редактора остаётся по ранее проверенному исключению.

Перед push необходимо подтвердить byte-identical оставшееся дерево, сохранённое
авторство/сообщения, отсутствие исключённых путей и объектов, fsck и version98.
Подготовка/проверка экспорта и результат push фиксируются ниже после выполнения.
Новые проверки приложения не требуются: исходники совпадают с уже проверенным
коммитом98; публикация не закрывает ручную проверку zone9.
