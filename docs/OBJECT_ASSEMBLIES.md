# Готовые сборки — Ataman 95

Выберите несколько уже размещённых деталей активного MOB, затем откройте нижнюю кнопку «Сборки» → «Сохранить выделенное». Введите название. Маппер сохраняет полный состав с моделями, текстурами, частями моделей, игровыми полями и неизвестными байтами исходных записей. Если у детали ещё нет полной исходной записи, сначала сохраните MOB. Выбранные детали становятся одной редакторской сборкой.

Каталог открывается этой же кнопкой («Каталог сборок»), через «Инструменты → Сборки», из «Создать объект» и из витрины моделей. Слева — плитки готовых сборок, справа — список составляющих моделей и их основных текстур. Поиск учитывает название сборки, ID моделей, их русские названия и текстуры. Разделы: Дома, Архитектура, Ворота, Утварь, Деревья, Кусты, Рычаги и сундуки, Декор; острова — Гипат, Ингос, Суслангер. Для нераспределённых объектов есть «Все сборки» и «Все острова». Разделитель областей и геометрия окна сохраняются.

Выберите плитку → «Разместить сборку». После закрытия каталога наведите мышь на рельеф: весь комплект следует за точкой размещения. ЛКМ или Enter подтверждает, Esc отменяет весь комплект и возвращает прежнее выделение. Без MPR доступна плоскость Z=0 самостоятельного MOB. Новые ID выделяются независимо от типа объектов; внутренние Parent Id указывают на новые детали. Игровые ссылки на родителя вне выделения требуют включить родителя в состав либо явно изменить связь до сохранения сборки.

Щелчок по одной детали выделяет всю сборку; Shift переключает всю группу. G переносит комплект, R вращает вокруг общей мировой оси, сохраняя взаимное расположение даже на неровной земле. Ctrl+C/Ctrl+V одной сборки создаёт самостоятельный экземпляр. Undo/Redo отменяет или возвращает размещение, группировку и разбор одной операцией. «Сборки → Разобрать выделенное» возвращает независимые детали; Undo восстанавливает группу. Удаление выделенной сборки использует обычное удаление всего выделения.

Чтобы изменить библиотечный образец, разместите/разберите его, отредактируйте части и выделите новый состав. Откройте каталог, выберите исходную запись и нажмите «Заменить состав из выделения». Уже размещённые экземпляры автоматически не меняются. «Сохранить описание» меняет название, категорию и остров. «Удалить из каталога» удаляет образец, сохраняя объекты на карте.

## Хранение и сохранение

Используется существующий профильный `model-catalog.json` рядом с выбранным `database.res`. JSON содержит:

- `assemblies`: ID записи, schemaVersion=1, имя, категория, остров, массив деталей. Каждая деталь содержит полный объект, raw provenance, мировой offset и порядковый `parentPart` либо -1. Сохраняются дополнительные поля записи.
- `assemblyInstances`: относительный путь MOB, SHA-256 его сохранённых байтов, группы экземпляров и однозначные пары ID/тип/модель. Эта часть хранит редакторскую группировку.

В MOB остаются обычные игровые объекты. Сохраните MOB после группировки/разбора/размещения, чтобы обновить экземпляры в JSON. Переносите карту вместе с каталогом профиля и используемыми моделями/текстурами. Пути экземпляров относительные; удаление JSON оставляет игровые объекты, но теряет редакторские группы и библиотечные образцы.

MOB и JSON сохраняются атомарно каждый отдельно. Это не одна общая транзакция двух файлов: если MOB уже записан, а каталог записать не удалось, маппер сообщает именно о частичном сохранении и оставляет ожидающую запись метаданных. После устранения ошибки повторите сохранение. Устаревший экземпляр каталога не перезаписывает внешние изменения JSON. Если MOB изменён внешним редактором и SHA-256 больше не совпадает, старая группировка не применяется к потенциально другим объектам с такими же ID; игровые объекты продолжают загружаться.

## Границы текущей функции

Поддержаны 1–512 объектов мира, рычагов, факелов, источников света/звука и частиц из одного активного MOB. Существа/ловушки с дополнительными поведенческими ссылками не переносятся в сборки. Неполные/повреждённые шаблоны, циклы родителей и нулевые кватернионы отклоняются целиком, без частичной вставки.

Сборка не объединяет геометрию и коллизии в одну игровую модель. G/R работают с общей геометрией; привычный Scale меняет параметры комплекции отдельных объектов. Магнит пока требует одну архитектурную деталь: используйте «Разобрать», стыкуйте детали и снова сохраните выделенное как сборку. Смешанное выделение сборки и других объектов не экспортируется как один сгруппированный буфер автоматически; сохранить такой комплект можно явно через «Сохранить выделенное».

CPU-превью собирает базовую геометрию выбранных частей с основными текстурами и поворотами. Свет/звук/частицы не имеют архитектурного превью; комплекция и дополнительные текстуры сохраняются в объекте, но не воспроизводятся полностью в плитке. Лимит превью — 60000 треугольников, всего каталога — 32 MiB; недоступное превью не удаляет состав. Превью только видимых плиток строится в фоне, закрытие отменяет работу без ожидания GUI. Исходные игровые данные не сканируются на каждом выделении.

Автоматическая проверка: `EIMapperEndurance.exe --assembly-catalog-check` использует отдельные синтетические данные и настройки. Ручная приёмка на конкретных Blender-моделях и профиле выполняется владельцем; сама сборка EXE её не заменяет.
