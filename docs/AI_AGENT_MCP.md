# ИИ-агент через MCP — Ataman 218

Версия218 даёт Codex CLI и Claude Code чтение уже открытого редактора. В меню
«Вид» откройте док «ИИ-агент» и сами выберите «Только чтение». Начальное
состояние каждого запуска — «Выкл»; выбор не сохраняется. «Правка — скоро»
недоступна. Кнопка «Отключить» отменяет операции, удаляет обнаружение и разрывает
все подключения. Мост не запускает редактор, не включает режим и не сохраняет карты.

## Подключение

Комплект содержит `EIMapperEndurance.exe` и `EIMapperMcp.exe` рядом с Qt DLL.
Сначала разместите комплект по окончательному пути: конфиг агента содержит
абсолютный путь к мосту. Для218 подготовлен staging; установка217 не обновляется.

Кнопка «Подключить Codex/Claude Code» показывает план изменения. До нажатия OK
ничего не записывает. Для Codex она запускает найденный в PATH `codex.exe` с
показанными аргументами. Если CLI установлен через другой launcher, выполните
показанную команду вручную. Пример PowerShell:

```powershell
codex mcp add ataman -- 'C:\путь к комплекту\EIMapperMcp.exe'
codex mcp get ataman --json
```

Для Claude Code кнопка предлагает выбрать проектный `.mcp.json`, затем показывает
полный итоговый JSON и путь для отдельного подтверждения. Сохраняет другие серверы
и ключи, создаёт точную `.ataman-<uuid>.bak`, проверяет отсутствие изменения файла
после предпросмотра, заменяет файл атомарно. Пример результата:

```json
{
  "mcpServers": {
    "ataman": {
      "type": "stdio",
      "command": "C:\\путь к комплекту\\EIMapperMcp.exe",
      "args": []
    }
  }
}
```

Альтернатива в каталоге выбранного проекта:

```powershell
claude mcp add --transport stdio --scope project ataman -- 'C:\путь к комплекту\EIMapperMcp.exe'
```

Перезапустите сессию агента после настройки. В Claude подтвердите доверие проектному
MCP, проверьте `/mcp`; в Codex также доступен `/mcp`. Команды регистрации описаны
в [документации Codex](https://developers.openai.com/codex/mcp) и
[Claude Code](https://code.claude.com/docs/en/mcp). Реальные конфиги владельца
при разработке не редактируются: тесты используют отдельные CODEX_HOME,
CLAUDE_CONFIG_DIR и проектный JSON внутри каталога проверки.

Первое поручение агенту: «Вызови list_instances, выбери мой экземпляр через
connect_instance, прочитай get_context». Если экземпляров несколько, выбирайте
ID из списка; список содержит PID/версию/время включения, без секрета.

## Инструменты

| Tool | Результат |
|---|---|
| `list_instances`, `connect_instance`, `disconnect_instance` | Обнаружение и подключение к включённому пользователем экземпляру |
| `get_context` | Профиль, MPR, загруженные MOB/активный MOB, dirty рельефа/мира/MOB/переходов, размеры и координаты соседей по текущей раскладке |
| `read_terrain` | Снимок текущего рельефа, min/max/mean всей сетки и ограниченный фрагмент/выборка высот |
| `read_paint` | Физические packed-тайлы, runtime type, overlay material и известные семантические углы по области |
| `material_palette` | ID/имена материалов палитры профиля, при её отсутствии — активного атласа |
| `list_objects` | Объекты загруженных MOB, фильтры имени/модели/типа, страницы и `selectedOnly`; выделение только читается |
| `search_database` | Поиск по monsters/items/prototypes активного снимка БД профиля |
| `list_profile_maps` | MPR/MOB в mapRoots профиля, включая незарегистрированные файлы |
| `read_profile_map` | Дисковые высоты, покраска, таблица материалов, объекты соседнего MOB; также отдельный MOB; без смены открытой карты |
| `operation_status`, `cancel_operation` | Опрос результата и отмена фонового чтения |
| `window_snapshot` | Настоящее окно с framebuffer вида, PNG до1024×768 и384 КиБ |

`read_terrain`, `search_database`, `list_profile_maps`, `read_profile_map` сразу
возвращают `operation`/`status: running`. Передайте ID в `operation_status`;
при `status: complete` данные находятся в `result`. Поле `error` означает отказ,
а не пустую карту. Рекомендуемый интервал опроса250–500мс. `cancel_operation`
отменяет работу и удаляет результат; последующий опрос вернёт unknown/expired.

Ресурсы MCP: `ataman://context` и `ataman://tools`. Первый требует подключения;
второй содержит описание tools и ограничений. Сырых архивов, скриптов, неизвестных
бинарных полей и файлов произвольного пути API не выдаёт.

## Координаты, страницы и ограничения

- Высоты: `x/y` — индексы вершин, одна единица сетки соответствует1м; реальное
  положение displaced-вершины находится в `worldX/worldY`. `raw * rawToWorld`
  даёт высоту мира. `width/height` по умолчанию16, до64; `step`1–1024.
- Покраска: координаты тайлов, шаг2м; `layer` — `land` или `overlay`.
  `semanticCornersNW_NE_SE_SW` возвращается только при известном поле.
  Неизвестная семантика не восстанавливается и не угадывается. Runtime material
  MPR, физический tile и ID материала палитры — разные идентификаторы.
- Страница — до200 строк; используйте возвращённый `nextOffset`. Для объектов
  offset относится к порядку исходных объектов всех MOB; один вызов просматривает
  не более10000 после offset. Палитра использует исходный индекс, БД — индекс
  совпадения. При редактировании человеком между страницами состав может меняться.
- Фрагмент — максимум4096 значений; JSON-ответ дополнительно ограничен512 КиБ.
  При отказе по размеру уменьшите область/страницу. Кадр stdio/pipe —1 МиБ.
- Карты профиля именуются ключами `номер-корня/относительное-имя` из каталога.
  Абсолютный путь, `..` и выход через ссылку за корень запрещены. Поиск каталога
  ограничен10000 файлами. MPR/MOB — до64 МиБ каждый; рельеф — до4096 секторов.
  Большая неподдерживаемая карта остаётся нетронутой, возвращается ошибка.
- Максимум4 локальных подключения,2 одновременно работающих чтения,8 операций
  с результатами. Результаты удаляются через60с от создания; работа ограничена30с.
  Парсер дисковых карт живёт в отдельном процессе с лимитом512 МиБ.
- Активная карта читается из памяти, дисковая — с диска. Снимок высот/БД фиксируется
  при запросе и может устареть после дальнейших действий человека. Undo, dirty,
  сохранение, файлы карты и выделение вызовы218 не меняют.
- Пока открыт модальный диалог, чтение редактора отклоняется; повторите после
  закрытия диалога. Не используется буфер обмена, TCP, HTTP или сетевой listener.

## Протокол, безопасность и завершение

Стандартный MCP работает через UTF-8 JSON-RPC2.0, одна строка на сообщение,
без LSP `Content-Length`. stdout моста содержит только протокол.
Поддерживается текущая [редакция2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning):
`server/discover`, metadata каждой modern-заявки, `resultType: complete`, tools/resources.
Для клиентов с handshake поддержаны initialize-редакции2025-11-25,2025-06-18,
2024-11-05. Необъявленные расширения MCP tasks/subscriptions не реализованы;
фоновые чтения используют обычные tools с явным опросом.

Мост соединяется через QLocalSocket с QLocalServer видимого редактора, Windows
`UserAccessOption`. Каждое включение создаёт новый случайный ID и секрет сессии.
Файл обнаружения находится в пользовательском AppData (`QStandardPaths::GenericDataLocation`)
по пути `EIMapperAtaman/automation/<id>.json`;
каталог получает защищённую DACL текущего Windows-пользователя, файлы наследуют её.
Секрет передаётся только внутри локального протокола и не попадает в конфиги,
списки экземпляров или кольцевой журнал200 событий панели. Такой доступ намеренно
доверяет процессам этого же пользователя; это не изоляция от вредоносной программы,
уже работающей от его имени. Stale-файлы после аварии не удаляются мостом; недоступные
каналы не показываются.

Транспортные ID моста независимы от MCP ID. Чужой/поздний ID отбрасывается;
после локального таймаута2с соединение уничтожается. Нужен новый connect_instance,
поэтому поздний ответ не может стать результатом следующего запроса.
Долгая операция не удерживает этот вызов: она возвращает ID для опроса.

Контроллер хранит QPointer вместо сырого CView*. В нормальном closeEvent211
`stop()` вызывается до `prepareForApplicationShutdown` и удаления вида.
Отключение закрывает sockets, отменяет снимки, убивает только свои read-worker
процессы и удаляет свой descriptor. Чтение/индексация не ожидается в GUI-потоке;
watcher после отмены не обращается к редактору. Деструктор и destroyed-сигнал
дают дополнительную защиту альтернативного пути завершения.

## Этап219+

Authority, локальный транспорт, MCP и read adapter разделены. Продолжение добавит
отдельные команды и режим правки, который включает только человек:

1. Подготовка ограниченного кандидата вне GUI, с ID операции, отменой и сроком.
   Кандидат фиксирует revision/generation открытого документа, профиль, источники
   и точные входы; применение устаревшего кандидата запрещается.
2. Неразрушающий preview в GUI; подтверждение применения отдельной командой.
   Никакой скрытой покраски или включения режима агентом.
3. Применение через существующие terrain/world brush commands и QUndoStack:
   один запрос/мазок — одна отмена, включая соседние карты и связанные высоты MOB.
4. Сохранение только штатным batch-конвейером209–216: guards, backup, validation,
   atomic commit/readback, точное принятие атласа и семантики. Создание карты — через
   существующий генератор. MCP не получает второй самостоятельный serializer.

RecipeBaker/MixedEdge и другое ядро переходов в218 не возвращаются.
